## 题目：
NPU 核内调度算法设计与优化研究

## 摘要：
随着人工智能技术的快速发展，神经网络模型的规模和复杂度不断增长，对计算资源的需求呈指数级增长。通用神经网络处理器（NPU）作为专门针对神经网络计算优化的硬件平台，其核内调度问题直接影响着整体计算性能和资源利用效率。本文针对SIMD 架构下通用神经网络处理器的核内调度问题，从计算图调度、缓存管理和性能优化等多个维度深入研究了调度算法的设计与优化，提出了一系列创新性的解决方案，并进行了算法通用性分析，为神经网络处理器的高效运行提供了重要的理论基础和实践指导。问题一：最小缓存驻留调度优化。本文研究了SIMD 平台下核内缓存的最小驻留调度优化问题。在给定的有向无环计算图（DAG）中，每个节点包含操作节点和缓存管理节点（ALLOC/FREE），需要在满足拓扑序约束的前提下，寻找使得执行过程中最大缓存驻留容量最小的调度序列。建立了基于拓扑排序的数学模型，该模型以最小化max(Vstay) 为目标函数，同时考虑了节点间的依赖关系、缓存分配与释放的时序约束等条件。创新性地设计了多约束平衡贪心调度算法（MCBGS），该算法融合图论、约束满足理论和启发式搜索方法，通过三层核心分量实现缓存峰值的近似最优化：（1）L0 缓存约束优先级分量：基于有限状态自动机理论，采用约束传播技术维护L0A/L0B/L0C 缓存的互斥访问约束；（2）内存感知优先级分量：基于排队论和资源管理理论，引入内存压力指标ρ(t) 和平滑阶跃函数 σ(x)；（3）关键路径优先级分量：基于项目调度理论和最长路径问题，通过关键路径长度 L(v) 和归一化机制确保关键路径上的节点获得优先调度权。算法在O(n2 log n) 时间复杂

度内实现高质量调度。实验验证表明，MCBGS 算法相比随机调度、内存感知贪心和关键路径优先算法的平均缓存峰值降低率分别达到89.2%、85.5% 和89.2%，在Conv0 数据集上实现了90.6% 的突破性改进。问题二：缓存分配与换入换出优化。在问题一调度优化的基础上，进一步研究了缓存分配与换入换出优化问题。在多级缓存架构（L1、UB、L0A/L0B/L0C 等）容量有限的约束下，需要为计算图中各缓冲区分配实际的物理地址偏移，并在缓存空间不足时设计SPILL

# 问题一：最小缓存驻留调度

# 针对给定的有向无环计算图，设计调度算法生成满足拓扑约束的节点执行序列，使得

# 前提下，通过优化调度顺序来压缩缓冲区的生命周期重叠，从而降低峰值缓存需求。这是

# 一个典型的图调度优化问题，需要综合考虑拓扑约束、缓存分配时序和资源利用效率。

# 问题二：缓存分配与换入换出

# 在问题一的基础上，考虑实际硬件缓存容量限制（L1: 4096, UB: 1024, L0A/L0B: 256,

# L0C: 512），为计算图中各缓冲区分配具体的物理地址偏移，并设计SPILL 操作策略以最

# 小化总额外数据搬运量。该问题需要解决：（1）缓存地址的连续分配和碎片化管理；（2）

# 缓存不足时的智能换入换出决策；（3）SPILL 操作对计算图拓扑结构的动态修改。这涉及

# 内存管理[5]、启发式搜索和动态规划等多种算法技术。

# 问题三：性能优化策略

# 在保证总额外数据搬运量不显著增加的前提下，进一步优化调度策略以最小化总执行

# 时间。该问题需要在两个相互冲突的优化目标间寻找最佳平衡：一方面要减少数据搬运开

# 销，另一方面要提高执行单元的并行度和流水线效率[6]。这是一个典型的多目标优化问

# 2 模型的假设

## 在本文的建模过程中，为了简化问题复杂度并确保模型的可行性和有效性，在不影响

## 核内调度算法核心思想和优化目标的前提下，我们做出如下合理假设：

## 假设1 假设计算图为有向无环图（DAG），且所有节点间的依赖关系在调度开始前已完全

## 确定，调度过程中不会动态产生新的依赖关系或修改现有依赖关系。

## 假设2 假设硬件平台各执行单元（Cube 核、Vector 核、MTE1/2/3、FIXP 等）的执行能力

## 稳定，每个操作节点在指定执行单元上的运行周期数为确定值，不受系统负载、温度等外

## 部因素影响。

## 假设3 假设各级缓存（L1、UB、L0A/L0B/L0C 等）的访问延迟相对于计算操作可忽略不

## 缓冲区的数据在不同时刻具有相同的存储需求。

## 假设5 假设SPILL 操作（缓存换入换出）过程中数据传输的可靠性，即数据在核内缓存与

## DDR 之间的搬移过程不会发生数据丢失或损坏，且搬移完成后数据内容保持一致。

## 4.1 问题分析

## 问题一要求针对给定的有向无环计算图G = {V, E}，设计调度算法生成满足拓扑约

## 束的节点执行序列S，使得执行过程中所需的最大缓存驻留容量max(Vstay) 尽可能小。该

## 问题的核心挑战在于：在保证依赖关系的前提下，通过优化调度顺序来压缩缓冲区的生命

## 周期重叠，从而降低峰值缓存需求。

## 针对问题一，整体思路流程如图4.4所示。首先，结合拓扑排序理论、关键路径分析方

## 法、L0 缓存约束管理和内存感知的节点选择策略，提出一种基于优先级的平衡贪心调度

## 算法[7]；随后，建立了计算图节点调度的数学优化模型，给出了平衡贪心算法的详细实施

## 步骤；最后，通过与传统贪心算法、简单优先级算法等方案在峰值内存占用、算法复杂度

## 等方面进行对比，验证所提出的基于优先级的平衡贪心调度算法能够有效降低缓存驻留峰

## 值，满足NPU 核内调度的内存优化需求。

## 4.2 求解思路概述

## 问题一的核心在于设计调度算法生成满足拓扑约束的节点执行序列，使得执行过程中

## 所需的最大缓存驻留容量尽可能小。整体求解思路采用基于优先级的平衡贪心调度算法，

## 通过结合拓扑排序理论、关键路径分析方法、L0 缓存约束管理和内存感知的节点选择策

## 略来实现优化目标。算法首先建立计算图节点调度的数学优化模型，构建多目标优化函数

## 平衡关键路径长度、内存使用和L0 缓存约束，然后通过设计平衡的节点优先级函数，在

## 满足拓扑约束的前提下优化调度顺序，压缩缓冲区的生命周期重叠，从而有效降低峰值缓

## 存需求。如图4.4所示，该算法能够在保证依赖关系的前提下，实现对缓存驻留峰值的有效

## 控制，满足NPU 核内调度的内存优化需求。

## 5.1 问题分析

## 问题二要求基于问题一得到的调度序列S，为计算图中各缓冲区分配实际的物理地址

## 战在于：在满足硬件缓存容量限制的前提下，通过合理的地址分配和SPILL 操作管理，最

## 小化数据在核外内存与核内缓存之间的搬运量。

## 针对问题二，整体思路流程如图5.7所示。首先，基于问题一得到的调度序列S，设计

## 个优化目标：通过first-fit 策略减少内存碎片，基于缓冲区大小、剩余生命周期和复制成本

## 选择SPILL 受害者，以及正确分流消费者到SPILL_OUT/SPILL_IN 节点。

# 8.3 模型缺点与不足

# 尽管本研究取得了一系列重要成果，但模型仍存在多方面的缺点和不足。

# 首先，算法复杂度较高，虽然MOACADSA 算法在多项式时间内获得近似解，但其时

# 间复杂度O(N 2 log N) 对于超大规模计算图仍可能面临性能挑战，在实际应用中可能需要

# 进一步优化。其次，模型中的多个权重参数需要根据具体应用场景进行调整，缺乏自适应

# 参数调整机制，可能影响算法的泛化能力。

# 此外，研究中的NPU 硬件模型进行了适当简化，未充分考虑实际硬件中的流水线深

# 度、内存带宽限制、能耗约束等因素，可能导致算法在实际硬件上的性能与理论预期存在

# 差距。同时，当前模型主要针对静态计算图进行优化，对于动态变化的计算图或运行时任

# 务调度的适应性不足，限制了模型在更广泛应用场景中的有效性。另外，虽然实验结果表

# 明算法在特定测试用例上表现优异，但缺乏在不同类型计算图、不同规模问题和不同硬件

# 配置上的广泛验证，算法的普适性有待进一步验证。最后，对于算法的理论性能边界缺乏

# 深入的理论分析，难以从理论上保证算法在最坏情况下的性能表现。

# 8.4 模型改进

# 以设计更高效的贪心策略或启发式方法，降低算法的时间复杂度，同时引入并行计算技术，

# 利用多核或GPU 加速算法执行，并研究增量式更新机制，避免每次调度都进行全局重新

# 计算。在自适应参数调整方面，可以设计基于机器学习的参数自动调整机制，根据计算图

# 特征动态优化参数设置，引入在线学习策略，使算法能够根据运行时反馈自动调整参数，

# 并开发参数敏感性分析工具，评估不同参数设置对算法性能的影响。在硬件模型精细化方

# 面，可以构建更精确的NPU 硬件模型，考虑流水线深度、内存带宽限制、能耗约束等因

# 素，引入硬件感知的调度策略，使算法能够更好地适应实际硬件特性，并开发硬件在环仿

# 真平台，验证算法在实际硬件环境中的性能表现。在动态适应性增强方面，可以设计支持

# 动态计算图的调度算法，能够适应运行时任务变化，引入预测机制，预判未来任务需求并

# 提前调整调度策略，并开发自适应调度框架，能够根据系统负载动态调整算法行为。在实
