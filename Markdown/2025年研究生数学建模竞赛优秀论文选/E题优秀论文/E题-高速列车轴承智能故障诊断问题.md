## 题目：高速列车轴承智能故障诊断问题

## 摘要：
轴承故障诊断在跨工况迁移场景下面临数据分布偏移、故障机理复杂、模型决策不透明等挑战。本文旨在解决源域至目标域的故障知识迁移与可信诊断问题，通过融合江南大学轴承数据集与目标域实测数据，综合运用了时频分析、Vision Transformer、 ResNet-CBAM、对抗域适应、最大均值差异、SHAP 可解释性分析等深度学习和迁移学习方法，构建了从特征提取、域对齐到可解释诊断的全流程解决方案。针对问题一（数据分析与故障特征提取），本文以江南大学轴承数据集（600 rpm）为源域，结合目标域迁移任务需求进行数据筛选与特征提取。首先，对原始振动信号下采样至32 kHz，采用滑动窗口（窗口1024、步长512）分割样本，并基于信噪比、均方根和波峰因子指标筛选高质量数据（每类362 个样本），同时保留10%低分样本以增强多样性。其次，通过时域波形、频谱包络和时频小波分析验证故障机理，定量计算轴承故障特征频率（如内圈BPFI、外圈BPFO），确保特征与物理机制一致。特征提取阶段，融合手工特征与深度特征：手工特征涵盖时域（均值、峭度等）、频域（故障能量比、频谱熵等）及时频域（谱图能量）共20 余项指标；深度特征则将信号转化为小波图，利用Vision Transformer（ViT）提取128 维高层语义特征。t-SNE 可视化显示ViT 特征轮廓系数达0.7755，各类别聚类显著，证明特征有效性。最终构建的多域融合特征集为后续故障诊断与迁移学习提供了鲁棒且判别性强的输入表示。针对问题二（源域故障诊断），本文基于任务一提取的人工设计特征与深度学习特征进行融合，通过系统对比不同分类模型在多种数据划分下的性能，旨在构建最优诊断模型。首先采用分层抽样策略，以6:4、7:3、8:2 三种比例划分训练集与测试集，确保类别分布均衡。随后，选取KNN、TCN、DenseNet 及ResNet-CBAM 四种模型进行对比实验，并以准确率、精确率、召回率和F1 分数作为核心评价指标。实验结果表明，ResNet-CBAM 模型凭借其残差结构与注意力机制，在所有划分比例下均取得最佳性能，尤其在7:3 划分时准确率高达99.8%，显著优于其他模型。混淆矩阵与t-SNE 可视化进一步证实了该模型优异的类间区分能力与特征聚类效果。最终确定ResNet-CBAM 为源域故障诊断的最优模型，其高性能也间接验证了任务一所提特征的有效性。该模型为后续迁移学习任务奠定了坚实基础。针对问题三，即利用源域带标签数据通过迁移学习对目标域16 个未知类别文件进行分类的任务，本文提出了一种结合特征对齐与无监督聚类的迁移学习框架。首先，对源域和目标域特征进行Z-score 标准化（以源域统计量避免信息泄露），并通过最大信息系数（MIC）筛选跨域共性特征，统一特征空间。模型核心采用对抗性域适应（DANN）和最大均值差异（MMD）联合优化，以ResNet-CBAM 作为特征提取器和分类器，通过对抗博弈和分布距离最小化消除域偏移，同时保留故障判别性。训练过程包括预训练、域适应迭代和目标

# 一、问题简介

## 1.1 问题背景

## 高速列车因其安全高效、便捷舒适、绿色低碳等优点，已经成为中国客运的主流运输

## 工具。轴承作为高速列车走行系统的关键旋转部件，长期处于高转速、交变载荷等复杂恶

## 劣的工况环境中，具有故障率高、易损坏等特点，是高速列车走行系统设备故障的主要源

## 头。一旦轴承发生故障，轻则导致列车延误和晚点，重则会诱发脱轨等恶性事故，危及生

## 命安全。

## 当前高铁轴承状态监测方法主要依赖于专家经验构建的特征指标或传统信号处理技

## 术实现。随着轨道交通系统向高密度、强耦合、智能化的方向快速发展，现有方法在诊断

## 精度、泛化能力和实时性方面难以满足复杂运营场景下的精准诊断需求。近年来，随着大

## 数据、人工智能技术的快速发展，数据驱动的智能故障诊断方法在列车装备运维领域受到

## 了广泛关注。基于海量运营数据构建的深度学习模型，能够实现更高精度的故障识别、更

## 强的工况适应性和更高效的实时诊断能力。然而，在实际应用场景中，受复杂运行环境与

## 多变工况的影响，传感器采集的原始振动信号易受到背景噪声、干扰源响应等诸多成分影

## 响，这不仅削弱了故障特征的显著性，也直接制约了深度学习模型的识别准确率。更关键

## 的是，为保障列车安全运营，关键设备的异常状态通常会被及时处理，导致在途列车的真

## 实故障数据极度稀缺，进而造成训练数据分布严重失衡，极大地限制了深度学习模型向工

## 程实践的转化。与实际运行数据相对的是，在台架实验环境下采集的轴承数据不仅数量丰

## 富、标签完备，而且其故障演化机理也与在途列车轴承相似。在此背景下，迁移学习技术

## 为解决上述问题提供了良好思路。

## 迁移学习技术是一种新兴机器学习方法，其核心思想是将在一个任务或领域中学到的

## 知识迁移到另一个相关但不同的任务或领域，以提升目标任务的模型性能。因此，通过解

## 析轴承故障机理对既有试验台数据展开分析，提取代表性的轴承故障特征以构建源域模

## 型，再结合迁移学习技术将诊断知识迁移至实际运营列车数据，可有效缓解样本不平衡问

## 题。轴承故障特征通常可以从时域、频域、时频域和二维图像等多个维度进行分析。

## 列车轴承的工作环境往往较为恶劣，在长时间运行过程中，轴承部件可能因过热、润

## 滑不良、腐蚀等多种因素发生损坏，进而影响列车正常运行。轴承故障诊断是指通过监测

## 轴承运行状态下的各类信号（其中振动加速度信号为主要监测数据），运用数据挖掘、信

## 号处理及机器学习等技术手段，判定轴承是否存在故障的技术。从本质上讲，基于机器学

## 习的故障诊断问题属于模式识别问题——通过信号处理等技术提取故障特征，再借助机器

## 学习模型实现精准分类，是该领域常见的实现路径。其核心目标在于实现对故障的提前预

## 警与精准诊断，从而避免设备突发性失效，为列车的安全运行提供可靠保障。

## 轴承结构主要包括内圈、外圈、滚动体和保持架四部分，其中典型故障多发生在内圈、

## 外圈和滚动体这三个核心承载部件。当轴承出现局部缺陷时，滚动体在接触并通过缺陷点

## 的瞬间，会产生突变的冲击脉冲，而在轴承周期性运转的过程中，这种脉冲力会持续作用，

## 进而形成周期性的冲击分量。在传感器采集的振动信号中，由缺陷引发的周期冲击分量呈

## 三、问题一模型建立与求解分析

## 3.1 问题一分析
问题一可划分为三个子问题，首先，由于后续要进行迁移学习，因此本文在源域选取文献[1]中的江南大学轴承数据集600 rpm 下的正常、内圈、外圈及滚动体故障数据，并将原始信号经下采样至32 kHz，这样源域与目标域数据参数更加接近，并利用滑动窗口切分样本，再基于信噪比、均方根等指标筛选，剔除噪声过大或失真片段，得到质量均衡的源域数据集。其次，结合轴承故障机理，利用时域统计、频谱及时频可视化分析验证不同类别信号的差异性。最后特征提取方面，本文采用手工特征结合深度特征策略：一方面提取均值、偏度、峭度、能量熵等物理意义明确的指标；另一方面将信号转化为64×64 小波时频图输入Vision Transformer (ViT)，提取其全连接层前的128 维深度特征。最终融合两类特征，为后续迁移诊断提供可靠的输入表示。

## 3.2 数据预处理
数据质量会对模型准确性和评估产生显著的影响。通过对江南大学轴承数据集进行数据清洗，判断是否存在明显的异常值、缺失值情况。若存在，则进行相应的剔除或填空。数据清洗以后得到四个类别分别有500500 个样本点。随后将数据下采样至32kHz 并使用滑动窗口（窗口大小设置为1024、步长为512）进行样本分割方便后续使用。设置为1024 个样本点是因为其能包含一个周期的故障信号长度，分割完以后每个类别得到624 个样本。用于后续筛选部分数据组成数据集。

# 在特征提取环节，本文同时采用手工特征与深度特征两类方法。手工特征方面，特征

# 涵盖了时域、频域和时频域多个维度，包括均值、标准差、RMS、峰值、峰峰值、偏度、

# 3.3.3.1 手工提取特征

# （1）时域特征组从信号幅值序列的直接统计计算中获取状态信息。

# 信号均值计算波形数据的算术平均值，其数值反映振动信号的直流偏移分量。

# 信号标准差通过计算各数据点与均值的偏离程度来量化信号的波动强度，其数值大小

# 直接表征振动的剧烈程度，是评估总体振动水平的基础指标。

# 均方根值采用平方求平均再开方的计算方法，其物理意义在于表征信号的平均功率水

# 平。

# 峰值检测捕获信号中的最大瞬时幅值，其对于突发性冲击事件具有高度敏感性，能够

# 有效识别轴承表面局部损伤产生的瞬时冲击力。

# 偏度系数通过三阶矩计算来评估振幅分布的不对称性，正偏度表明分布右侧存在长尾，

# 对应较大的正向冲击事件，负偏度则指示显著的负向冲击占主导地位。

# 峭度系数采用四阶矩计算来衡量分布形态的尖锐程度，其对信号中的异常脉冲分量极

# 为敏感，在轴承故障初期，微小的表面损伤即可引起峭度值的显著升高，但随着故障发展

# 冲击事件趋于频繁，峭度值反而可能出现回落现象。

# 裕度因子通过峰值与均方根值的比值来评估波峰尖锐程度，其值在故障初期因峰值增

# 大而升高，在故障严重期因均方根值增大而可能降低。

# 脉冲因子采用峰值与绝对平均值的比值，其对冲击成分的敏感性优于裕度因子。波形

# 因子通过均方根值与绝对平均值的比值来描述信号波形与理想正弦波的偏离程度。

# （2）包络域分析针对调制信号特征进行提取。

# 包络峰值检测解调信号中的最大幅值，包络均方根值计算解调信号的平均能量水平，

# 这两个指标专门用于评估故障引起的振幅调制强度。

# 频域分析则从频率结构角度提供诊断信息，频谱重心通过加权平均计算确定振动能量

# 的主要分布频带，其偏移趋势反映能量在频率轴上的迁移特性。

# 频谱带宽量化频率分布的离散程度，带宽增大通常表明故障引发了宽频带振动响应。

# 频谱熵采用信息熵理论度量频谱能量的混乱程度，频域熵值变化反映频率成分复杂性的改

# 变。

# （3）故障特征频率能量监测是轴承诊断的核心环节。

# 外圈故障特征频带能量计算轴承外圈损伤激发的特定频率成分的能量值，内圈故障特

# 征频带能量监测内圈损伤对应的频率成分，滚动体故障特征频带能量捕获滚动体损伤引起

# 的振动能量。这些能量的绝对值反映故障的绝对强度，而其与总能量的比值则消除总体振

# 动水平的影响，更能体现故障的相对严重程度。前五个频谱峰值频率记录频谱中显著波峰

# 对应的频率值，这些频率成分往往对应系统的固有特性或故障特征。

# 综上所述，本特征提取方案的设计遵循了多域联合分析的思路。时域特征快速评估总

由于人工提取特征易存在主观性、信息覆盖不全面的问题，本文提出引入故障深度特征以优化特征体系：首先采用小波变换对一维振动信号进行处理，将其转化为保留时域- 频域联合信息的二维小波图，为深度特征提取提供更丰富的空间表征；随后利用视觉 Transformer（ViT）模型对二维小波图进行特征学习，提取模型全连接层前一层的128 维深度故障特征；最后将该深度特征与手工提取的传统特征进行融合。此融合策略既保留了手工特征物理意义明确、可解释性强的优势，又通过深度特征补充了传统方法难以捕捉的隐性信息，使最终的特征集更具完整性与表征能力，为后续故障诊断提供更可靠的特征支撑。 (1)视觉Transformer（vit）模型视觉Transformer（Vision Transformer，ViT）是基于Transformer 自注意力机制提出的视觉特征提取模型，其核心优势在于打破卷积神经网络（CNN）的局部感受野限制，能够直接捕捉输入图像的全局特征关联。 ViT 的核心流程为：首先将二维视觉输入（如本文中的小波图）分割为固定尺寸的局部图像块（Patch），通过线性嵌入（Patch Embedding）将每个图像块转化为低维向量序列；随后为该序列添加位置编码（Positional Encoding），以补充图像块的空间位置信息（自注意力机制本身无位置感知能力）；最后将编码后的序列输入由多头自注意力层（Multi-Head Self-Attention）与多层感知机（MLP）组成的Encoder 模块，通过自注意力机制自适应学习不同图像块的关联权重，最终输出蕴含全局特征的深层向量。针对本文的振动故障诊断场景，ViT 可有效适配二维小波图的视觉表征形式，通过全局注意力机制挖掘小波图中时域- 频域联合的隐性故障信息（如局部冲击与宽频振动的关联特征），尤其适合提取手工特征难以覆盖的深层抽象特征，为后续特征融合与故障识别提供强表征能力的特征支撑。 (2)小波图小波图的本质是离散小波变换（Discrete Wavelet Transform, DWT）的系数可视化结果。其核心思想是：用一组可缩放、可平移的小波基函数（替代傅里叶变换的正弦/ 余弦基）与一维振动信号卷积，通过调整尺度因子（控制小波基的频率覆盖范围）和平移因子（控制小波基的时间定位），计算不同时频点的信号关联强度（即小波系数），最终将尺度- 平移- 系数幅值的三维关系转化为二维图像（小波图）。设一维振动信号为x（t）（t 为时间变量），离散小波变换通过对尺度因子a 和平移因子b 离散化，计算信号在不同时频点的小波系数Wx（j，k），公式为： j t - ka b+ 

# （3）可解释性指标

# 保真度（Fidelity）：衡量将被解释为最重要的top-k 特征去除后模型性能下降的幅度

# （例如准确率下降）。值越大说明这些被标记为重要的特征确实对模型决策贡献大，解释

# 更可信。

# 充分性（Sufficiency）：保留被认为最重要的top-k 特征时，模型仍能维持多少对正确

# 类别的预测概率（或准确率）。值越高表示这组重要特征本身就足够支持模型判断。

# 完备性（Comprehensiveness）：删除top-k 特征后真实类别概率的减少量（与原概率

# 之差），用于衡量这些特征对当前预测的必要性。值越大说明这些特征对该决策是必不可

# 少的（补充fidelity 的意义）。

# 类内解释一致性（Stability / Consistency）：计算同一类别内不同样本的解释向量（或

# 频带归因）之间的相似度（如Spearman/ cosine）的平均值。值越高说明模型对同类样本

# 给出的一致性解释越强，解释更稳定可靠。

<!-- Page 35 -->

# 稀疏度（Sparsity）：表示解释中被判为重要的特征占全部特征的比例（或1 −非零

# 比例），反映解释的简洁性。值越高表示解释更简洁、关注的特征更少，但需结合fidelity

# 以防人为稀疏化。

# TCAV score：概念激活向量（CAV）测试中，某概念对某类别产生正向影响的样本比

# 例（并常伴随p-value）。高且显著的TCAV score 表明模型确实在决策中利用了该人工定

# 义的概念。

# Layer MMD（最大均值差异）：衡量源域与目标域在某一网络层的特征分布差异（核

# 方法计算的距离）；MMD 值越小表示两个域在该层的分布越接近，表明该层的表示已实

# 现更好的域对齐/迁移。

# 七、模型的改进与推广

## 1、对于问题一中的特征提取，融合了手工特征与ViT 深度特征，既保留了物理可解

## 释性，又增强了特征表征能力，具有较强的工程推广价值；但在数据筛选阶段，信噪比、

## 均方根等指标的权重设置依赖经验，缺乏自适应优化，可能影响数据集的代表性和均衡性，

## 后续可引入强化学习或优化算法动态调整筛选策略。

## 2、对于问题二中采用的多种分类模型对比实验，虽全面验证了ResNet-CBAM 的优越

## 性，但模型超参数（如学习率、批次大小）未进行系统调优，可能未充分发挥各模型潜力；

## 此外，模型选择偏重于深度学习结构，未充分考虑轻量化模型在实时诊断场景中的应用需

## 求，可引入神经网络架构搜索（NAS）或模型剪裁技术以平衡精度与效率。

## 3、对于问题三设计的DANN+MMD 迁移学习框架，在域对齐和特征适配方面表现良

## 好，但迁移过程仅依赖于对抗训练和分布度量，未引入多源域或增量迁移策略，在面对更

## 复杂的工况变化时泛化能力可能受限；后续可探索基于元学习或联邦学习的跨域迁移机

## 制，提升模型对动态环境的适应性。

## 4、对于问题四的可解释性分析，虽从事前、迁移过程与事后多角度展开，并引入了

## SHAP、TCAV 等先进工具，但可解释性指标（如保真度、稀疏度）的阈值设定仍依赖人工

## 经验，缺乏统一标准；建议结合领域知识构建可解释性评估体系，并与实际故障机理深度

## 融合，形成可量化、可复用的解释框架。
