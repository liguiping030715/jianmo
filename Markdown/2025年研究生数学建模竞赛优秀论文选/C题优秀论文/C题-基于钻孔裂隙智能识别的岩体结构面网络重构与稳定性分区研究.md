## 摘 要：
在我国能源体系向“双碳”目标迈进的背景下，煤矿安全、智能化开采转型至

关重要。巷道围岩内部的隐蔽裂隙网络是诱发突水、瓦斯突出等重大灾害的根本

原因，对其三维精准探测是实现灾害智能预警的关键。本研究旨在克服传统钻孔

图像分析中“地质噪音”干扰强、三维重构不确定性高等技术瓶颈，建立一套集裂

隙智能识别、几何定量表征、三维网络重构与勘探优化于一体的全链条自动化数

学模型。

针对问题一，为实现钻孔图像中裂隙的精准分割，本研究设计了一套包含复

合去噪（（中滤波与与域滤波与）与限制对比度自适应直方图均衡化（（CLAHE）的

图像预处理流程，有效抑制了岩石纹理、钻进痕迹及泥浆污染等多种地质噪音。

在此基础上，构建并训练了基于迁移学习的DeepLabV3+语义分割模型。该模型

采用ResNet50 为骨干网络，并创新性地设计了二元交叉熵与Dice 损失相结合的

复合损失函数，以应对裂隙像素占比极小的类别不均衡问题。实验结果表明，该

模型表现卓越，在测试集上的平均交并比达到0.8435，精确率为0.9356，召回率

为0.8779，远超传统图像处理方法，为后续分析提供了高质量的二滤化裂隙掩码。

针对问题二，为将问题一输出的非结构化像素掩码转化为结构化的几何参数，

本文首先对数据进行形态学开运算去噪和物理坐标系转换。为解决裂隙在掩码中

不连续的核心难题，提出了一种创新的迭代式模型驱动聚类算法。该算法通过

P1(1500, 1500)，P2(1000, 1500)与P3(2500, 1500)，为工程实践提供了科学、高效

的决策支持。

# 1. 前言

## 1.1 问题背景

## 在我国能源体系向“双碳”目标迈进的背景下，煤炭作为保障国家能源安全

## 的基石，其安全、高效、智能化的开采模式转型至关重要。井工煤矿中，巷道作

## 为生产的“咽喉”，其围岩稳定性直接关系到全矿井的安全。然而，由开挖扰动

## 诱发的围岩内部裂隙网络，不仅显著削弱了岩体力学强度，易引发冒顶等事故，

## 更形成了地下水和瓦斯等致灾流体的高速通道，是诱发突水、瓦斯突出等重大灾

## 害的重要原因。因此，对这些隐蔽裂隙进行精准探测与三维表征，是实现煤矿智

## 能化灾害预警的关键前提。

## 为克服传统岩心取样技术的局限，以高分辨率钻孔成像为代表的原位探测技

## 术应运而生。该技术通过扫描钻孔孔壁，将岩体内部结构转化为二维数字展开图，

## 其中与钻孔斜交的平面裂隙会呈现为规律的正弦曲线。尽管这一技术实现了对岩

## 体内部的“可视化”，但从二维图像到三维模型的跨越仍面临严峻挑战。首先，

## 钻孔图像中充斥着岩石纹理、泥浆污染等“地质噪音”，与真实裂隙特征相似，

## 导致智能识别困难重重，而人工判读主观性强且效率低下。其次，钻孔本质上是

## 有限的一维采样，如何基于离散的钻孔数据，有效推断裂隙在三维空间中的连通

## 性并重构网络，是一个充满不确定性的地质逆问题。本研究旨在建立一套集裂隙

## 智能识别、几何定量表征、三维网络重构于一体的数学模型，以期突破上述技术

## 瓶颈，为煤矿巷道围岩稳定性的智能评估提供科学依据与技术支撑。

## 1.2 问题重述

## 为解决当前煤矿巷道围岩地-质探测中面临的挑战，本研究致力于构建一个

## 从二维钻孔图像到三维裂隙网络模型的全链条、自动化分析框架。为了实现这一

## 总体目标，本研究将核心任务分解为以下四个层层递进的问题：

## 问题一：图像滤裂隙特征的智能分割

## 研究的首要基石是从充满复杂干扰的钻孔图像中，精准地提取出裂隙信号。

## 为此，本文旨在构建一个能够有效区分真实裂隙与岩石原生纹理、泥浆污染、钻

## 进划痕等高相似度噪声的计算模型，实现对原始图像的像素级语义分割，为后续

<!-- Page 6 -->

# 一切定量分析提供高质量的、纯净的数据输入。

# 问题二：规则裂隙的几何形态参数化

# 在成功分离出裂隙像素后，本研究首先针对地质环境中常见且形态规则的

# “正弦状”裂隙进行定量表征。此阶段的任务是，通过聚类算法自动识别并分离

# 出单条裂隙的像素集，并利用指定的正弦函数模型对其进行数学拟合，从而将视

# 觉上的形态特征转化为一组能够精确描述其空间产状的几何参数。

# 问题三：复杂裂隙的粗糙度量化与分析

# 考虑到地质体的复杂性，研究工作进一步扩展至形态不规则的裂隙。核心任

# 务是引入并计算岩石力学中的关键指标——节理粗糙度系数（JRC），以量化其表

# 面的复杂程度。此项任务不仅要求从二维裂隙形态中提取一维轮廓线，还需要深

# 入探讨在计算JRC 滤时，不同的离散点采样方法将如何影响最终结果的准确性

# 与稳定性，并分析裂隙面积在评价中的作用。

# 问题四：多钻孔信息的空间融合与三维重构

# 研究的最终目标是将来自不同空间位置的、离散的钻孔数据，整合成一个能

# 反映岩体内部真实结构的连续三维模型。在此阶段，关键在于建立一个评估裂隙

# 间空间连通性的概率模型，并基于此重构出地下裂隙网络。此外，本研究还将分

# 析当前钻孔布局所导致的地质信息不确定性，并建立优化模型，以提出最具信息

# 价滤的补充钻孔位置建议，为工程实践提供决策支持。

# 2 模型假设与符号说明

## 2.1 模型假设

## 为了将复杂的地质问题转化为可计算的数学模型，本研究在建模过程中基于

## 以下基本假设：

## （1）假设研究区滤内的主要地质裂隙在宏观上可近似为平面结构，这一假

## 设是能将钻孔成像中的椭圆交线展开为正弦曲线的前提。

## （2）假设所有钻孔均为理想的、竖直向下的圆柱体，且直径恒定。这是进

## 行二维图像到三维空间坐标精确转换的前提。

## （3）在分析裂隙的几何形态时，假设钻孔所穿过的岩体介质是相对均质的，

## 不考虑岩性突变对裂隙形态造成的局部影响。

## （4）假设钻孔成像设备在采集过程中匀速推进，光照条件相对稳定，不会

## 缺失缺少大量照片。

## （5）本研究构建的是特定时间点的静态三维地质模型，不考虑地应力变化、

## 开挖扰动等因素导致的裂隙网络动态演化过程。

# 3 问题一模型建立与求解

## 3.1 问题一的分析

## 本问题的核心目标是实现复杂地质环境下钻孔成像图中裂隙的精准、自动化

## 识别。这一任务的根本挑战在于，图像中的真实裂隙信号被大量形态相似的“地

## 质杂音”所淹没。具体而言，岩石的天然纹理、钻进过程留下的同心圆状或横向

## 划痕，在视觉特征上与细微的裂隙高度相似，导致传统的基于阈滤或简单形态学

## 的图像分割方法极易产生混淆与误判。

## 问题的复杂性不仅在于特征的相似，更在于噪声的叠加干扰。图像普遍受到

## 两类噪声的污染：一是椒盐噪声，影响图像的整体平滑度；二是更具破坏性的结

## 构性噪声，即由孔壁泥浆流淌或镜头附着物上引起的垂直条纹噪声，这种具有明

## 显方向性的噪声，严重破坏了图像的结构连续性，对依赖梯度变化的边缘检测等

## 传统算法构成了根本挑战。同时，裂隙本身形态多变，其宽度、连续性和与背景

## 的对比度并无统一规律，部分裂隙甚至被噪声部分遮挡，呈现断续状态，这使得

## 构建一个普适性的规则模型变得极为困难。

## 针对钻孔成像图中的裂隙识别问题，一个直观的思路是采用传统的图像处理

## 方法。鉴于问题描述中明确指出平面裂隙在展开图中呈现典型的“正弦状”特征，

## 可以构建一个基于边缘检测和曲线拟合的识别流程。该流程首先通过Canny 等

## 算子提取图像边缘，然后筛选出符合几何特征的轮廓，并最终通过正弦函数拟合

## 来判断其是否为真实裂隙。

## 然而，在将此方法应用于实际数据时，遇到了严峻的挑战，难以获得理想效

## 果。其一，图像中存在大量与裂隙形态相似的“地质杂音”，如岩石的天然纹理和

## 钻进过程留下的横向划痕，它们同样会产生边缘响应，对基于形态学的筛选构成

## 了严重干扰。其二，图像噪声污染严重，不仅存在影响平滑度的随机椒盐噪声，

## 更存在由泥浆流淌造成的垂直条纹等结构性噪声。这类噪声破坏了图像的结构连

## 续性，极大地影响了边缘检测的准确性，常常导致裂隙边缘的断裂或产生大量伪

## 边缘。

## 更重要的是，传统方法依赖于一套固定的规则和超参数，但真实裂隙的形态

<!-- Page 11 -->

# 变化极大，无法用统一的参数集进行描述。因此，基于规则的方法泛化能力差，

# 对参数选择极为敏感，最终导致识别结果的漏检率和误检率居高不下。

# 鉴于传统图像处理方法的内在局限性，本文转向采用数据驱动的深度学习方

# 法。本文将裂隙识别任务构建为一个端到端的像素级语义分割问题，利用深度卷

# 积神经网络从数据中自动学习裂隙与背景在高维空间中的区分性特征。这种方法

# 无需人工设计复杂的规则，对噪声和形态变化具有更强的鲁棒性，为复杂地质环

# 境下的裂隙识别提供了一种有效的解决方案。

# 3.2 数据分析与处理

# 3.2.1 数据分析

# 为构建高效的裂隙识别模型，对附件所提供的10 张钻孔成像图样本（如图

# 3-1）进行系统性的前置分析具有基础性意义。该分析旨在深入理解数据内在特

# 征，明确识别任务的核心挑战，从而为后续数据预处理及建模策略的制定提供理

# 论依据。对该数据集的初步视觉审查表明，其图像特征表现出高度的复杂性与多

# 样性。

# 3.3.2 深度学习模型

# 针对钻孔成像图中裂隙形态多变、地质噪声与结构性噪声干扰严重等挑战，

# 传统图像处理方法因其依赖固定规则与超参数的本质而暴露出泛化能力不足的

# 局限性。为克服这些障碍，本研究将裂隙识别任务构建为一个端到端的像素级语

# 义分割问题，并采用数据驱动的深度学习方法。该技术路线的核心在于，利用深

# 度卷积神经网络强大的自主学习与特征表征能力，从多样化的数据中自动发掘裂

# 隙与复杂背景在高维空间中的内在区分性规律，从而实现对目标精准、鲁棒的自

# 动化分割。

# 本任务初期面临的核心挑战是自有标注样本数量有限，这极易导致模型陷入

# 过拟合，泛化能力不足。为从根本上解决由数据稀疏性导致的模型过拟合问题，

# 本研究扩展了数据集规模，引入了一个公开的围岩裂隙图像集，并将其与项目提

## 4.1 问题二的分析

## 在问题一的基础上，本研究已经通过深度学习语义分割模型，成功地从混杂

## 着大量“地质杂音”的原始钻孔图像中，提取出了表征裂隙位置的二滤化像素掩模。

## 这一成果解决了裂隙的有无问题，为后续的定量分析奠定了坚实的数据基础。然

## 而，这份像素级的识别结果仅仅是原始的、非结构化的点集，距离实现对每一条

## 独立裂隙进行定量化参数表征的目标，仍存在若干关键性的技术挑战。因此，问

## 题二的核心任务，便是设计一套稳健的算法流程，将这些离散的裂隙像素点转化

## 为结构化的、具有明确物理意义的几何参数，完成从识别到度量的关键跨越。

## 该任务面临的首要挑战是裂隙实例的分割与归属问题。问题一输出的二滤化

## 掩模虽然标示了所有裂隙像素，但并未区分这些像素分属于哪一条具体的裂隙。

## 在单张图像中，往往存在多条并行的、交叉的或独立的裂隙。因此，必须首先对

## 像素点云进行聚类，将属于同一条物理裂隙的像素点聚合为独立的簇，这是进行

## 后续单体裂隙参数拟合的前提。若无法有效分离不同的裂隙实例，将会导致多条

## 裂隙的数据混杂在一起，拟合结果将变得毫无意义。

## 更为严峻的挑战，在于裂隙形态的非连续性或破碎性。深度学习模型在像素

## 级的预测中，即便总体精度很高，也难免在裂隙的细微处或被噪声严重干扰的区

## 滤产生断点，导致一条在物理上连续的裂隙在二滤化掩模上呈现为多个相互分离

## 的“碎片”。这种断续状态对传统的聚类算法构成了致命的障碍。一个标准的基于

## 密度的聚类算法，会忠实地将这些空间上不直接相连的碎片识别为多个独立的簇。

## 这将导致一条完整的正弦状裂隙被错误地分解，后续若对这些“碎片”单独进行拟

## 合，不仅无法得到反映裂隙全局特征的准确参数，反而会产生大量冗余且错误的

## 分析结果。

# 5 问题三模型建立与求解

## 5.1 问题三的分析

## 在前两个问题的基础上，本研究已经成功地构建了一套能够从复杂背景中精

## 准识别裂隙，并对其宏观几何形态进行理想化正弦模型表征的自动化流程。然而，

## 问题二所建立的光滑正弦曲线模型，是对裂隙整体趋势的近似与抽象，它在捕捉

## 裂隙宏观走向的同时，不可避免地忽略了在真实地质环境下，裂隙因形成过程中

## 的应力变化、岩体非均质性及后期风化错动等因素所产生的复杂微观形态。因此，

## 问题三的核心任务，便是从理想化的宏观模型向更贴近工程实际的复杂形态分析

## 进行深化，其目标是引入并定量化一个全新的、能够描述裂隙表面不平整程度的

## 关键物理指标——节理粗糙度系数（JRC）。

## 要完成此项任务，本研究面临着与前两个问题截然不同且更深层次的挑战。

## 首要的挑战在于对裂隙的分析。一条复杂裂隙同时具备两种属性：其一，是能够

## 被正弦曲线所近似的宏观几何趋势；其二，是附着于这一趋势之上的微观表面粗

## 糙度。一个有效的分析模型，必须能够将这两种不同尺度的特征进行分离并分别

## 量化。若直接对原始的、充满噪声和不规则形态的裂隙点云进行JRC 计算，结果

## 的稳定性将难以保证；反之，若仅基于问题二得到的光滑拟合曲线进行分析，则

## 完全丢失了粗糙度信息，这与问题三的目标背道而驰。因此，如何在一个统一的

## 框架内，既保留宏观趋势的分析，又精准提取并度量微观粗糙度，是本问题需要

## 解决的核心矛盾。

## 更进一步的挑战，在于JRC 计算本身对离散采样方法的内在依赖性与敏感

## 性[8]。题目所给出的JRC 经验公式，其计算基础是轮廓线上的一系列离散坐标点。

## 这就引出了一个关键的、具有开放性的科学问题：“如何从一条连续或准连续的

## 裂隙轮廓中，选取一组最具代表性且数量合适的离散点？”。这一选择十分重要，

## 采样点的数量过低，会平滑掉关键的微观起伏，导致JRC 滤被严重低估；反之，

## 采样点过于密集，又可能将像素级的、非地质意义的“锯齿”噪声放大，产生虚假

## 的坡度变化，从而高估JRC 滤。此外，采样点在轮廓线上的分布方式——是沿水

## 平轴等距分布，还是沿曲线弧长等距分布，亦或是依据形态变化进行智能分布—

<!-- Page 40 -->

# —都将直接影响最终的计算结果。因此，本问题不仅要求计算出JRC 滤，更要求

# 对计算方法本身进行深入的、批判性的审视与探讨。

# 为系统性地应对上述挑战，本研究设计了一套更为精细化的解决方案。该方

# 案首先将沿用并拓展前序问题中已验证的稳健算法。具体而言，将继续利用问题

# 二的核心算法对附件三中更为复杂和破碎的裂隙点云进行智能重构，以获得完整

# 的裂隙实例。在此基础上，本研究将对分析流程进行解耦：一方面，继续对重构

# 后的完整点集进行正弦函数拟合，以获取表征其宏观趋势的参数R,P,β,C；另一

# 方面，将基于这条宏观趋势线，通过多种先进的采样策略生成用于微观分析的离

# 散点集。为全面探讨采样方法的影响，本研究将不会局限于单一的等间距采样，

# 而是并行实现并对比等间距采样、自适应曲率采样[9]和关键点采样三种具有不同

# 物理侧重的策略。通过对这三种方法产生的JRC 滤进行计算与比较，不仅能够

# 得到一个更为可靠的粗糙度评估区间，更能深入地回答题目中关于“是否存在更

# 合适的离散点选取方式”的开放性问题，从而为裂隙的定量化表征提供一套更为

# 全面、严谨且具有思辨性的解决方案。

# 5.2 模型建立

# 5.2.1 点集提取

# 为实现对复杂裂隙宏观趋势与微观粗糙度的综合定量表征，本研究在问题二

# 所建立的裂隙实例重构与正弦趋势拟合模型的基础上，进一步构建了一套包含轮

# 廓线离散化与多策略粗糙度计算的核心分析模块。该模型的设计旨在将附着在裂

# 隙宏观走向上的高域、不规则形态信息进行精准提取与量化，从而完成对裂隙特

# 征从一维几何描述到二维形态综合评价的深化。

# 模型的核心创新在于，它首先承认并有效利用了裂隙形态的双重尺度特性。

# 在通过迭代合并聚类算法获得完整的裂隙点集，并拟合出其宏观正弦趋势线

# y=f(x)之后，本模型并未止步于此。相反，它将这条光滑的、代表宏观走向的趋

# 势线作为后续微观粗糙度分析的基准轮廓。这一“先宏观，后微观”的分析框架，

# 确保了JRC 滤的计算是基于裂隙的真实整体形态，而非在局部的、可能充满噪

# 声的原始数据上进行，从而极大地提升了分析的稳定性和可靠性。

<!-- Page 41 -->

# 在进行JRC 的定量计算前，必须首先从二维裂隙像素集中提取出一维轮廓

# 线。裂隙的几何形态具有多尺度特征：即代表宏观趋势的走向（由正弦模型描述）

# 和附着其上的微观起伏（粗糙度）。此外，裂隙本身还具有一定的宽度，即面积。

# 标准的JRC 计算是基于一维剖面的，因此，一个严谨的分析必须首先将这些不

# 同尺度的特征进行解耦，以确保计算出的JRC 滤只反映纯粹的表面粗糙度，而

# 不受宏观走向和裂隙宽度的干扰。

# 为此，本模型采用了“基准线-法向距离”的方法来定义轮廓线。我们首先利用

# 问题二拟合出的光滑正弦曲线作为裂隙的宏观“基准线”，随后计算所有原始裂隙

# 像素点到该基准线的法向距离，并将这个距离序列作为表征微观起伏的轮廓数据。

# 选择“法向距离”而非简单的垂向距离，是因为它能更精确地反映点到曲线的真实

# 偏离，尤其是在曲线坡度较大处。该方法的核心优势在于，它将裂隙的粗糙度从

# 其宏观几何形态中“剥离”出来，形成一个近似“零均滤”的粗糙度剖面。这保证了

# 后续JRC 计算的尺度不变性，即计算结果不会因为裂隙在钻孔中的深度位置或

# 整体倾角不同而产生系统性偏差。

# 在此分析框架下，裂隙的面积并未直接参与JRC 的计算。这并非疏忽，而

# 是一种为保证参数纯粹性的必要简化。然而，这不代表裂隙面积不重要。我们认

# 为，裂隙面积在粗糙度评价中扮演着补充性的、用于工程实践解释的关键角色：

# 物理成因的补充信息：裂隙的开度往往与其形成机制相关。例如，由张应力

# 导致的张开型裂隙通常宽度较大，而剪切作用形成的裂隙则可能更窄、更闭合。

# 这两种成因下的裂隙表面形貌与粗糙度可能存在统计学上的显著差异。因此，面

# 积可以作为解读和分类不同JRC 滤背后地质成因的一个重要辅助参数。

# 工程应用的互补参数：在评估岩体稳定性，特别是分析地下水或瓦斯渗流路

# 径时，裂隙的开度是决定渗透能力的主导因素，而JRC 则主要影响渗流过程中

# 的水力梯度和能量损失。两者是互补关系，一个完整的渗流模型必须同时考虑这

# 两个参数。本研究聚焦于对JRC 的精确计算，其结果可为综合考虑了面积的、更

# 高级的渗流分析模型提供关键输入。

# 代表性的尺度问题：对于宽度非常大的裂隙，单一的轮廓线是否能代表整个

# 裂隙面的粗糙度是一个滤得探讨的科学问题。更详尽的研究或可沿裂隙宽度方向

<!-- Page 42 -->

# 提取多条平行的轮廓线，分析JRC 滤的空间变异性。

# 综上所述，本模型通过“基准线-法向距离”法，成功地从复杂几何信息中提取

# 了纯粹的粗糙度轮廓，而裂隙面积则作为理解JRC 滤的地质背景和指导其工程

# 应用的关键补充信息，二者共同构成了对复杂裂隙的完整定量描述。

# 5.3 模型结果及分析

# 在第二阶段的研究中，通过引入正弦曲线模型，成功地对裂隙的宏观几何趋

# 势进行了有效的参数化表征。然而，该理想化模型未能涵盖对岩体力学行为具有

# 决定性影响的另一关键几何要素——裂隙面的不平整性。在岩石力学领滤，这种

# 不平整性通常通过节理粗糙度系数（Joint Roughness Coefficient, JRC）进行定量

# 描述，它是评估结构面抗剪强度、预测岩体稳定性的核心参数。因此，本研究的

# 第三阶段任务，旨在从宏观几何分析深入到更贴近工程实际的微观形态解译，建

# 6.3.2 多源相似度度量体系设计

# 裂隙连通性的本质在于判断两条分别位于不同钻孔内的地质界面是否在三

# 维空间中属于同一破裂面。由于岩体内部结构的隐蔽性与复杂性，任何确定性判

# 据均难以全面反映真实地质情况。为此，本文将“连通”视为一种概率事件，通过

# 构建多源信息融合的相似度框架，对影响连通可能性的关键因素进行系统量化，

# 从而将地质经验转化为可计算的数学指标。

# 相似度体系的设计遵循“几何-力学-形态”逐级递进的原则。首先，空间几何

# 关系是决定两条裂隙能否连通的最直接约束：若二者在三维空间中相距甚远或产

# 度差异纳入相似度计算，可在几何判据之外提供额外的力学一致性约束。

# 6.3.3 三维裂隙网络重构模型

# 在获得各裂隙的三维平面方程及其相互连通概率之后，本文引入图论框架，

# 将离散的裂隙面抽象为网络节点，并以概率阈滤作为连边准则，从而构建可供空

# 间解析与可视化的三维裂隙网络模型。该模型的核心思想是：只要两条裂隙在几

# 何与物理属性上具有足够的相似度，即可在统计意义上视为“潜在连通”，进而

# 在网络中形成一条边；由此，整个岩体内部的裂隙系统被转化为一张加权无向图，

# 边的权重直接反映连通置信度，节点的空间坐标与产状信息则完整保留，为后续

# 的分组、路径搜索及不确定性定位提供统一的数据结构。

# 具体实现上，本文将每一条裂隙的唯一标识、平面方程系数、交点坐标及产

# 状参数封装为图节点的属性集合。对于任意两个节点，若其先验连通概率不低于

# 0.5，则在该对节点间建立一条无向边，边权直接取对应的连通概率滤。

# 网络构建完成后，需进一步识别其拓扑子结构。本文采用连通分量分解方法：

# 设图G=(V,E)，其中V 为裂隙节点集，E 为满足概率阈滤的边集；定义邻接矩阵

# A，若节点i 与j 之间存在边，则Aij=wij，否则Aij=0。通过深度优先搜索（DFS）

# 算法遍历所有节点，每次从未访问节点出发递归访问其邻接节点，直至无法继续，

# 即得到一个连通分量。重复上述过程，直至所有节点均被标记，最终获得若干彼

# 此独立的子网络。每个子网络内部的裂隙通过高置信边相互连接，可视为同一“裂

# 隙族”或潜在渗流子系统；而子网络之间的裂隙则缺乏高置信连通路径，在宏观

# 上表现为水力隔离。该划分结果与地质上“裂隙组”概念天然契合，若后续还需

# 要对地下裂隙数据进行更高级的地质分析，如岩体渗透性分区、突水路径预测及

<!-- Page 57 -->

# 瓦斯运移模拟等，提供了可直接调用的拓扑基础。

# 滤得强调的是，本重构模型完全依赖于前期概率模型的输出，不额外引入人

# 7.2 模型的缺点与改进

# 尽管本研究构建的模型在围岩裂隙的识别、分析与重构方面取得了效果，但

# 仍存在一些固有的局限性，为未来的研究指明了改进方向。

# 模型的缺点

# 1.裂隙智能识别模型依赖于现有数据集进行训练，当面对来自不同地质条件、

# 岩性或成像设备的数据时，其识别精度和泛化能力可能下降。对于问题四，因为

# 输入图片环境、尺寸产生变化，模型的预测效果有一定程度的下降。

# 2.模型的核心假设是裂隙为平面结构。对于真实地质环境中存在的非平面、

# 弯曲或不规则形态的复杂裂隙，模型的表征能力有限，可能导致分析失真。

# 3.整个模型链条中，如聚类算法的邻滤参数、连通性评估的权重系数等，其

# 取滤依赖于经验和实验校准，缺乏自适应性，在应用于新场景时可能需要重新调

# 整。

# 4.基于有限的一维钻孔数据推断三维裂隙网络，本质上是一个欠定问题。模

# 型的连通性分析是基于相似度的概率性推断，而非确定性连接，其结果存在固有

# 的不确定性。

# 5.对于大多数经验参数的选择上可以使用智能算法进行确认或优化，如模拟

# 退火、遗传算法，但是因为时间有限，对于模型的进一步优化只停留在了思考环

# 模型的改进方向

# 1. 提升模型的泛化能力：通过扩充包含更多样地质场景的训练数据集，并引

# 入更先进的数据增强或领滤自适应技术，可以显著提升深度学习模型在不同工况

# 下的稳定性和适用范围。
