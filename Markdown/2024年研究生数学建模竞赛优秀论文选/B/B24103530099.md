## 题 目：   __基于特征对齐与多重预测驱动的WLAN 信号预测方案__

## 摘 要：
无线局域网基于IEEE802.11 标准不断发展演变，然而在高密度部署场景下信号干扰、碰撞等问题显著导致实际部署带宽和数据传输速率大幅下降，针对此类现象，本文综合运用自适应器、随机森林、GBDT、虚拟变量、DBSCAN 算法、CNN 系列等理论和方法，建立分频预测模型，预测AP 发送数据帧序列的总时长、MCS,NSS 以及网络吞吐量等信息，从而对WLAN 进行优化。针对问题一，本题要求分析各参数对AP 发送机会的影响，给出影响性强弱的顺序，对AP 发送机会进行预测。本文首先通过目标编码与虚拟变量的方式将特征转换为数值形式，采用DBSCAN 聚类算法将同步传输和异步传输按照高低密度不同的聚类区域进行区分，同时引入一个扰动机制以控制随机性，接着分别构建基于随机森林、GBDT 的预测模型，比较二者在训练集上性能指标MSE 和拟合优度，进而确定模型的应用，最后依据模型输出的特征重要性评分，按影响力大小对seq_time 的因素进行排序，并使用拟合好的随机森林模型对测试集上AP 发送数据帧序列总时长进行了预测。针对问题二，本题要求对测试中AP 发送数据选用最多次数MCS（调制编码方案）,N SS（空间流数），并通过测试集预测MCS,NSS。本文首先将标签NSS和MCS进行融合，形成一个新的复合标签，减少模型训练时的复杂性，同时考虑到编码数字大小会对模型的输入产生影响，继而采用独热编码的方式消除该影响，确保每个类别特征都以独立且平等的方式呈现给模型。接着构建新特征SINR（信号与干扰加噪声比），采用截断操作使训练集中两个数据集长度保持一致，并用过采样的方法丰富样本量，根据同步传输和异步传输类型的不同分别采取不同的方法来计算，并对两个类型的SINR 分别取平均值得到最终标签，最后分别输入到BP 神经网络和卷积神经网络（CNN）中加以训练，选用预测效果更好的模型加以预测。针对问题三，本文首先结合题目中所给出的相关信息，吞吐量的计算中仅MSDU 的总字节数属于有效传输数据，但是AMSDU 和AMPDU 聚合的准确评估对吞吐量预测也有影响，由此可以明显判断AMSDU 和AMPDU 聚合的准确评估会影响num_ppdu 和ppdu _dur (s)，通过观察数据集中pkt_len 代表的列的意思为数据报文的长度数值相同，即说明

# 一、前言

# 1.1 问题背景

# 无线局域网（WLAN）是一种利用无线通信技术构建的计算机网络，允许设备在一

# 定范围内进行无线连接和通信，其技术背景源于人们对移动性和网络灵活性的需求。基

# 于IEEE 802.11 系列标准，WLAN 不断演进，从最初的802.11b、802.11g 到Wi-Fi 4（802.

# 11n）、Wi-Fi 5（802.11ac），再到最新的Wi-Fi 6（802.11ax）和即将到来的Wi-Fi 7（802.

# 11be），提供了更高的带宽、更低的延迟和更好的用户体验。这些标准的升级满足了从语

# 音、邮件到网页、视频以及虚拟现实/增强现实等日益复杂的业务需求。

# 然而，随着WLAN 在家庭、办公、教育、医疗、工业制造和仓储等场景的广泛部署，

# 高密度环境下的节点密集度增加，导致相邻小区覆盖范围重叠，引发干扰和碰撞问题，

# 实际带宽和数据传输速率大幅下降，系统吞吐量受到限制，需要进一步优化。安全性方

# 面，WLAN 采用了从WEP、WPA 到WPA2 和WPA3 的加密协议，提升了数据传输的安全

# 性，但仍需警惕未经授权的接入、中间人攻击等安全威胁。

# 提升无线局域网（WLAN）性能的关键在于对网络吞吐量进行精确预测。吞吐量代

# 表了节点在单位时间内成功传输的数据量，是衡量网络效率的重要指标，快速而准确地

# 预测吞吐量，有助于设计出更加稳健、高效的WLAN 系统。近年来，研究人员尝试利用

# 机器学习技术，通过提取诸如信道条件、带宽配置、流量特征、发射功率、接入控制机

# 制等基本信息，以及节点之间的接收信号强度（RSSI）、信号干扰噪声比（SINR）、传

# 输时延等架构信息，来构建模型预测网络吞吐量。然而，在实际应用中，WLAN 的通信

# 行为受到信道环境和干扰的快速变化，以及复杂多样的业务流量影响，导致仿真模型与

# 真实情况存在差异。因此，单纯依赖仿真数据训练的模型难以满足商业应用的需求，需

# 要开发能够适应实时变化的预测方法，以进一步优化WLAN 系统的性能。

# 因此，为了满足用户对高速无线通信的需求，需要在结合实际部署情况的基础上，

# 对WLAN 系统进行进一步的优化，包括改进技术标准、加强安全措施和优化网络架构，

# 以提升系统的吞吐量和整体性能。

# 1.2 问题研究现状

# 有关WLAN 吞吐量影响因素的探索，国内外早已有不少学者展开了研究。在国外学

# 者中，Nazabal 等人[1]认为室内场景中元件的布局和组成在无线传感器网络和系统中使用

# 的传播信道损耗方面起着关键作用，为此他们开发了一种基于 3D 射线发射的内部确定性

# 代码，以分析室内拓扑和形态在两种不同的现实场景中对无线链路运行的影响；Radhakri

# shna K S 等人[2]通过分析WLAN 在 5240 MHz 和移动网络在 2100 MHz 下的接收功率（dB

# m）和自由空间路径损耗（FSPL），认为随着距离的增加，FSPL 的值增加，这会导致接

# 收的功率减少，障碍物越密集，信号衰减越多；Qureshi I A 等人[3]对标准IEEE802.11 论文

# 4.3.1 数据处理

# 在无线局域网（WLAN）中，RSSI 是影响节点间通信的重要参数。根据题目中所给

# 的信息结合IEEE 802.11 系列标准，当两个节点之间的 RSSI > ED 时，一个节点可以检测

# 到另一个节点的数据传输。这种情况下，两个节点可以“听到”彼此，表示它们能够侦听到

# 对方正在传输数据。本团队不考虑偶然同时回退到0 时，多AP 同时开始数据传输极小的

# 概率。当RSSI 值在PD 和ED 之间时，由于包长的差异较大，导致在CCA 机制中错过对

# 方Preamble 的情况从而判定信道为空闲，导致异步传输，但是在此区间中发生异步传输

# 和同步传输的概率未知。当RSSI 值小于PD 时，则说明该信号非常弱，可能来自于一个

# 较远的节点或者干扰源，此时节点会判断信道是空闲的，会导致产生异步传输。

# 由于无法判断RSSI 值在PD 和ED 之间时的传输方式，本团队通过查阅相关文献，决

# 定使用DBSCAN 来进行传输方式的划分，将RSSI 值进行DBSCAN 聚类，在高密度的聚

# 类区域代表同步传输，因为在高密度聚类区域中节点之间的信号强度相对较强且较为稳

# 定；低密度的区域代表了异步传输，反映了节点间信号较弱或不稳定的传输状态。同时

# 我们还考虑到这部分同步传输和异步传输的判断取决于随机回退的随机性，然而，这一

# 机制也带来了不可预测的随机性，尤其是在信号强度接近 PD 和 ED 的临界情况下。节点

# 在回退到 0 时可能会同时开始传输，或者因错过其他节点的 Preamble（前导信号）而错误

# 地判断信道为空闲，导致同步和异步传输的混合发生。

# 为了更好地应对这种随机性，我们在 DBSCAN 聚类分类之后，加入了一个 扰动机制。

# 该扰动机制通过随机翻转一部分分类结果，模拟无线传输中的不确定性和随机性。具体

# 来说，在高密度区域（DBSCAN 聚类识别为同步传输）和低密度区域（识别为异步传输）

# 之间，加入随机扰动能够更真实地反映实际网络中由于随机回退和干扰导致的传输方式

# 不稳定性。

# 通过这种方式，我们不仅通过 DBSCAN 聚类模型区分了不同密度的传输方式，还进

# 一步引入了随机扰动，增强了模型对实际网络环境中随机性和不确定性的鲁棒性。该方

# 法可以更精确地模拟 WLAN 中复杂的传输模式，尤其是在多节点环境中，信道竞争激烈

# 时的情况。

## 5.2.3 过采样

## 过采样是一种处理不平衡数据集的技术，特别适用于分类问题中少数类样本数量远

## 少于多数类的情况。通过增加少数类样本的数量，过采样旨在平衡不同类别之间的样本

## 数，从而改善模型对少数类的识别能力。

## 常见的过采样方法包括随机过采样，即简单地复制少数类中的样本直到达到平衡；

## 合成少数类过采样技术（SMOTE），它不是简单复制现有样本，而是基于少数类样本生

## 成新的合成样本，以减少过拟合的风险并帮助模型更好地理解少数类分布；边界线SMOT

## E 专注于那些位于决策边界附近的少数类样本，通过合成更多这类样本来提高决策边界的

## 准确性；ADASYN 则是一种自适应的合成抽样方法，根据少数类样本周围的密度来生成

## 新样本，倾向于为难以学习的区域生成更多样本；聚类后过采样则是先通过聚类算法将

## 少数类样本分成几个簇，然后分别对每个簇进行过采样，以保留数据的内部结构。

## 使用过采样时需要注意其可能带来的过拟合风险，因为过多复制相同的样本可能导

## 致模型在训练数据上表现良好但在未见数据上的泛化能力较差；此外，生成的新样本会

## 增加数据集大小，这可能会增加训练时间和计算资源的需求。因此，在应用过采样时应

## 结合适当的评估策略，如考虑使用精确度、召回率、F1分数或AUC-ROC曲线等指标，以

## 确保模型的有效性和泛化能力。

# 络和BP 神经网络进行对比分析，由于卷积神经网络（CNN）则在局部特征提取、参数共

# 享、降维能力表现良好，以及在训练集上的数据表现，选择卷积神经网络作为我们的模

# 型进行预测。

# 经网络（ResNet）结合的方式来预测WLAN 的吞吐量。深度残差神经网络（ResNet）通

# 过引入残差块解决了深层网络梯度消失/爆炸的问题，使得网络可以更深，从而提高模型

# 的表达能力，有更好的拟合效果，而随机森林在问题一中对于本文中初步的特征处理有

# 良好的表现，两者交叉结合对于模型的预测有更好的效果。

# 7.2 模型的缺点

# （1）随机森林模型可以通过多棵树捕捉部分特征交互，但是如果特征间存在复杂的

# 非线性交互关系，随机森林模型可能无法处理和捕捉。

# （2）卷积神经网络（CNN）的效果高度依赖于输入数据的质量，如果数据存在噪声

# 或不一致性，可能会严重影响模型性能。

# （3）深度残差神经网络（ResNet）一般需要较大的计算资源，特别是在处理大规模

# 数据集时。

# （4）采用的双层交叉预测模型由于结构的复杂性，其计算效率会相对低一些。
