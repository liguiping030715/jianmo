# P2 2024 C 题横向比较：磁芯损耗建模

## 四篇方法谱系
| 队号 | Q1波形分类 | Q2温度修正 | Q3最优工况 |
|---|---|---|---|
| 江苏科大 | MLP+RF+加权集成 | Solow函数 SE修正 R²=0.995 | ANOVA p值+穷举 |
| 福州大 | 8统计+11几何+投票 | 6种假设枚举 R²=0.986 | 对数变换后分层抽样 |
| 山东大学 | FFT+PCA SVM 100% | 5种修正+动态PSO R²=0.995 | 热力图交互 |
| 西南交大 | 阶跃阈值→SVM 100%+抗噪 | LSE对数线性化→LSEDSR R²=0.13 | ANOVA+非参数检验 |

## 共性范式
1. **经典SE方程不推翻，乘温度修正因子**（Solow/二次/指数/幂级数），最小二乘拟合。
2. 波形分类全是"手工特征+树模型/集成"，没人纯深度学习。
3. 找最优工况 = ANOVA证显著 + 穷举/热力图。

## 高价值技巧
- **主动加噪测抗噪性**（西南交大）：干净数据100%不算数，加噪掉点再补特征域。
- **对数线性化**（西南交大）：非线性物理方程取对数变线性结构。
- **多假设枚举**（福州大）：修正形式别只试一种，枚举线性/对数/指数让数据选。
- **ANOVA前提检验**（福州大）：先检查正态/方差齐，不满足就对数变换。

## 给2026新题的迁移建议
- 物理方程不准 → 乘修正因子，别推倒重建。
- 分类模型要做抗噪鲁棒性测试。
- ANOVA前检查假设，多因素用热力图看交互。
