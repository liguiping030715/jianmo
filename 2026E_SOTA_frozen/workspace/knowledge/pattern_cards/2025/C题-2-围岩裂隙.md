# Card: 2025C-2 围岩裂隙精准识别与三维模型重构（多特征Canny+GMM+NN拟合）

## 0. 元数据
- 年份/题号：2025 C 题
- 学校：未在摘要标注

## 1. 问题指纹
- 同 C 题。特色：**传统方法三方案对打 + 神经网络做正弦参数回归**。

## 2. 信息流
```
Q1: 数据增强+光照矫正+非局部均值 → 三方案(K-Means+Canny融合/Canny单法/YOLOv8) → 选Canny
Q2: Canny边缘 → 空间接近+方向一致+GMM聚类 → 中心线 → 梯度下降-牛顿融合+NN回归振幅R/残差P
Q3: 轮廓离散化 → 等间距JRC → 曲率-紧凑度加权自适应采样 → 二阶导数改进JRC
Q4: 正弦参数 → 反演3D产状(倾角/倾向) → 平面方程+空间距离贴合度
```

## 3. 分问拆解
- Q1：数据增强防小样本过拟合；三方案对打后选**多特征融合的Canny**（比YOLOv8在本数据上更稳）。
- Q2：GMM聚类比DBSCAN更依赖方向一致性；**梯度下降-牛顿融合+神经网络**两套参数回归对比，NN更准。
- Q3：发现**一阶导数对线性趋势敏感**→ 用二阶导数改进JRC；曲率-紧凑度加权自适应采样。
- Q4：从二维正弦参数反演三维裂隙平面的倾角/倾向。

## 6. 可迁移 Pattern
> **"图像分割别默认上深度模型：传统方法(Canny/聚类)+后处理在小样本上可能比YOLO更稳，必须三方案对打"；"曲线参数拟合：传统最小二乘 vs 神经网络回归对比，后者可作非线性备选"；"粗糙度类指标对导数敏感 → 用二阶导数/多尺度残差改进，避免单参数模型"。**

## 7. 局限
- NN拟合需训练数据，小样本风险；
- 方向一致性准则需手动阈值。
