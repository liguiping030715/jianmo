# Card: 2025B-MIMO建模研究（EESM+7横向对比+无监督对齐）

## 0. 元数据
- 年份/题号：2025 B 题（MIMO-OFDM链路速率）
- 学校：未在摘要标注

## 1. 问题指纹
- 表面任务：关TxBF拟合EESM基线 → 改进聚合方法 → 开TxBF场景扩展。
- 真实困难：**122个子载波的频率选择性如何压成一个等效SNR**；开/关TxBF是两个不同数据域，存在分布偏移。
- 题型标签：物理层抽象 + 多模型横向对比 + 跨域对齐。

## 2. 信息流
```
Q1: CSI矩阵 → Frobenius范数→子载波SNR → EESM指数聚合(β) → 对数单调映射速率
Q2: 7个变体(E1基线/E2噪声标定/E3 MMSE/E4 MIESM/E5 LogSumExp/E6分位数+单调/E7混合)
Q3: SVD取主奇异值 → MIESM/EESM → 无监督分布对齐DA/DAiqr → TxBF速率
```

## 3. 分问拆解
- Q1：Frobenius范数算信道功率+噪声底噪得子载波SNR；**EESM聚合：β小→趋近min(最差子载波主导)，β大→趋近mean**，可调折中；外层香农式单调回归；RMSE=61.2、Spearman=0.78。
- Q2：**系统设计7个横向变体对比**——噪声标定、MMSE自适应γ、MIESM互信息聚合、温度LogSumExp、分位数特征(p10/25/50/75/90)+单调回归、混合；MIESM RMSE降8%，Spearman升到0.82。
- Q3：TxBF下先**SVD分解取主奇异值通道**；用**中位数+四分位距的无监督分布对齐**修正关/开TxBF的分布偏移（对齐前预测228偏低，对齐后311）。

## 6. 可迁移 Pattern
> **"多子载波/多通道聚合问题：EESM类指数聚合，参数β在'最差主导'和'平均'之间调"；"改进型题用横向实验矩阵(7个变体)系统对比，每变体只改一个组件"；"跨域/换场景数据分布偏移 → 无监督分布对齐(中位数/IQR/分位数)，不要硬套旧模型"；"物理映射函数必须加单调性约束(SNR越大速率不能越小)"。**

## 7. 局限
- 7变体计算量大；
- 无监督对齐假设两域边缘分布可对齐，不总成立。
