# Card: 2025C-DeepLab 基于钻孔裂隙智能识别的结构面网络重构与稳定性分区

## 0. 元数据
- 年份/题号：2025 C 题
- 学校：未在摘要标注

## 1. 问题指纹
- 同 C 题。特色：**DeepLabV3+语义分割+复合损失(BCE+Dice)+迭代式模型驱动聚类+巴顿标准轮廓验证**。

## 2. 信息流
```
Q1: 中值/双边去噪+CLAHE → 迁移DeepLabV3+(ResNet50+BCE+Dice复合损失) → mIoU=0.8435
Q2: 形态学开运算+坐标变换 → 迭代聚类(DBSCAN初分→最大碎片种子正弦拟合→MAE合并同趋势碎片)
Q3: 基线-法向距离法剥离宏观趋势 → 等间距/曲率/关键点采样对比 → 巴顿标准轮廓上验证(R²=0.918)
```

## 3. 分问拆解
- Q1：**BCE+Dice复合损失**专治裂隙像素占比小的类别不平衡；mIoU=0.8435、Prec=0.9356、Recall=0.8779。
- Q2：**迭代式模型驱动聚类**（创新）：DBSCAN初分→最大碎片作种子拟合正弦→以MAE为几何约束迭代合并符合同趋势的碎片→最小二乘精修；**周期P收敛到94.25mm（=30mm钻孔周长），自证物理一致**。
- Q3：**基线-法向距离法**把微观起伏从宏观正弦趋势中剥离；三种采样在国际巴顿标准轮廓线上定量验证，关键点采样最优（R²=0.9177/RMSE=1.63）。

## 6. 可迁移 Pattern
> **"类别极不平衡的二分割：BCE+Dice复合损失"；"破碎实例聚类：先拟合最大碎片当模板，再MAE迭代吸收同趋势碎片（模型驱动聚类）"；"算法参数好不好，用国际公认标准数据集/标准轮廓线（巴顿JRC轮廓）做外部验证"；"周期P收敛到物理周长=模型自洽性证据"。**

## 7. 局限
- DeepLabV3+训练成本高；
- 迭代聚类对初始种子敏感。
