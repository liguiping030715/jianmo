# Card: 2025C-Frangi 基于Frangi滤波的钻孔裂隙识别与三维概率重构

## 0. 元数据
- 年份/题号：2025 C 题
- 学校：未在摘要标注

## 1. 问题指纹
- 同 C 题。特色：**Frangi医学血管滤波迁移 + 蒙特卡洛不确定性量化**。

## 2. 信息流
```
Q1: Hessian多尺度Frangi滤波 → Otsu+形态学+先验掩码 → 4组预处理对比
Q2: 形态学闭运算 → DBSCAN → 两阶段鲁棒拟合(初拟合/异常块剔除/精炼)
Q3: 中心线分段+长度加权JRC → 等弧长采样>60%点趋稳
Q4: JRC关联法向量不确定性 → 蒙特卡洛抽样 → 连通概率+不确定性云图+3个补孔
```

## 3. 分问拆解
- Q1：**把医学图像Frangi血管滤波器迁移到地质裂隙**（线状结构检测）；4组预处理对比选"灰度+光照归一化"。
- Q2：两阶段鲁棒拟合三步——初拟合→RANSAC式异常块检测剔除→精炼拟合；拟合误差<1.0。
- Q3：**等弧长采样优于等间距采样**；采样点超过总弧长60%后JRC趋稳；JRC范围16~39。
- Q4：**创新点——蒙特卡洛概率重构**：把JRC与平面法向量不确定性挂钩，大量随机抽样生成裂隙平面可能形态，用"空间最小距离+法向量夹角"两指标算连通概率；输出不确定性云图+3个补孔坐标。

## 6. 可迁移 Pattern
> **"线状结构检测：Hessian矩阵多尺度Frangi滤波（医学/地质通用）"；"从2D曲线推3D平面有不确定性 → 蒙特卡洛抽样+概率云图，别给确定性单点"；"采样收敛性要画'采样点数-JRC'曲线找饱和点"；"跨领域方法迁移（医学血管→地质裂隙）是数模亮点"。**

## 7. 局限
- 蒙特卡洛计算量大；
- Frangi参数随图像尺度变化。
