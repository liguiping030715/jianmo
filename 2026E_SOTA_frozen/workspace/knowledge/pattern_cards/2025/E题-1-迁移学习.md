# Card: 2025E-1 基于迁移学习的高速列车轴承故障诊断

## 0. 元数据
- 年份/题号：2025 E 题（轴承迁移诊断）
- 学校：未在摘要标注

## 1. 问题指纹
- 表面任务：源域选样本+多域特征→源域诊断→无标签目标域迁移→可解释性。
- 真实困难：**源域台架数据丰富但目标域实际列车数据无标签且分布偏移**。
- 题型标签：多域特征工程 + 多模型对打 + 域适应 + 三层可解释性。

## 2. 信息流
```
Q1: 39特征(时/频/时频/包络) → Pearson+Spearman+PCA+互信息+卡方 → 14特征
Q2: 14特征 → SVM/RF/MLP 5折CV  +  小波时频图→VGG/CNN → MLP Acc=99.66%
Q3: CNN决策边界对齐策略 → 调源/目标特征分布 → 目标域4+4+5+3
Q4: MMD+分布距离+类间相关 → 迁移前后可解释
```

## 3. 分问拆解
- Q1：四维度39候选特征，**五种筛选方法交叉**（Pearson线性相关、Spearman秩相关、PCA降维、互信息非线性、卡方类别相关）筛出14个。
- Q2：两种路线并行——手工特征喂SVM/RF/MLP；小波变换二维图喂VGG/CNN；MLP最优。
- Q3：**决策边界对齐**——不靠全局分布对齐，而是让源域决策边界适应目标域特征分布。
- Q4：引入MMD、分布距离度量、类间相关度量三组指标，量化迁移前后差距。

## 6. 可迁移 Pattern
> **"迁移学习题的特征筛选要多法交叉（Pearson/Spearman/PCA/互信息/卡方），单法会漏"；"迁移分两条路并行验证：手工特征+传统ML vs 时频图+深度模型"；"域适应除MMD全局对齐外，可试决策边界对齐"。**

## 7. 局限
- 决策边界对齐对超参敏感；
- 5折CV在小样本上波动大。
