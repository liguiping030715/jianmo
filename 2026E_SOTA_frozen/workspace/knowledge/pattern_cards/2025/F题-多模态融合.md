## 1. 问题指纹

## 2. 信息流
```
Q1: 园林抽象为赋权无向图 → 双维评价(路径平滑度+总异景) → IGA(整数编码+贪心初始化+精英保留)帕累托
Q2: 核密度估计+最邻近指数量元素分布 → 视域多边形面积变化率刻画开合 → AHP-熵权组合赋权
Q3: 特征提取器→MKL融合异构特征+对比损失→美学嵌入空间 → 特征/拓扑/行为三重相似度 → NeRF+时空图卷积多任务
```

## 3. 分问拆解
- Q1：双维评价函数——路径平滑度（蜿蜒体验）+总异景程度（视觉变化丰富）；IGA改进：整数编码适配路径+贪心初始化提收敛+精英保留。
- Q2：**AHP-熵权法组合赋权**（专家经验+数据客观分布）；视域多边形面积变化率刻画开合。
- Q3：**多核学习MKL融合异构特征**+对比损失把园林映到"美学嵌入空间"；特征/拓扑/行为三重相似度；拓展NeRF+时空图卷积。

## 6. 可迁移 Pattern
> **"多源异构特征融合：MKL多核学习比手工拼接好"；"相似度学习：对比损失把样本映到嵌入空间，再算距离"；"主观权重AHP+客观权重熵权组合赋权，比单用一个稳"；"路径优化算法改进三板斧：整数编码+贪心初始化+精英保留"。**
