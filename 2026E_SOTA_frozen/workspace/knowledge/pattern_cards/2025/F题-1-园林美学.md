# Card: 2025F-1 江南古典园林的美学特征建模（Voronoi+射线探测+马尔科夫+NSGA-II）

## 0. 元数据
- 年份/题号：2025 F 题（园林美学量化）
- 学校：未在摘要标注

## 1. 问题指纹
- 表面任务：移步异景趣味性游线优化 → 小中见大幻境感评分 → 有法无式园林相似度。
- 真实困难：**把"移步异景""小中见大"这种感性体验翻译成可计算指标**。
- 题型标签：图论路径 + 射线追踪视域 + 多目标优化 + 景观生态学指标 + 深度相似度。

## 2. 信息流
```
Q1: 障碍物→Voronoi+空间索引+分支修剪→路径网络 → 射线探测视景矩阵 → 马尔科夫链(时间)+汉明距离(空间) → 改进NSGA-II游线
Q2: 局部矩形扫描→栅格矩阵→连通域斑块→景观生态学指标 + 空间句法(连接度/围合比) → 层次加权幻境分
Q3: 特征金字塔四层(路径/幻境/栅格局部/空间关系)+卷积自编码器 → 相似度→共性+个性
```

## 3. 分问拆解
- Q1：路径网络构建——Voronoi图+空间索引快速筛障碍物+连通分量最大子图+分支修剪保出入口；**射线探测视景矩阵**（人眼高度发射线）；异景程度=马尔科夫链景观状态转移概率矩阵（小概率转移=意外）+汉明距离（相邻节点视景差异）；改进NSGA-II最大化异景+最小化重复。
- Q2：元素分布转栅格矩阵，连通域聚合斑块，算多样性/聚集度/蔓延度/边缘密度等景观生态学指标；空间句法算连接度+平均最近邻+围合比；层次加权融合。
- Q3：四层特征金字塔+卷积自编码器提深层空间特征；拆相似性=共性（围合度/紧凑度）+个性（个性化指数）。

## 6. 可迁移 Pattern
> **"感性体验量化：拆成可计算子指标——时间维度(马尔科夫转移意外性)+空间维度(相邻状态汉明差)"；"视线可视性问题：射线追踪+视景矩阵是标准做法"；"游线优化=多目标GA(异景最大+重复最小)"；"景观分布用景观生态学一整套指标(多样性/聚集度/蔓延度)"。**

## 7. 局限
- Voronoi对不规则园林边界近似；
- 改进NSGA-II参数敏感。
