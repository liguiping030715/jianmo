# Card: 2025E-2 无监督迁移学习下的轴承故障诊断建模与优化

## 0. 元数据
- 年份/题号：2025 E 题
- 学校：未在摘要标注

## 1. 问题指纹
- 同 E 题。特色：**两阶段信号去噪（TVFEMD+GWO-MOMEDA）+ MixHop多域融合 + 二阶高阶矩联合匹配**。

## 2. 信息流
```
Q1: 48kHz→32kHz重采样 → TVFEMD+WESK选IMF → GWO-MOMEDA再降噪 → SMOTE平衡 → 36特征+MixHop
Q2: 归一化标准化 → RF/LSTM/CNN/ViT对比 → ViT Acc=95.7%
Q3: KDE确认分布偏移 → MMD+二阶/高阶统计量联合匹配 → ViT无监督域自适应+权值共享
Q4: t-SNE散乱到对齐 + 质心方差 + 注意力可视化 + SHAP事后审计
```

## 3. 分问拆解
- Q1：信号预处理最重——**TVFEMD分解IMF，用加权包络谱峭度WESK选有效IMF**；再用**GWO灰狼优化MOMEDA的T和L参数**做第二次降噪；SMOTE平衡到每类28；36特征（时16+频13+熵7）+**MixHop图网络融合多域特征**。
- Q2：四模型对比选ViT。
- Q3：**核密度估计KDE先定量确认源/目标分布偏移存在**；MMD+二阶/高阶统计量联合匹配（不只对齐均值，还对齐方差和高阶矩）。
- Q4：可解释三层——t-SNE可视化"散乱→对齐"、质心方差量化、注意力+SHAP审计单样本决策。

## 6. 可迁移 Pattern
> **"强噪声振动信号：先EMD类分解（TVFEMD/CEEMDAN）选IMF再降噪，别直接喂原始信号"；"EMD后选IMF：用包络谱峭度/加权包络谱峭度WESK，别瞎选"；"域对齐不只对齐均值(MMD)，二阶+高阶统计量一起对齐更稳"；"迁移效果验证：t-SNE前后对比+MMD数值+质心方差三件套"。**

## 7. 局限
- TVFEMD+GWO-MOMEDA两阶段去噪计算重；
- ViT在小样本上易过拟合。
