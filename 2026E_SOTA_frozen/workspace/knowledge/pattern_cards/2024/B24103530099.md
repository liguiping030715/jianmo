# Card: 2024B 浙江工商大学（DBSCAN同步异步 + 过采样CNN + 双层交叉预测）

> **Depth: L3_DEEP（P1.5 全文深读）**

## 0. 元数据
- 队号 B24103530099，浙江工商大学，题目：WLAN 吞吐量建模

## 1. 问题指纹
- 表面：发送机会 seq_time → (MCS,NSS) → 吞吐量。
- 真正困难：①RSSI 在 PD–ED 区间时同步/异步概率未知；②(MCS,NSS) 组合多且类别极不平衡（1 个 vs 249 个）；③测试集缺中间观测变量（num_ppdu 等），无法直接算吞吐量。

## 2. 数学抽象链
```
原始CSV → 按AP数(2/3)分组
Q1: RSSI → DBSCAN密度聚类(高密度=同步/低密度=异步) → 随机翻转扰动 → RF/GBDT → seq_time
Q2: (MCS,NSS) → 融合标签 → 数字0-14编码 → 独热；新特征SINR(同步=RSSI+99/异步=RSSI0-RSSI1,按占比加权) → 过采样 → CNN
Q3: 第一层RF预测4中间变量(num_ppdu/ppdu_dur/seq_time/other_air_time) → 第二层深度残差网络(+per+PHYRate) → throughput
```

## 3. 为什么每个模型被选
- **DBSCAN 而非硬阈值**：PD–ED 临界区同步/异步无明确分界，DBSCAN 不需预设簇数、按密度自动发现，符合"概率未知"。
- **RF vs GBDT 对打**：两者都处理非线性表格，RF(Bagging)抗过拟合、GBDT(Boosting)降偏差，让数据选；RF 胜（2ap MSE9.09/R²0.91）。
- **融合标签+独热**：MCS、NSS 单独建模会丢失组合关系，融合后用独热避免模型误判数字大小有序。
- **BP vs CNN 对打**：CNN 一维卷积提局部特征，胜（92.41% vs 88.61%）。
- **过采样**：类别 1 vs 249，不平衡导致少数类被忽视。
- **双层串联（核心）**：吞吐量依赖的中间变量在测试集缺失，先用第一问验证过的 RF 补中间量，再喂残差网络——绕开缺失。

## 4. Baseline 与消融逻辑
- Q1：RF vs GBDT。
- Q2：BP vs CNN → CNN 再加过采样（92.41%→99.57%，逐层看增益）。
- Q3：第一阶段 RF 4 变量分别报 R²（seq_time/other_air >0.9，num_ppdu 0.74/ppdu_dur 0.61），第二阶段残差网络。
- 特征重要性排序回答"哪类信息主导"：节点间RSSI > 门限 > 拓扑 > 业务流量。

## 5. 参数选择逻辑
- 环境底噪 -99dBm（查 IEEE802.11 + 假设）。
- CNN：64 滤波器，核 2×2，全连接100，epoch100→过采样后200，batch32。
- 3ap 输出层 22 神经元（类别数倒推），epoch300。
- 过采样目标：每类补到 249（=最大类），共 3486。

## 6. 验证策略
- 80/20 划分，报 MSE/R²/Acc。
- 自编码器/CNN 均画 train vs test 损失曲线判断过拟合。
- 热力图多次使用：特征相关性、特征与标签。
- 特征重要性排序图。

## 7. 敏感性/鲁棒性
- DBSCAN 后随机翻转部分标签 + 模型加高斯扰动，模拟无线随机性。
- 但翻转比例/扰动方差未明确给出。

## 9. 章节承接技法
- Q1 验证过的 RF 直接复用到 Q3 第一阶段；Q2 的(MCS,NSS)经 PHYRate 查表转为连续量喂 Q3 第二阶段——**前三问的模型/产物在 Q3 全部汇合**。

## 10. 弱点 / 可疑论断（深读发现，重要）
1. **过采样 99.57% 有泄漏虚高嫌疑**：随机过采样复制少数类样本，随后按 80/20 随机划分（非按时间/实验组），同一复制样本极易同时进训练集和测试集，准确率被人为抬高。正确做法应先划分、只在训练集内过采样。
2. **Q3 两阶段误差累积未讨论**：第一层 RF 的 num_ppdu/ppdu_dur R²仅 0.6–0.74，其预测误差传入第二层，但第二层报 loss→0/R²→1，疑似用了真实中间变量训练、预测时却用第一层的不准预测，训练/预测输入分布不一致。
3. 自编码器填补 3ap 缺失效果不佳，直接剔除整个文件而非改进，损失数据。
4. 随机翻转比例、高斯扰动方差、底噪 -99dBm 均为假设/未量化。

## 11. 可迁移条件 vs 不可迁移
- **可迁移**：测试集缺中间变量→先建模补中间量的双层串联；组合标签融合+独热；不平衡先量化比例；多模型对打+特征重要性排序；前三问产物在末问汇合的组织。
- **不可迁移 / 需修正**：随机过采样后随机划分（会泄漏，必须先划分再过采样）；-99dBm 底噪、50/60 等 WLAN 专用阈值。
