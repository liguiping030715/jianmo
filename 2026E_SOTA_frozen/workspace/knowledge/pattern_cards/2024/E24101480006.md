# Card: E24101480006（辽宁石油化工大学）高速公路应急车道启用管控优化与决策模型

## 0. 元数据
- 年份/题号：2024 E 题（高速应急车道）
- 学校：辽宁石油化工大学

## 1. 问题指纹
- 表面任务：视频提取交通流参数 → 拥堵预测/预警 → 应急车道启用决策 → 监控点布局。
- 真实困难：**从监控视频自动抠出 q/u/ρ 三参数 + 把"经验性开道"变成有理论依据的阈值决策**。
- 题型标签：CV检测跟踪 + 时序预测 + 阈值规则决策。

## 2. 信息流
```
Q1(1): 视频 → YOLOv5+DeepSORT → 5指标 → 速度/流量/密度
Q1(2)(3): 历史平均/SVM/树/LSTM预测密度 + Greenberg模型预测速度 → 阈值判拥堵
Q2: 五大理论依据 + 四类紧急情况 → 启用规则
```

## 3. 分问拆解
- Q1(1)：任务分解为多目标检测(YOLOv5)+跟踪(DeepSORT)；提取总车数/当前车数/小车/大车/应急车道车5指标，归一化后画分布与时序图。
- Q1(2)(3)：预测密度四模型对打选 LSTM；**Greenberg 交通流模型预测速度**；多阈值分级判拥堵严重程度。
- Q2：启用模型建**五条理论依据**（合法使用/紧急情况/优先原则/安全驾驶/及时退出）；紧急分四类（拥堵/事故/维修/禁行）；拥堵启用标准：速度<阈值持续时长 OR 密度>阈值持续时长。

## 6. 可迁移 Pattern
> **"视频题第一步永远是 检测+跟踪 两件套（YOLO+DeepSORT/ByteTrack）"；"预警判据不要单点触发，要'指标越限+持续N秒'防抖"；"管理决策类问题先立理论依据/原则清单，再写规则，避免拍脑袋"。**

## 7. 局限
- 启用阈值靠经验设定，未数据驱动标定；
- Greenberg模型对非拥挤段拟合弱。
