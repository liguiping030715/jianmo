# Card: B24116640167（西安邮电大学）WLAN 组网中网络吞吐量建模

## 0. 元数据
- 年份/题号：2024 B 题
- 学校：西安邮电大学

## 1. 问题指纹
- 表面任务：同 B 题。
- 真实困难：多因素影响筛选 + 回归/分类/回归三问都要跑通。
- 题型标签：相关性分析 + 多模型对打（RF/决策树/LSTM/SVM多核）。

## 2. 信息流
```
Q1: Pearson相关 → RF/决策树/LSTM对比 → 发送机会
Q2: 相关性选特征 → RF/多元线性回归/LSTM → PHY Rate → 查表映射(MCS,NSS)
Q3: Q1+Q2预测值+原特征融合 → RF/3核SVM/LSTM对比 → 吞吐量
```

## 3. 分问拆解
- Q1：Python+SPSS+Matlab 工具组合；Pearson 相关 + RF 特征重要性排序；RF vs LSTM 选优。
- Q2：先预测连续 PHY Rate，再用 **(MCS,NSS)组合表反查映射**——把多分类问题转成回归+查表，绕开离散标签不平衡。
- Q3：把 Q1、Q2 的预测结果和原特征融合，相关性二次筛选，跑 RF/LinearSVM/RBF-SVM/多项式SVM/LSTM 对比。

## 4. 亮点
- **Q2 的"回归 + 查表映射"技巧**：MCS,NSS 是离散组合，直接分类类别不平衡；先回归 PHY Rate 再反查，简单稳定。
- 工具链混合：Python/SPSS/Matlab 各取所长。

## 5. 验证策略
- 每问三模型对打；
- 特征融合后再做一次相关性筛选，防止冗余特征进模型。

## 6. 可迁移 Pattern
> **"离散标签分类难（类别少/不平衡）→ 改成预测连续物理量，再用查找表映射回离散标签"；"多模型对打至少包括一个树模型、一个线性模型、一个深度模型"；"前后问的预测值可以作为后问的增强特征（链式特征）"。**

## 7. 局限 / 慎用点
- 回归 PHY Rate 后查表映射，边界处误差会被放大（刚好在两个 MCS 阈值之间时跳变）；
- LSTM 对表格数据非时序，使用理由偏弱。
