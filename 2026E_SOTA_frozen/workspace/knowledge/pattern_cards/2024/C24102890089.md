# Card: C24102890089（江苏科技大学）数据驱动下磁性元件的磁芯损耗建模

## 0. 元数据
- 年份/题号：2024 C 题
- 学校：江苏科技大学

## 1. 问题指纹
- 表面任务：励磁波形分类 + 斯坦麦茨(SE)方程温度修正 + 三因素影响分析与最优组合。
- 真实困难：**经典物理方程(SE)缺温度项**，直接拟合误差大；波形类别靠"形状"区分，要自己设计特征。
- 题型标签：波形分类 + 物理公式修正 + 方差分析/穷举寻优。

## 2. 信息流
```
Q1: 磁通密度时序 → 形状特征 → MLP/RF/加权集成 → 波形分类
Q2: 温度因子CT × 原SE方程 → 三方案最小二乘拟合 → 修正损耗预测
Q3: 三因素方差分析 → 穷举48组合 → 最优工况
```

## 3. 分问拆解
- Q1：傅里叶分析去噪；提取时域/形状特征（峰峰值、升降速率、峰度偏度、频域能量）；MLP+RF+**加权集成**；混淆矩阵+交叉验证。结果：正弦20/三角44/梯形16。
- Q2：原SE缺温度项→三种温度修正函数：Solow线性、二次多项式、温度饱和模型；最小二乘+非线性拟合；最终选 Solow 修正 SE，MAPE=15.94%、R²=0.9954。
- Q3：单因素ANOVA的p值（温度1.7e-11、波形1.5e-118、材料2.1e-63）→ 多因素交互 → 直接穷举三因素得 90℃+正弦波+材料4 损耗最小=37860 W/m³。

## 4. 可迁移 Pattern
> **"经典物理方程在新工况下不准 → 不推倒重建，在方程上乘一个修正因子(温度/形状)，最小二乘拟合因子参数"；"离散因素找最优组合 → ANOVA先证显著，再穷举全组合"。**

## 5. 证据
- R²=0.9954；p值量化各因素独立影响程度；混淆矩阵+交叉验证。

## 7. 局限
- 穷举寻优只在三因素少量离散值上可行，维度高时不可行；
- MAPE=15.94% 对工程预测仍偏大。
