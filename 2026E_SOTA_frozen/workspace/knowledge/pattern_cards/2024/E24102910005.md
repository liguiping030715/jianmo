## 1. 问题指纹
- 同 E 题。特色：**区间占用率 K(t) 串联上下游 + 三条显式启用依据**。

## 2. 信息流
```
Q1: YOLOv10m+ByteTrack过线统计 → ARIMA分析 → 最小二乘拟合q-u-ρ关系 → AdaBoost提前10分钟预警

```

## 3. 分问拆解
- Q1：YOLOv10m+ByteTrack过线计数；ARIMA分析拥堵/非拥堵曲线差异；最小二乘拟合经典交通流三关系（密度-速度/流量-密度/流量-速度）；**用A/B/C上游点预测D点（相关性递推10分钟）**，多元回归+AdaBoost，R²=0.968；间断交通流方程判持续拥堵，与实际视频核对（C点拥堵38min/D点25min判断全对）。
- Q2：**区间占用率模型 K(t)** 量化区间车流；按CD段距离加权 K=0.4K_AB+0.6K_BC；三条启用依据：①上游K>0.8 ②下游ρ_D<0.8 ③利用率够高才开。
- Q3：对比开道前后K(t)，拥堵后移3分钟。

## 6. 可迁移 Pattern
> **"多监测点串联 → 构造区间占用率类综合指标，按物理距离加权"；"预测下游点 → 看上游点与下游的时序相关性，有10分钟滞后就可提前预警"；"启用/关闭给三条独立依据（上游挤、下游空、利用率高），比单一阈值鲁棒"。**

## 5. 证据
- AdaBoost R²=0.968；拥堵起止时间与人工核对全对。
