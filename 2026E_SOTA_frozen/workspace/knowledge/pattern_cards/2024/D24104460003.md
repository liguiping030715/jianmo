# Card: D24104460003（曲阜师范大学）大数据驱动的地理综合问题

## 0. 元数据
- 年份/题号：2024 D 题
- 学校：曲阜师范大学

## 1. 问题指纹
- 同 D 题。最大亮点：**面对极端不平衡的地理大数据，规范的对齐+欠采样处理流程**。

## 2. 信息流
```
Q1: 日降水/年LULC → 自定义指标(距平百分率/动态度/成分度) → 时序分解(趋势/周期/随机)
Q2: 多源重采样0.5°对齐 → 617万条 → 降水等级标签极度不平衡 → 分层欠采样 → 建模
```

## 3. 分问拆解
- Q1：自定义指标体系——年均/月均降水、**降水距平百分率**、区域方差；LULC **动态度/成分度**；月降水做**时间序列分解（长期趋势/循环/随机）**；箱线图+地图+堆叠条形图可视化。
- Q2：多源数据**重采样到统一0.5°像素**后连接成 617 万条；降水按等级打标签；**发现特大暴雨仅 92 条(0.0025%)，类别极度不平衡**；采用**欠采样分层抽样**（无雨6000/小雨5000/中雨4000/大雨3000/暴雨1500/大暴雨1208/特大92）；联合均值方差模型+决策树+MCP变量选择。

## 4. 亮点
- 大规模地理数据对齐（重采样到统一网格）是隐性的前置工程；
- **诚实面对类别不平衡并显式分层抽样**，而不是硬训。

## 6. 可迁移 Pattern
> **"多源栅格数据必须先重采样到统一分辨率+时间对齐再建模"；"类别极不平衡 → 先量化不平衡比例，再分层欠采样/过采样，不要直接用准确率评估"；"时序现象要做趋势-周期-随机三分解"。**

## 7. 局限
- 欠采样丢弃大量多数类信息，对多数类精度有损失。
