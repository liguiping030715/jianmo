# Card: C24104220149（山东大学）基于多因素分析与深度学习的磁芯损耗建模

## 0. 元数据
- 年份/题号：2024 C 题
- 学校：山东大学

## 1. 问题指纹
- 同 C 题。特色：**特征工程+PCA+多优化器对打+Bi-LSTM+改进蚁群**，方法栈最全。

## 2. 信息流
```
Q1: FFT时频特征 → PCA降维 → SVM/决策树/集成 100%分类
Q2: 5种温度修正 × 3种优化器(动态PSO/最小二乘/模拟退火) → 三次修正最优
Q3: 单因素+两两交叉均值方差+热力图 → 最优组合
Q4: 特征权重Bi-LSTM预测 + 改进蚁群优化
```

## 3. 分问拆解
- Q1：频率直方图+波形图可视化+FFT；PCA 提主成分；SVM/决策树/集成学习**三种全到100%**（证明特征选得好）。
- Q2：五种温度修正函数（比例/二次/三次/指数/幂级数）；三种参数寻优器对比（**动态参数PSO > 常值PSO**，R²+0.041）；三次修正 R²=0.9955（原0.9448）。
- Q3：单因素→两两交叉均值方差→热力图；最优 90℃+正弦波+材料4。
- Q4：跨材料跨工况通用模型——**特征权重提取的 Bi-LSTM**；改进蚁群算法找最小损耗/最大磁能传输条件。

## 4. 可迁移 Pattern
> **"参数寻优器也有超参 → 用动态调整版比固定版好"；"通用预测模型 → 不要只在单一材料上训练，跨材料跨工况泛化才是真问题"；"分类准确率100%要警惕数据泄漏，多模型同时100%才可信"。**

## 5. 证据
- R² 提升量化（0.9448→0.9955）；动态PSO vs 常值PSO对比；热力图。

## 7. 局限
- Bi-LSTM 用于表格型损耗数据，时序假设弱；
- 改进蚁群的收敛性未充分论证。
