## 0. 元数据
- 队号 C24106130096，西南交通大学，题目：磁芯损耗建模

## 1. 问题指纹
- 表面：波形分类 → 温度修正 → 最优工况 → 损耗预测 → 多目标优化。
- 真正困难：①干净数据分类易、有噪环境才是真考验；②SE 方程非线性且不含温度；③损耗预测要跨材料/温度/波形多因素泛化；④损耗与传输磁能两目标冲突。

## 2. 数学抽象链
```
Q1: 波形 → 0-1标准化(去幅值) → 一阶差分→阶跃数nstep(形状) → 描述统计5特征 → SVM
       → 加噪SNR=5dB检验 → 多域融合(HHT边际谱5+双谱投影5=10维)+t-SNE
Q2: SE: P=k·f^α·B^β
       → NAdam数值解(25000次)
       → LSE对数线性化: lnP=lnk+αlnf+βlnB (最小二乘闭式解)
       → TLSE: ×kT温度修正，枚举 T^γ / e^γT / e^γT+c
Q4: 深度自表示DSR把经验模型与深度学习融合（先验知识指导训练）
Q5: min 损耗 P，max 传输磁能 P'=f·Bm
```

## 3. 为什么每个模型被选
- **阶跃数先做规则分类**：正弦/三角/梯形的本质差异是"突变次数"，可直接由差分检测，成本最低（但 Acc0.985、正弦类偏低，故继续）。
- **SVM 4 核对打**：高斯/线性/Poly/Sigmoid，让数据选核（高斯≈Poly=1.0）。
- **主动加噪而非等理想**：真实测量必有噪，SNR=5dB 下时域特征掉到 0.72，暴露脆弱，才引出多域融合。
- **HHT+双谱**：HHT 边际谱捕非平稳时频结构、双谱捕非线性相位耦合，比纯时域抗噪。
- **NAdam vs 最小二乘闭式解**：同一 LSE 模型，数值迭代 vs 矩阵闭式，结果类似但闭式省算力——论证"能闭式就别迭代"。
- **温度修正枚举三形式**：不预设温度关系，让数据在幂/指数/指数+常数中选。
- **GA 和 PSO 都跑**：验证最优解不依赖单一智能算法。

## 10. 弱点 / 可疑论断（深读发现）
1. **GA 与 PSO 结果表（5.37/5.38）减法列数值完全相同**：两种机理不同的算法给出逐位一致的解不合常理，疑似复制表格或用了同一缓存结果。
2. **除法模型 L2 全部不合现实范围**（P=1.80、P′=57.40 近乎固定），说明 L2=P/P′ 被分母 P′ 主导、转化失效，但正文仅"弃用除法"未深究原因。
3. **温度系数 γ=−0.61（温度升、损耗降）**：仅在 25–90℃、材料一主导的数据上成立，外推到其他材料/更高温度风险大。
4. 深度自表示 DSR 的具体网络结构/损失在正文描述偏简，主要靠附录。
5. 表5.1 波形规则在 Markdown 转换中行错位（正弦 nstep≥10 明显与图5.1"突变0"矛盾）——转换产物问题，引用时需核对原文。

## 11. 可迁移条件 vs 不可迁移
- **可迁移**：主动加噪暴露脆弱再补特征；消融矩阵逐层加组件+信息增益量化；非线性模型对数线性化求闭式解；修正项枚举多函数形式；多目标结果用现实范围筛选；系数显著性检验。
- **不可迁移**：γ=−0.61、α=1.61/β=2.51 等磁芯专用参数；P/P′ 除法转化（本例已证失效）。
