# Card: D24106570027（贵州大学）大数据驱动的地理综合问题建模与分析

## 0. 元数据
- 年份/题号：2024 D 题
- 学校：贵州大学

## 1. 问题指纹
- 同 D 题。特色：**空间自相关(Moran's I) + 多预测模型对比 + 极值统计物理框架**。

## 2. 信息流
```
Q1: Kriging插值/栅格矢量化 → Moran's I+CV → ARIMA/MK/LSTM对比
Q2: 元高斯(metagaussian)极值全微分方程 + 大尺度物理场 → 集成框架
```

## 3. 分问拆解
- Q1：指标除常规降水外引入 **Moran's I（空间自相关）、变差系数CV**；土地动态度 + Theil-Sen 中值趋势；ARIMA / Mann-Kendall / LSTM 三模型对比，95%置信水平显著性检验。
- Q2：整合**元高斯模型极端事件重现期全微分方程** + 大尺度物理场，构建统计+非线性+物理三位一体框架。

## 4. 亮点
- 把空间自相关（Moran's I）作为分析维度——D题里少数显式做空间统计的；
- 极值问题上"元高斯重现期"物理框架，比纯ML更有深度。

## 6. 可迁移 Pattern
> **"空间数据别只看时间趋势，要算Moran's I看空间聚集"；"趋势估计用Theil-Sen中值比最小二乘抗异常值"；"极值/重现期问题 → 元高斯/GEV极值统计，而不是直接回归"。**

## 7. 局限
- LSTM损失0.050对降水量级仍偏大；
- 元高斯框架门槛高，可复现性弱。
