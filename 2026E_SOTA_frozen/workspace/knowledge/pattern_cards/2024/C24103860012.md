# Card: C24103860012（福州大学）数据驱动下磁性元件的磁芯损耗建模

## 0. 元数据
- 年份/题号：2024 C 题
- 学校：福州大学

## 1. 问题指纹
- 同 C 题。特色：**双视角特征提取（统计+几何）+ 假设枚举式方程修正**。

## 2. 信息流
```
Q1: 8维统计特征 + 11维几何特征 → 树模型选重要性 → 投票分类
Q2: SE对数线性化 → 6种温度修正假设 → 挑最优
Q3: 对数变换满足ANOVA假设 → 分层抽样50条 → 双因素交互
```

## 3. 分问拆解
- Q1：双视角提特征（统计：峰度偏度等8种；几何：可视化筛11种）；决策树/RF 特征重要性筛出峰度+前k大频率；决策树+RF+逻辑回归**投票法**集成。
- Q2：SE 取对数后最小二乘；提出**6种温度修正假设**（线性项/对数项等），参数求解测试后挑最优；R² 从 0.9299 → 0.9857，误差降近4倍。
- Q3：先**对数变换使数据满足ANOVA的方差齐性+正态性**；48组合按频率分层抽样50条；单/双因素ANOVA+热力图；**分频率段给最优**：低频90℃、高频70℃。

## 4. 可迁移 Pattern
> **"做ANOVA前先检查前提假设（正态/方差齐），不满足就对数变换"；"找方程修正形式 → 枚举多种假设（线性/对数/指数），数据说话挑最优，不要只试一种"；"最优工况随频段变化 → 分层报告，不给单一全局答案"。**

## 5. 证据
- R²提升路径清晰（0.93→0.99）；误差降4倍；热力图可视化交互效应。

## 7. 局限
- 投票集成三模型差异大时可能不稳定；
- 分层抽样50条对48组合样本量偏薄。
