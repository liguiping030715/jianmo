# Pattern Card 模板

> 用法：每篇优秀论文填一张。字段全部从论文摘要/目录/模型章节中提取，不臆造。
> 目标：让未来新题做 Problem Fingerprint 后，能反查"历史上谁解决过类似结构"。

---

# Card: <队号> <论文短题>

## 0. 元数据
- 年份 / 题号：
- 学校：
- 篇幅：约 N 页

## 1. 问题指纹（Problem Fingerprint）
- 表面任务：题目字面让你做什么
- 真实困难：题目真正难在哪（不是算法选择难，而是数学对象构造难）
- 关键不可观测量：题目没直接给、但后面所有模型都依赖的量
- 题型标签：[预测 / 回归估计 / 时序实时计算 / 多目标优化 / 鲁棒优化 / 分类评价 / 反演 / 路径规划 / 不确定性量化 …]

## 2. 信息流（各问之间传递什么）
```
Q1 产出 → Q2 输入 → Q3 输入 → Q4 输入
```
一句话说清：上一问的哪个中间表示是下一问的地基。

## 3. 分问拆解（每问写"为什么这么做"）
### Q1
- 任务：
- 采用方法：
- 为什么是这个方法（对比了什么 baseline / 避开了什么坑）：
- 关键创新点：
- 验证指标/证据：

### Q2 / Q3 / Q4 同上格式

## 4. Baseline → 改进链
| 基线方法 | 为什么不够 | 本文改进 | 证据 |
|---|---|---|---|

## 5. 验证策略（怎么证明自己对）
- 与参考答案/参考方法对比什么指标
- 做了哪些消融/对比实验
- 鲁棒性测试怎么做的

## 6. 可迁移 Pattern（一句话，新题可直接套用）
> 例："实时累计指标算不准 → 滑动窗口局部化 + 尾部逆向补全；不可观测量 → 物理方程打底 + 数据拟合校准。"

## 7. 局限 / 慎用点
- 哪些假设强、换题容易失效
- 哪些方法是本题数据规模/场景特有的
