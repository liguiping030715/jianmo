# Representative Historical Case Map

This is an initial map from papers already inspected. Full P1/P2 mining should expand it.

## 2024 A — Wind farm active-power allocation

Structural lesson: real-time damage quantification -> load estimation -> allocation optimization -> uncertainty/robustness. The final optimizer depends on earlier estimated physical quantities.

## 2024 B — WLAN throughput modeling

Structural lesson: data cleaning/feature influence -> transmission-state/rate modeling -> end-to-end throughput prediction. Intermediate communication variables connect sub-questions.

## 2024 C — Magnetic-core loss modeling

Structural lesson: classify waveform -> modify physical empirical model -> analyze factor interactions -> general loss predictor -> multiobjective operating-point optimization.

## 2024 D — Heavy-rain disaster mechanism

Structural lesson: descriptive spatiotemporal pattern -> mechanism/interaction analysis -> threshold/vulnerability modeling -> future/spatial decision analysis.

## 2024 E — Emergency-lane control

Structural lesson: video -> traffic-flow variables -> congestion forecast -> control rule -> monitoring-layout decision. Raw vision is converted into decision variables before optimization.

## 2024 F — X-ray pulsar photon arrival time

Structural lesson: coordinate/state transformation -> simplified delay -> refined multi-factor delay -> stochastic signal simulation and error analysis. Each question increases model fidelity.

## 2025 A — NPU scheduling

Structural lesson: formulate hard feasibility/resource constraints first, compare constructive/heuristic approaches, then extend objective from peak residency to movement/time tradeoffs.

## 2025 B — MIMO-OFDM link-rate prediction

Structural lesson: interpretable physical baseline -> diagnose mapping limitations -> controlled feature/aggregation improvements -> adapt to changed TxBF/domain structure.

## 2025 C — Borehole fracture reconstruction

Structural lesson: image pixels -> fracture objects -> geometric parameters/roughness -> probabilistic 3D connectivity -> additional measurement decision. Intermediate representation and uncertainty are central.

## 2025 D — Low-altitude turbulence and route optimization

Structural lesson: physical turbulence index -> heterogeneous-source alignment/fusion -> short-term field prediction -> risk-aware route optimization.

## 2025 E — Bearing fault domain adaptation

Structural lesson: representative source-domain construction -> feature/model baselines -> source-target shift handling -> interpretability/distribution evidence.

## 2025 F — Classical-garden aesthetics

Structural lesson: abstract semantic concepts -> measurable spatial/graph proxies -> composite evaluation/optimization -> similarity/generalization. Proxy design is the real modeling step.
