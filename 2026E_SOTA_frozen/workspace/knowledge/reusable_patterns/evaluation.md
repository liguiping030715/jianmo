# P3 reusable_patterns: 评价/综合评分类模式（带适用条件）

> P1.5 据 2024 D/E + 2025 F 深读重写。

---

## Pattern V-1：主客观组合赋权
- **Applicable When**：多指标综合评价，既需专家经验又有客观数据。
- **Why It Works**：AHP（主观、含 CR<0.1 一致性检验）+ 熵权法（客观）组合，比单用任一稳健、可解释。
- **Evidence**：2024D HEV + AHP；各评价题指标显式赋 0~1 权重。
- **Failure Modes**：AHP 成对比较主观、熵权受样本分布影响；权重对结果敏感却未做敏感性。
- **Do Not Use When**：指标间强相关未处理时，加权会重复计权，应先去冗余。

## Pattern V-2：抽象/感性概念拆成可计算子指标
- **Applicable When**：评价对象含主观概念（美学、风险、适宜性）。
- **Why It Works**：拆成时间+空间等多个可定义子指标、各给数学定义再加权，把主观判断落到可复现计算。
- **Evidence**：2025F 移步异景→段间 JS+段内种类密度、开阔/围合双轴；2024D 风险 D=H×E×V。
- **Failure Modes**：代理变量只覆盖部分维度（2025F 二维平面丢失三维/意境）；"理想值/锚点"主观。
- **Do Not Use When**：概念本质无法被所选代理表征时，须明说局限，不可宣称"已量化全部"。

## Pattern V-3："适量度"而非"越多越好"
- **Applicable When**：某指标存在最优区间，过多过少都不好（转折、交叉、长度、浓度）。
- **Why It Works**：用高斯型 exp(−(x−x*)²/σ²) 或区间效用，在理想值取 1、双向偏离递减，纠正线性堆砌思维。
- **Evidence**：2025F 转折/交叉/长度适量度 I2/I3/I5。
- **Failure Modes**：理想值 x* 与容忍度 σ 主观、依据不足。
- **Do Not Use When**：指标确为单调（如安全裕度越大越好）时不可强行设最优区间。

## Pattern V-4：鲁棒性检验与决策规则
- **Applicable When**：评价结果用于管理/工程决策。
- **Why It Works**：单参+联合扰动、外推验证、排名与常识对照；决策开关双向写、多独立依据 AND 组合。
- **Evidence**：2025F 距离衰减重标定、出现阈值滤噪；2024E 时空双约束防抖。
- **Failure Modes**：单阈值脆弱、易被噪声触发；外推样本与训练同分布则验证无效。
- **Do Not Use When**：原则清单（合法/安全/公平/效率）未立先写规则会导致规则互相冲突。
