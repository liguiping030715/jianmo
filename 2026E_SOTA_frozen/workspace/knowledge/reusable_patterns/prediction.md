# P3 reusable_patterns: 预测/回归类模式（带适用条件，非通用规则）

> P1.5 据 12 篇深读重写。每条 Pattern 是**带条件的经验**，不是硬规则。

---

## Pattern P-1：多模型横向对比择优
- **Applicable When**：有足够标注数据、模型与目标关系不明确、需用数据决定模型时。
- **Why It Works**：不同模型的归纳偏置不同，系统对比可避免主观押注，并暴露过拟合。
- **Evidence**：2025D 对比 12 种回归选 RF（RMSE5.12/R²0.85）；2024C Q1 SVM 四核对打。
- **Failure Modes**：数据少时模型排序不稳定；只比单一指标会选错；训练/测试指标背离（2025D 梯度提升训练 R²0.998/测试 0.80）。
- **Do Not Use When**：机理已非常明确且样本极少——硬跑大量黑箱模型浪费时间且不稳。模型数量按数据量定，**不存在"至少 N 个"的硬指标**。

## Pattern P-2：物理机理定结构 + 数据驱动校残差
- **Applicable When**：存在可信机理公式、机理能解释主体趋势、残差仍有可学结构。
- **Why It Works**：物理项保可解释与外推、ML 只补机理偏差，少样本更稳。
- **Evidence**：2024A 扭矩/推力 BiLSTM；2024C SE 方程+温度修正；2025D 全源模型 a 蒸馏单源模型 b。
- **Failure Modes**：机理假设错误时残差建模是"给错模型打补丁"；教师模型（a）本身不可靠会把误差传给学生（b）。
- **Do Not Use When**：机理假设明显不成立、关键状态变量不可观测、物理公式误差已主导结果。非线性方程可对数线性化（SE→LSE），但须验证线性化是否引入偏差。

## Pattern P-3：分组 + 多法特征筛选
- **Applicable When**：数据来自多站点/多工况/多批次，存在天然分组结构。
- **Why It Works**：分组建模避免跨组混淆；多法交叉筛选（相关/互信息/RF 重要性）比单一法稳健。
- **Evidence**：2025B 按 sta_mac/file_source 分组、Isotonic+HGBR；2024C 多域融合+t-SNE。
- **Failure Modes**：one-hot 分组在新域失效且可能"按文件记忆"；筛选误删弱但有交互作用的特征。
- **Do Not Use When**：分组无物理意义、或目标就是要跨组泛化时不应分组建独立模型。

## Pattern P-4：防泄漏交叉验证
- **Applicable When**：样本间存在相关/复制/时序依赖（几乎所有工业数据）。
- **Why It Works**：OOF、GroupKFold、折内校准、只用训练统计量标准化，杜绝信息穿越。
- **Evidence**：2025B GroupKFold+OOF+逆频率权重；2025E 用源域 μ/σ 标准化目标域。
- **Failure Modes**：反例——2024B 过采样后再随机划分，复制样本跨训练/测试致 99.57% 虚高。
- **Do Not Use When**：无（防泄漏是默认要求；但分组键必须按泄漏机理选择，不能机械套用）。
