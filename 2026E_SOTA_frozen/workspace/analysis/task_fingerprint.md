# Structural task fingerprint

Supervised utterance-level three-class classification and bounded regression; heterogeneous text/audio/video sequences; asynchronous sampling; variable valid length and padding; local contiguous missing intervals at test time; full-modality explanation set; small official training pool (4,850 per version across splits, not 4,850 independent per split); sample-level and local temporal attribution; raw-video traceability. No physical law, graph routing or resource optimization. Question chain: raw-to-timed representation (Q1) → reliability-aware prediction under local observation loss (Q2) → source-linked and intervention-checked decision explanation (Q3). Principal risks: index/time mismatch, missing-vs-padding confusion, shifted missingness simulation, split leakage, and explanation overclaim.
