The numerical results in this report are regenerated by:

python workspace/analysis/scripts/run_stage2_audit.py

Detailed evidence is in `workspace/analysis/audit_artifacts/`, especially `audit_summary.json`, `profiler_file_summary.csv`, `microwave_cycle_sequence.csv`, `microwave_duplicate_records.csv`, and `microwave_duplicate_comparisons.csv`.

## Structural validation results

### Microwave files

- Both tables have a stable 95-column schema and every data row has width 95.
- Station A has 64 rows and station B has 72; record IDs are unique and contiguous within each file.
- Every detected cycle contains exactly one row of each code token `11`, `12`, `13`, and `14`.
- Named scalar fields are internally identical across all four code rows of every cycle.
- Every expected numeric token parses as a finite number; no blank field is present.
- The 83 labeled height columns are unique, strictly increasing, and identical between stations.
- `QCflag` is `9` in all 136 rows. No supplied definition says whether `9` means valid, invalid, or something else.
- Neither file has an exact duplicate full row or an exact duplicate payload after excluding only `Record`.

### Profiler files

- All 12 files have the expected `WNDROBS 01.20`, `ROBS`, and `NNNN` markers.
- Every file contains 62 vertical rows of width seven.
- Internal station IDs and timestamps match filenames in every file.
- Vertical grids are identical, unique, and strictly increasing in every file.
- A row is either fully numeric in `W1`–`W6` or slash-filled in all six positions; there are no partially missing rows.
- In every file, fully numeric rows form a contiguous lower block and slash-filled rows form the upper block. Numeric values never resume above the first slash-filled row.
- No two profiler files have the same SHA-256 digest.

These checks establish parseability and internal structure; they do not establish physical correctness.

## Coordinate metadata consistency

Coordinates from the microwave location line were converted from DMS to decimal degrees and compared with the profiler metadata. Great-circle separation uses the Haversine formula with radius 6,371,008.8 m; it is a reproducible calculation, not a value supplied by the files.

| Station | Microwave lon/lat | Profiler lon/lat | Profiler-minus-microwave degree deltas | Derived separation |
|---|---|---|---|---:|
| A | 118.8472222222, 32.3686111111 | 118.8472, 32.3686 | -0.0000222222, -0.0000111111 | 2.425 m |
| B | 118.5900, 32.0652777778 | 118.8994, 31.9317 | +0.3094, -0.1335777778 | 32,739.660 m |

Station A's two horizontal positions are consistent with coordinate rounding. Station B's are not a plausible rounding difference and must not be treated as collocated without correction or authoritative confirmation.

The microwave location lines also contain opaque numeric tokens `6.5` and `9.4`, while profiler metadata contain opaque values `16.2` and `40.6`. Their numeric differences are 9.7 and 31.2 respectively, but no unit or semantic comparison is valid.

## Cross-field numerical checks without semantic assignment

For each cycle, the zero-kilometre `q11` value exactly equals the named surface-temperature value at both stations: 16 of 16 cycles at A and 18 of 18 at B. This is evidence of a numerical relationship, not sufficient documentation to rename `q11`.

The corresponding `q13` check is station-dependent:

- A: the zero-kilometre `q13` value exactly equals named surface humidity in 16 of 16 cycles.
- B: it equals named surface humidity in 0 of 18 cycles; absolute differences range from 0.102 to 0.210, with mean 0.1716667.

Accordingly, the Stage 1 candidate interpretation of `q13` cannot be generalized across the supplied files. `q12` and `q14` also have no supplied definitions.

No distributional value was classified as physically impossible or an outlier because units and field semantics are unresolved. Numerical ranges and uniqueness counts are inventories, not physical QC decisions.

## Encoding and metadata issues

- Station A requires different successful decodings for its microwave location line (`cp1252`) and header (`gb18030`). Its numeric records are ASCII-compatible.
- Station B's microwave location and header decode as UTF-8, but two unit strings are literally present as `??`; no decoding choice can safely reconstruct the lost characters.
- Profiler files are ASCII.
- Time-zone metadata are absent.
- Profiler `W1`–`W6`, code meanings `11`–`14`, `QCflag=9`, the profiler vertical-coordinate unit/datum, and two site metadata fields are undocumented in the supplied files.

## Issues that would invalidate a later experiment

1. **Invented field mappings.** Renaming `W1`–`W6` or `q11`–`q14` from visual patterns would make the physical analysis unsupported.
2. **Unjustified station B pairing.** Treating points separated by 32.740 km as collocated would invalidate a combined-instrument reference.
3. **Arbitrary duplicate removal or averaging.** The repeated station B cycles are distinct observations or versions of unknown status.
4. **Row-level data splitting.** Four microwave code rows from the same cycle share timestamps and named scalar fields. Splitting them between training and validation would leak cycle information.
5. **Duplicate-cycle pseudoreplication.** Counting station B repeated timestamp cycles as independent without acquisition metadata could overstate sample size.
6. **Future leakage.** With only six profiler times, random row-level or height-level splitting would put the same time profile in both training and validation. Any later temporal prediction test must split by whole time blocks and preserve chronology.
7. **Treating missing values as zero.** Upper profiler rows are unavailable, not measured zeros.
8. **Assuming `QCflag=9` is valid.** The quality-code dictionary is absent.
9. **Silent interpolation or unit conversion.** Only six exact vertical tokens align numerically under the statement-supported metre correspondence; any larger matched set requires a declared interpolation rule and confirmed datum.
10. **Overclaiming representativeness.** The supplied 00:00–00:30 subset cannot support claims about the full three-hour window, broader weather regimes, or deployment stability.
11. **Using constant opaque fields as demonstrated predictors.** `W4` and `W5` have no variation in the supplied numeric rows, so this subset cannot empirically identify their relation to any target even after semantics are obtained.

## Safe conclusions from data quality alone

The files are structurally parseable and their missingness, duplication, coordinates, timestamps, and grids can be audited reproducibly. That is the limit of the current evidence. Physical field identity, instrument QC validity, true collocation at station B, and a valid turbulence target are not established.
