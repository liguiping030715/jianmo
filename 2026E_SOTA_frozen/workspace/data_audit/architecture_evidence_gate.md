# Stage 2 evidence against frozen Stage 1.5 architecture

| Hypothesis | Status | Direct evidence / consequence |
|---|---|---|
| H1. Source-linked temporal observation is feasible | PARTIALLY_SUPPORTED | IDs, MP4 frames and transcript exist, but PKLs have no feature-to-second or word timestamps; Attachment 3 lacks IDs. OpenCV metadata and decoded frame counts disagree in 122/140 videos. Retain source-linked *index* plus mapping uncertainty. |
| H2. Valid and missing states can be separated reliably | FALSIFIED for the full official interface | Text attention and unaligned audio lengths help, but unaligned vision lengths disagree with observed support in 618 train/141 valid/131 test; Attachment 3 has no length/observed mask; boundary zeros can be padding or gaps. `R` is unsupplied. This is the critical blocker. |
| H3. Synthetic local contiguous gaps can approximate official missingness | PARTIALLY_SUPPORTED | Exact-zero interior runs strongly increase in Attachment 3 audio; multiple short runs occur. Exact type, duration and boundary semantics cannot be recovered, and special text fields differ from train. A train/valid generator can know its own injected mask but cannot claim a verified official gap distribution. |
| H4. Aligned and/or unaligned representation is usable | PARTIALLY_SUPPORTED | Both Attachment 2 versions have expected shapes and finite values; both admit restricted interface pilots. Special-set text field mismatch and unaligned vision-length error prevent a final version choice. |
| H5. Attachment 4 permits source-linked explanation at defensible resolution | PARTIALLY_SUPPORTED | Local IDs pair features with video, and feature index/token positions are available. Second-level feature mapping and word timestamps are not supplied; media frame count mismatch adds a timebase concern. No precise speech/frame locator can yet be claimed. |
| H6. Full-input teacher can train without leakage | SUPPORTED as a split protocol | Attachment 2 train/valid/test have zero sample and source-video overlap; fitting a teacher only on train and selecting on valid is possible. Its predictive quality remains untested. |
| H7. Official split supports planned validation | SUPPORTED | 3,395/728/727 split; no exact ID or video-ID overlap across them; labels align with spreadsheet. Q1 overlaps official train/test and must not be imported as new Q2/Q3 training data. |

The core Stage 1.5 representation survives as a specification, but the assumption that masks can be recovered exactly from the supplied special files is contradicted. Do not modify the frozen architecture to hide this limitation.
