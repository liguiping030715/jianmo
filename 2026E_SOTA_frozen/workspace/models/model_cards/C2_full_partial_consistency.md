# C2 — full-to-partial consistency student

**Diagnosed B1 weakness.** A state-aware student may still lose the clean prediction when a short trusted interval disappears. C2 tests whether a teacher trained on the **unmodified A2-train input** can supply useful paired clean targets. “Full” here means *no injected synthetic gap*; native zero/unknown positions remain unresolved.

| Required item | Design |
|---|---|
| 1. Exact input object | Teacher: B1's clean `aligned_50` A2-train `(text_bert,audio,vision,P,O)` only. Student: the same sample/label plus deterministic copied local-gap input and its known `injected_mask`; frozen v2 source arrays untouched. Valid is for competence and selection, never teacher fitting. A3/A4 are excluded entirely. |
| 2. Conceptual dimensions | Teacher and student each use B1's `[B,50,768]` frozen BERT states, `[B,50,74/35]` A/V, three `[B,128]` pooled states and `[B,128]` fusion. Teacher logits `[B,3]` and intensity `[B,1]` are paired with student outputs of the same dimensions. |
| 3. Encoders | Teacher is a separately fitted **B1 architecture** on clean A2 train; then frozen. Student is a separately initialized B1 architecture fitted on clean+gap A2 train. Both use the same pinned generic BERT weights, frozen during the pilot; no sentiment-trained external teacher. |
| 4. Temporal aggregation | Identical B1 content/state pooling. Teacher uses clean tokens/features, student uses post-intervention tokens/features. Text-gap BERT states are recomputed **after** replacing eligible IDs, so the student cannot see clean-word context via cached embeddings. |
| 5. Fusion | Identical B1 concatenation fusion for teacher and student. No C1 gate in the first C2 test: this isolates consistency from reliability fusion. A later combined candidate would need its own review and is not a fifth level here. |
| 6. Outputs | Same three polarity logits and `[-3,3]` intensity; teacher outputs are training targets only. Student alone would perform eventual inference. |
| 7. Loss | Student `L=λ_cls CE(y,z_S)+λ_reg Huber(v,ŷ_S)+β_cls τ² KL(softmax(z_T/τ) || softmax(z_S/τ))+β_reg Huber(ŷ_S,stopgrad(ŷ_T))`. Exactly **two** consistency targets: classification logits and regression prediction; no shared-representation target. Teacher frozen; select λ, β and τ from a small prespecified search using A2 valid only after passing competence gate. No values are fixed as final before that search. |
| 8. `P/O` handling | Teacher receives the same truthful tri-state operational inputs as B1 on clean A2; student receives `P=1,O=0` only at known injected positions. No inferred A3 mask or generator. |
| 9. Unknown-state handling | Native `P/O=2` remains unknown in both teacher and student. Primary pooling is B1 unknown-retained; unknown-excluded is a sensitivity check. Teacher “full” never means all entries are valid/observed. |
| 10. Assumptions/current evidence | A2 clean train can support a teacher if its valid clean dual-task quality is competent. Paired clean/gap copies exist without external labels. The local gap may be recoverable from remaining modalities, but distillation can also transmit teacher mistakes; this is explicitly gated. |
| 11. Parameters/compute | Two B1-sized heads (~0.18–0.20 M trainable each) with a shared specification of frozen ~110 M BERT, not two fine-tuned BERTs. Teacher clean outputs may be cached only after train fitting. Training wall time includes teacher then student and extra validation; inference cost equals one B1 student. CPU 16 GB feasibility is a gate. |
| 12. Literature/historical source | Full-to-partial consistency is a bounded adaptation of [CMAD, ICCV 2025](https://openaccess.thecvf.com/content/ICCV2025/html/Zhuang_CMAD_Correlation-Aware_and_Modalities-Aware_Distillation_for_Multimodal_Sentiment_Analysis_with_ICCV_2025_paper.html). Its reported missingness is whole-modality, so its architecture and performance do **not** transfer to local contiguous gaps. [2025D historical synthesis](../../analysis/historical_transfer_plan.md) warns against a weak teacher. |
| 13. Deliberately rejected mechanisms | No direct copy of CMAD, third representation target, reconstruction, dialogue diffusion, additional sentiment corpus, or teacher predictions on A3/A4. |
| 14. Falsification experiment | First require teacher valid clean competence against B0/B1 clean references. If it passes, compare C2 with augmentation-matched B1 and the best admissible C1 on the same valid clean/6-gap masks, three seeds; report teacher-student disagreement, gap benefit and CPU time. |
| 15. Promotion criterion | Reject immediately for weak teacher; otherwise require stable extra robustness versus the best simpler admissible model, no unacceptable clean loss, and bounded cost under [pilot plan](../../experiments/pilot_plan.md). C2 never wins solely because it mimics the teacher or improves one metric on one seed. |
| 16. Leakage risks | Teacher trained only on A2 train and never on valid/test/A3/A4. Student teacher targets come from the **same train sample's clean copy**, never from its valid label. No full-text embedding can be reused for a student text gap. A1 samples may overlap A2 test and cannot augment teacher fitting. |
