# C1 — lightweight reliability-aware dynamic fusion

**Diagnosed B1 weakness.** Even after exposing `P/O`, B1's fixed fusion may give similar weight to a modality with many trustworthy observations and one with little usable content. C1 tests whether a *small learned, sample-conditioned fusion gate* improves local-gap robustness. `R` is a model estimate, never an observed label or explanation.

| Required item | Design |
|---|---|
| 1. Exact input object | Exactly B1's frozen-v2 aligned `[text_bert, audio, vision, P, O]` object, plus the same deterministic synthetic `injected_mask` on train/valid copies. No extra quality field, A3/A4 signal, or external sentiment examples. |
| 2. Conceptual dimensions | Three B1 pooled states `h_m[B,128]`; each modality's state summary and fractions `f_m=[fraction(P=0),fraction(P=1),fraction(P=2),fraction(O=0),fraction(O=1),fraction(O=2)]∈R^6`; gate logit `r_m[B,1]`; normalized `α[B,3]`; fusion input `[B,384]`; shared `[B,128]`. |
| 3. Encoders | Identical frozen BERT and small modality-specific encoders to B1. One two-layer MLP per modality, `Linear(134→32)+GELU+Linear(32→1)`, reads `h_m` and six state fractions. The gate is the only new mechanism. |
| 4. Temporal aggregation | Identical B1 content/state pooling and unknown-retained primary mode. The gate receives the aggregated local-state pattern via `h_m` plus fractions; it never needs a fabricated official missing mask. Unknown-excluded remains a sensitivity check. |
| 5. Fusion | `α_m = softmax(r_T,r_A,r_V)_m`; feed `[3α_T h_T,3α_A h_A,3α_V h_V]` to B1's same fusion layer. Uniform gates recover B1's input scale at initialization. If a modality has no eligible content, its state summary remains defined; if all three have no content, a declared no-information fallback avoids undefined softmax. No expert bank. |
| 6. Outputs | Same classification logits and bounded regression output as B1. Classification and intensity heads may react differently to shared gated evidence; `α` is **not** either head's modality contribution. |
| 7. Loss | Same CE+Huber multitask objective as B1; no R target or self-supervised reliability label. An optional tiny entropy penalty is **not** included in the first pilot because it could force arbitrary uniformity; add it only after a diagnosed collapse and separate review. λ selection uses valid only. |
| 8. `P/O` handling | B1 rules unchanged: P0 padding, O0 known synthetic unavailability, state2 unresolved. Fractions count these codes as categories, not ground-truth quality probabilities. `zero_context=3` remains unused. |
| 9. Unknown-state handling | Unknown-retained primary, unknown-excluded fixed-weight sensitivity. Gate input contains unknown fractions, so unknown is never silently treated as missing. Native zero vectors stay unchanged. |
| 10. Assumptions/current evidence | The official task has local partial input and A2/A3 show heterogeneous observations; a gate might condition fusion on how much *known usable* evidence is present. It may still learn spurious shortcuts, so performance and gate responsiveness must be tested, not presumed. |
| 11. Parameters/compute | B1 plus about **13 K** trainable gate parameters; frozen ~110 M BERT unchanged. Gate cost is negligible against BERT; training/inference runtime should remain near B1 after equal text-cache preparation. CPU 16 GB pilot, batch 32–64, cap 12 epochs. |
| 12. Literature/historical source | Instance trust concept in [EBMC, CVPR 2026](https://openaccess.thecvf.com/content/CVPR2026/html/He_Enhance-then-Balance_Modality_Collaboration_for_Robust_Multimodal_Sentiment_Analysis_CVPR_2026_paper.html) and dynamic mixing in [EMOE, CVPR 2025](https://openaccess.thecvf.com/content/CVPR2025/html/Fang_EMOE_Modality-Specific_Enhanced_Dynamic_Emotion_Experts_CVPR_2025_paper.html). Only the small conditional-gate *mechanism* transfers. [2025D historical analogy](../../analysis/historical_transfer_plan.md) motivates checking variable source availability, not copying atmospheric weights or results. |
| 13. Deliberately rejected mechanisms | No EMOE expert bank, Gaussian uncertainty proxy, reconstruction, diffusion, class-dependent explanation from α, or whole-modality CMAD transfer. A scalar gate alone is not a local evidence locator. |
| 14. Falsification experiment | Same B1 augmentation, seeds, masks, frozen text encoder, λ budget and valid scenarios. Compare clean and paired gap metrics; log α by modality, scenario and fraction O1, gate entropy, and sensitivity when a trusted modality is ablated. |
| 15. Promotion criterion | Must exceed B1's robust prediction under the prespecified dual-task and multi-seed thresholds without material clean loss, and gates must respond to interventions without global collapse. If gains are unstable, α collapses, or runtime/capacity is not justified, reject C1. See [pilot plan](../../experiments/pilot_plan.md). |
| 16. Leakage risks | `r/α` learned from A2 train only; valid selects hyperparameters, never A3/A4. No pseudo-labels from A3, no official missing truth inferred from zeros, no attention/gate-as-explanation claim. Keep identical synthetic masks across B1/C1. |
