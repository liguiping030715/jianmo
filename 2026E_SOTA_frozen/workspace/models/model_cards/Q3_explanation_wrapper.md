# Q3 — model-agnostic intervention wrapper

**Role.** An inference/evaluation wrapper for whichever of B1, C1 or C2 survives the Stage 4 reviewer gate. It is **not** a separately trained explanation network. Here **“deletion” means the declared masking/intervention operator below**, never literal removal of source material or a real-world causal intervention. It follows the [Stage 2.5 output contract](../../evidence_recovery/explanation_contract.md) and [source-localization limits](../../evidence_recovery/source_localization.md).

| Required item | Design |
|---|---|
| 1. Exact input object | One frozen-v2 `aligned_50` sample `(id, source key, text_bert[3,50], A[50,74], V[50,35], P_m[50], O_m[50])` and a fixed trained B1/C1/C2 predictor. For Q3 use A2 valid to assess faithfulness; A4 is final inference only. Text source offsets come from A4 `raw_text` with the pinned tokenizer. |
| 2. Conceptual dimensions | Batchable base and intervened copies retain the exact predictor input dimensions. Output contains `[3]` classification logits, scalar regression, three signed classification contributions, three signed regression contributions, and zero or more modality-specific half-open index intervals `[i,j)`. |
| 3. Encoder | No new encoder: invoke the selected predictor unchanged. For each text intervention, replace token IDs **before** its frozen BERT encoder and recompute contextual states; never edit only a post-BERT vector. |
| 4. Temporal aggregation | No new pooling: invoke the predictor's own B1/C1/C2 aggregation on base, deletion, retention and matched-control inputs. Search candidate contiguous intervals only inside `P=O=1`, exclude special text tokens, and predeclare lengths `{1,3,5}` positions (shorten only at sample boundary and log). |
| 5. Fusion | No new fusion. Recompute the model's full forward pass after each intervention, including C1 gates if present. Different heads may rely on different evidence. |
| 6. Outputs | Preserve original predicted polarity/intensity plus separate `Δ_cls(m)`, `Δ_reg(m)`, `dominant_modality_classification`, `dominant_modality_regression`, top intervals, source locator/resolution/uncertainty, deletion and retention responses, matched-control response and stability summary. No guessed audio/vision seconds. |
| 7. Loss | **No training loss.** Evaluation uses model-response contrasts and faithfulness diagnostics. The predictor retains its CE+Huber training loss; the wrapper never updates parameters on A2 valid or A4. |
| 8. `P/O` handling | Only trusted `P=O=1` positions are eligible to be deleted. A deletion sets copied input `P=1,O=0` and a declared placeholder; untouched native `P/O=2` remains unknown. Never turn native zeros into missing labels. The original source and v2 arrays are immutable. |
| 9. Unknown-state handling | Unknown positions are neither selected as explanatory intervals nor silently dropped. Report their counts and, if a selected interval abuts unknown positions, lower localization confidence. Recompute B1/C1/C2 under their prespecified primary unknown policy and report sensitivity under the alternate policy where available. |
| 10. Assumptions/current evidence | A4 local IDs pair the feature file and MP4. Token offsets/phrases are defensible where raw text is present; existing A/V feature indices cannot be mapped to verified video/audio seconds. Perturbations reveal model dependence, **not causal influence** or human emotional reasoning. |
| 11. Parameters/compute | **Zero trainable parameters.** Inference cost is roughly one base pass plus three full-modality deletions and a bounded number of candidate/matched-control/retention passes. Freeze a maximum interval budget per sample in the pilot plan; text changes require BERT recomputation, so cache by exact intervened token IDs only. |
| 12. Literature/historical source | Modality ablation, perturbation, sufficiency/comprehensiveness and stability mechanisms in [Stage 1.1 scan](../../references/sota_literature_scan.md), with limitations surveyed in [Computational Linguistics 2024](https://aclanthology.org/2024.cl-2.6/). [2025E historical pattern](../../analysis/historical_transfer_plan.md) transfers claim-matched validation, not SHAP scores or bearing semantics. |
| 13. Deliberately rejected mechanisms | No attention-weight or C1 gate-weight “explanation”; no large saliency network, feature reconstruction, raw-video counterfactual, guessed word timestamps, or assumption that contributions add to 100%. Gradient attribution may be a later diagnostic but is not this wrapper's primary evidence. |
| 14. Falsification experiment | On a prespecified A2-valid explanation subset, compare each top interval's deletion response with equal-length same-modality/same-position-band controls; test retention/sufficiency and five repeated reference/perturbation draws; bootstrap by source video. Reject strong source-evidence wording if top intervals are no better than controls or ranks/locations are unstable. |
| 15. Promotion criterion | Wrapper can support Q3 claims only if the trained predictor itself passes the prediction gate and intervention evidence exceeds matched controls with stable target-specific rankings. Otherwise output honest low-confidence/`no_dominant_modality` records, not forced interpretation. |
| 16. Leakage risks | Select interval budget, intervention reference and comparison rule on train plus valid protocol, never from A4 outcomes. Do not use valid labels to pick per-sample evidence; labels only assess aggregate faithfulness/prediction. Do not create exact media times from 50/500 indices or use Q1 overlapping clips as extra predictor training data. |

## Fixed response definitions

Let `c*` be the unperturbed argmax class and `s_cls(z;c*) = z[c*] − logsumexp_{k≠c*} z[k]`. Keep `c*` fixed when evaluating interventions, even if the predicted class flips. For modality `m`,

`Δ_cls(m) = s_cls(z_full;c*) − s_cls(z_delete(m);c*)`;

`Δ_reg(m) = ŷ_full − ŷ_delete(m)`.

The classification dominant modality is the largest **positive** `Δ_cls`; if none is positive beyond matched-control variation, report `none/tie`. Regression dominance is the largest `|Δ_reg|`, with sign retained and `none/tie` if indistinguishable from controls. These rankings need not agree and are not additive: cross-modal interactions remain in the response.

Use the **same declared deletion operator** for modality and interval tests. For text, replace eligible token IDs by `[UNK]` before BERT; for A/V, replace eligible standardized feature rows with the zero placeholder; set only intervened `O=0` and leave `P=1`. Retention keeps the selected trustworthy intervals and intervenes on the other trustworthy positions; unknown positions remain unchanged. Report both changed and unchanged logits/intensity. Matched controls have the same modality, interval length, and early/middle/late band. For stability, repeat the full interval ranking under five independently seeded, clipped `N(0,0.01²)` perturbations of **other trusted A/V feature rows** in train-standardized units, without altering P/O or text; also redraw the matched-control intervals. This tests a narrow nuisance perturbation, not guaranteed semantic/label preservation or lexical stability. If the base class changes under a draw, log the flip rather than discarding it. The wrapper outputs feature intervals `[i,j)` for A/V and phrase/token spans for text, with `time_seconds=null` where the feature-to-media map is absent.
