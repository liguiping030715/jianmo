# M1 — same MulT-style backbone with audited observation adapter

Hypothesis H12: explicit tri-state P/O embeddings and defensible known-unavailable attention exclusion improve local-gap robustness over M0, while preserving unknown states as unknown. It consumes the same native A2 train/valid tensors and has the exact same projection width, heads, attention depth, fusion, heads, loss, optimizer, schedule, mask bytes and seeds as M0. Its only addition is P/O state embeddings and their declared attention/pooling policy. Zero feature magnitude is never turned into missingness; native `P=2/O=2` rows remain available, and synthetic gap `O=0` is a known artificial unavailability. The adapter is a representation/interface hypothesis, not an estimate of the official hidden mask.

Frozen clean guards, paired gap gains, seed and scenario consistency are in [q2_bridge_plan.md](../../experiments/q2_bridge_plan.md). M1 is rejected if those fail even if one metric or seed improves. The transfer is from the task's audited P/O contract and the need for explicit availability; any literature analogy is mechanism-level only. No A3/A4 labels, external sentiment data, recovery network or reconstruction objective is used.
