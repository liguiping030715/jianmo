# B0 — complete-input reference

**Role.** Smallest credible shared-representation predictor on the frozen `aligned_50` Attachment 2 interface. It is a reference, not a robustness claim. No teacher, explicit observation state, reliability gate, reconstruction, or expert mixture. See [pilot plan](../../experiments/pilot_plan.md) for prespecified comparisons.

| Required item | Design |
|---|---|
| 1. Exact input object | One A2 sample: `text_bert[int64,3,50]` in `[input_ids,attention_mask,token_type_ids]` order; frozen-v2 `audio[50,74]`, `vision[50,35]`; IDs and targets from train/valid metadata. Basic `P==0` padding exclusion only; no `O`, `zero_context`, A3/A4, or precomputed A2 `text` input. |
| 2. Conceptual dimensions | Batch `B`: BERT states `T[B,50,768]`; audio `A[B,50,74]`; vision `V[B,50,35]`; per-modality sequence state `[B,50,128]`; pooled modality state `[B,128]`; concatenation `[B,384]`; fused state `[B,128]`. |
| 3. Encoders | Pin and **freeze** the verified `bert-base-uncased` encoder; project each contextual token `768→128`. For audio and vision, separate position-wise `Linear(74→128)` and `Linear(35→128)` with GELU. Add a learned 50-position vector before GELU so early/middle/late observations need not be identical. No Transformer for audio/vision. BERT is a permitted generic pretrained text tool, not external sentiment training. |
| 4. Temporal aggregation | Arithmetic mean of encoded positions, excluding only verified `P=0` padding (text attention; none proven for aligned audio/vision). Include all ambiguous audio/vision zeros as numeric input. Empty eligible sets return a fixed zero pooled vector and an explicit empty flag in logs. |
| 5. Fusion | Concatenate three pooled states; one `Linear(384→128)+GELU` shared state. Equal architectural access to modalities; no learned reliability gate. |
| 6. Outputs | `Linear(128→3)` logits for Negative/Neutral/Positive, argmax class; separate `Linear(128→1)` with `3*tanh` for bounded intensity `[-3,3]`. Heads may rely on different components of shared state. |
| 7. Loss | `λ_cls*CrossEntropy(logits,class)+λ_reg*Huber(intensity,target)`; unweighted CE is the primary classification loss and Huber the primary bounded-rating regression loss. A2 train class counts are Positive 1,670, Negative 967, Neutral 758: uneven but no class is vanishing, so begin without class resampling and assess macro-F1/neutral recall. Choose λ only by the prespecified A2-valid rule in the pilot plan; do not fit them to A3/A4. |
| 8. `P/O` handling | Uses `P=0` solely for ordinary padding bookkeeping; collapses `P=1/2` for content pooling. It does not receive `O`. In a synthetic-gap diagnostic, the same B0 architecture sees the intervention placeholder but not its mask. |
| 9. Unknown-state handling | Unknown native zeros remain untouched and are numerically pooled. No assertion that zero means missing. B0 cannot distinguish injected placeholders from native zeros; this is the diagnosed weakness. |
| 10. Assumptions/current evidence | A2 aligned has 3,395 train and 728 valid samples, consistent `[50]` coordinate, finite 74/35-dimensional A/V and executable common text encoder. Aligned positions are index correspondence, not measured word/frame seconds. The baseline tests whether simple per-stream summaries predict both targets at all. |
| 11. Parameters/compute | Approximately **0.18 M trainable parameters** plus ~110 M **frozen** BERT parameters (exact count to be logged on implementation); CPU 16 GB/24 logical processors, `torch 2.4.1+cpu`, batch 32–64, 12-epoch cap. Frozen BERT states may be cached **only after** any text intervention; never reuse a clean contextual embedding for a text-gap sample. No external training data. |
| 12. Literature/historical source | Baseline-first and controlled improvement discipline: [Stage 1.2 historical retrieval](../../analysis/historical_transfer_plan.md) and [Stage 1.1 mechanism matrix](../../references/sota_method_matrix.md). The official aligned representation, rather than a paper's architecture name, motivates this simple comparator. Historical formulas/scores are not transferred. |
| 13. Deliberately rejected mechanisms | Cross-modal Transformer, soft alignment, MoE, distillation, reconstruction, invariant-factor loss, reliability estimation, and attention-as-explanation: none is necessary to establish the reference. |
| 14. Falsification experiment | Train on A2 train, select by A2 valid, evaluate clean and the six fixed synthetic gap scenarios. Reject B0 as an *adequate final robust model* if gaps cause material paired degradation or clean dual-task performance is poor; keep its reference results regardless. |
| 15. Promotion criterion | **Reference only**; B0 is never promoted by novelty or one favorable metric. It anchors clean performance, augmentation-matched comparison and runtime. |
| 16. Leakage risks | No A2 test/A3/A4 selection; no A1 labels or Q1-derived features in Q2/Q3 fitting; train-fitted v2 scaling only. Synthetic validation masks must be predeclared and identical for all models. Cache keys must include token IDs after intervention so original text cannot leak into a gap condition. |

**Training-condition control.** The primary B0 run uses complete supplied inputs. A **B0 architecture with the same train gap augmentation as B1** is a diagnostic control, not a fifth model level; comparing B1 only with clean-trained B0 would confound observation-state information with augmentation exposure.
