# B1 — tri-state mask-aware baseline

**Diagnosed B0 weakness.** B0 numerically conflates native zero, simulated local absence, and unresolved position. B1 retains the same frozen BERT, small modality encoders, fusion and two heads, while exposing the [observation contract](../../evidence_recovery/observation_contract.md) states.

| Required item | Design |
|---|---|
| 1. Exact input object | B0 tensors plus per-modality `P_m,O_m ∈ {0,1,2}^{B×50}` from frozen v2. For A3 aligned text only, derive attention-based P and ID-100 `O=2` **in memory** as contracted; A3 is never used for fitting/selection. Synthetic train/valid gaps create an additional `injected_mask` kept separate from original P/O and set `P=1,O=0` only at selected trusted positions. |
| 2. Conceptual dimensions | B0 `T/A/V` states; three P and three O one-hot channels or equivalent 128-wide learned categorical embeddings per stream/time; content and state summaries each `[B,128]`, combined per-modality `[B,128]`; concatenated `[B,384]`; shared `[B,128]`; heads 3 and 1. |
| 3. Encoders | B0 modality-specific frozen BERT/projector and per-position A/V projectors. At each position add separate learned embeddings `e^P_m(P_mt)+e^O_m(O_mt)` to the projected state before GELU. Include the 50-position vector. Use a separate state-only summary, so an injected `O=0` interval is visible even when its content is excluded. |
| 4. Temporal aggregation | `h_m = mean_{t:q_mt=1} GELU(W_m x_mt+p_t+e^P+e^O) + mean_{t:P_mt≠0} GELU(p_t+e^P+e^O)`. A zero denominator yields a zero content summary and logged empty flag. For text `x` means **BERT states recomputed from intervened token IDs**, never clean cached states. |
| 5. Fusion | Same concatenation and `Linear(384→128)+GELU` as B0. The only added mechanism is explicit tri-state information and its pooling rule; no reliability weights. |
| 6. Outputs | Same three logits/argmax polarity and separate bounded `3*tanh` intensity head as B0. |
| 7. Loss | Same CE + Huber multitask loss and A2-valid λ-selection rule as B0. Train on a prespecified mixture of clean A2-train examples and deterministic synthetic local-gap copies; do not use A3/A4 to design the mixture. |
| 8. `P/O` handling | `P=0` is the sole hard padding exclusion. Known synthetic absence is `P=1,O=0`; native `P=O=2` remains unknown. Trusted content is `P=O=1`. `zero_context=3` is never supervised. |
| 9. Unknown-state sensitivity | **Retained:** `q=(P≠0)∧(O≠0)`, so `P/O=2` content stays with explicit unknown embeddings. **Excluded (R1x):** `q=(P=1)∧(O=1)`, while the state-only summary still records every unknown position. R1x is **inference-time only with the identical fitted R1 weights**. Any separately refitted unknown-excluded model is post-pilot sensitivity and cannot affect promotion. Neither mode declares unknown to be missing. Known `O=0` content is excluded in both. |
| 10. Assumptions/current evidence | A2 text attention is trustworthy; aligned A/V nonzero rows are usable but zero rows ambiguous; A3 has no official hidden mask. The interface is a *restricted pilot* with declared uncertainty, not exact gap recovery. Position-wise encoding avoids claiming measured seconds. |
| 11. Parameters/compute | B0 plus six categorical embedding tables (roughly **2–4 K** additional trainable values); same frozen ~110 M BERT and essentially the same head cost. Text-gap copies require separate frozen-BERT forward passes. CPU estimate and cache protocol are in pilot plan. |
| 12. Literature/historical source | Direct mask-aware incomplete-input principle in [DQF, WACV 2026](https://openaccess.thecvf.com/content/WACV2026/html/Miyoshi_Robust_Multimodal_Emotion_Recognition_from_Incomplete_Modalities_via_Query-Based_Unimodal_WACV_2026_paper.html), bounded by [negative-transfer audit](../../analysis/negative_transfer_audit.md): the paper's missingness granularity is not assumed to match local A3 gaps. Historical 2025E contributes split-safe validation organization, not a network. |
| 13. Deliberately rejected mechanisms | No learned R, expert routing, teacher, reconstruction or imputed signal. Hard zero→missing labels and unaligned `vision_lengths` truncation are forbidden. |
| 14. Falsification experiment | Paired clean/6-gap valid comparison against both B0-clean and **augmentation-matched B0** with identical seeds, masks, λ search budget and BERT cache semantics. Repeat three seeds; evaluate unknown retained versus excluded. |
| 15. Promotion criterion | Follow [pilot plan](../../experiments/pilot_plan.md): material gap macro-F1 and MAE benefit over augmentation-matched B0 in multiple seeds/scenarios, within clean-performance guards. If state sensitivity reverses conclusions, report that instability and do not promote. |
| 16. Leakage risks | Build gaps solely from A2 train for fitting and A2 valid for stress testing; only `P=O=1` runs eligible. Never fit on A3/A4, infer `O=0` from zero values, cache full-text BERT states for altered text, or select unknown mode by A3 outcomes. Source-video grouping and train-only scaling stay intact. |

**Text intervention detail.** In a known synthetic text gap, replace only eligible non-special token IDs with the tokenizer's `[UNK]` ID **before** frozen BERT, retain attention `P=1`, and set injected positions `O=0`. This is a declared training perturbation, not a claim that it reproduces A3's generator. Audio/vision gap copies set the selected standardized feature rows to a declared zero placeholder and `O=0`; original frozen-v2 arrays are never changed.
