## 3. 预注册 D0 gate 机械判定

| 条款 | 结果 |
|---|---|
| clean F1 不低于 R1 超过 0.01（ΔF1 ≥ −0.01） | True（-0.0007） |
| clean MAE 不高于 R1 超过 0.02（ΔMAE ≤ +0.02） | True（-0.0007） |
| 至少一个任务实际改善（ΔF1≥+0.015 或 ΔMAE≤−0.015） | **False** |
| 改善方向 2/3 seed 一致 | True（F1 正向 seed 1、MAE 改善 seed 2） |
| 拆东墙补西墙（一任务改善以另一任务明显退化为代价） | False |

**D0 gate 结果：False → H8 NOT_SUPPORTED。**

D0 与 R1 在两个目标上都仅相差约 ±0.001（统计上基本持平），未达到任一任务 +0.015 的实际改善门槛，
任务特定融合没有可测收益。
