**Boundary.** This is a design for later review, not Stage 4. Train no model now; do not read A2 test outcomes or use Attachment 3/4 for model choice. Keep `workspace/data/processed/cleaning_2026e_v2/` immutable and use its aligned version as the primary `aligned_50` interface. The reviewer wrote `unaligned_50`; the supplied unaligned A/V arrays actually have **500** positions, so the secondary comparison is called `unaligned_500` without truncating it to 50. Evidence/limits: [observation](../evidence_recovery/observation_contract.md), [text](../evidence_recovery/text_interface.md), [explanation](../evidence_recovery/explanation_contract.md), [readiness](../evidence_recovery/stage2_5_readiness.md).

## Data, losses and common training budget

- **Data:** A2 aligned train 3,395, valid 728. Official A2 test, A3 and A4 are untouched until a later final-inference decision. Same sample ID, labels, scaler, text encoder and train/valid split for all aligned comparisons. Q1 Attachment 1 is not extra training data.
- **Inputs:** `text_bert[B,3,50]`, `audio[B,50,74]`, `vision[B,50,35]`, `P/O[B,50]` for each modality. B0 uses only known padding P0. All models share pinned frozen `bert-base-uncased`; the model sees **intervened token IDs before BERT**. Derived BERT caches, if used, are keyed by exact token IDs and are stored outside frozen v2.
- **Targets:** class `negative` if rating `<0`, `neutral` if `=0`, `positive` if `>0`; regression target is the original rating in `[-3,3]`. CE over three logits and Huber on bounded `3*tanh` output. No labels altered. No class sampler in this first pilot; if neutral recall fails, that is a diagnosed later choice, not a silent preprocessing change.
- **Multitask weights:** Do not fix final λ now. Compute the initial CE/Huber scale ratio `q` on **train only** with the B0 seed-1729 initialization; test only `λ_cls=1, λ_reg∈q×{0.5,1,2}` in three **3-epoch B0 clean warmups**. Choose once on A2-valid clean by Pareto ordering of macro-F1 (higher) and MAE (lower), with Accuracy/Pearson as noninferiority guards; if nondominated candidates tie, take the middle ratio. Then run the full-cap R0 seed-1729 baseline with that choice. Freeze the chosen λ pair across B0/B1/C1/C2 so mechanism comparisons do not gain separate loss-search budgets. Save all three valid results, not just the winner.
- **Seeds/batches:** training seeds `1729, 2718, 31415`; deterministic per-sample mask seed from SHA-256 of `(version, split, original_id, scenario, global_seed)` (never Python's process-randomized `hash`). Frozen BERT cache batches 16–32; trainable heads batches 32–64, chosen once after a memory smoke check and then equal across aligned models.
- **Budget/stop:** maximum 12 epochs per fitted network, patience 3. Use AdamW, learning rate `0.001`, weight decay `0.0001`, Huber transition `δ=1`, and head batch size `64` unless the Step 0 memory smoke test requires a lower batch from the prespecified 32–64 range. The learning rate is a fixed common pilot implementation value, not tuned after seeing candidate results. Checkpoint on a predeclared valid composite of clean and selection-mask CE+Huber, not on A3/A4. C2 teacher is trained and gated first; skip C2 student if teacher fails. Three seeds are required for promotion even if an early seed looks good.
- **Hardware estimate:** observed host has 16 GB RAM, 24 logical CPUs, PyTorch 2.4.1 CPU build, no CUDA. BERT dominates. Cache frozen-BERT states for exact clean/intervened token sequences in float32 after checking disk/RAM; estimate ~1–3 hours for the complete three-seed CPU screening, with a 15–30 minute first-seed budget check. These are planning bounds, not measured runtime. Stop a candidate if a single seed exceeds the prespecified 2-hour wall-time cap or memory exceeds 14 GB; record failure. Exclude caches and pretrained weights from the ≤50 MB final submission package unless later rules explicitly allow packaging them.

## Synthetic local-gap protocol

Use the frozen [local-gap specification](../data_audit/local_gap_protocol.md) with the Stage 2.5 correction: **eligible positions are only contiguous runs of `P=O=1`**. Do not inject into native zero/unknown (`2`) or padding (`0`); do not train on `zero_context=3`. For text, exclude `[CLS]`, `[SEP]` and padding, replace eligible IDs with `[UNK]` **before** BERT, and set copied `O=0,P=1`. For audio/vision, replace selected standardized feature rows by a declared zero placeholder and set copied `O=0,P=1`. Preserve an independent Boolean `injected_mask`; never infer it from the placeholder. Frozen v2 files stay unchanged.

For a chosen modality set, find eligible contiguous positions in each selected modality. The scenario's early/middle/late band refers to thirds of the trusted observed support in that modality, **not verified media seconds**. Request a contiguous span of approximately 10%/25%/40% of its eligible support for small/medium/large. Select a span in that band with the deterministic seed; for two modalities prefer overlapping aligned indices and record overlap. If the requested span cannot fit, use the largest feasible nonzero span in-band and record the realized support ratio; if none exists, mark `not_injectable`, retain the sample unchanged in the full-valid ledger, and exclude it only from the **paired conditional gap metric** with its count reported. This is an evaluation condition, not dataset cleaning or sample deletion. Never claim the simulator reproduces A3's hidden generator or use A3 to choose ratios.

**Small balanced six-scenario screen** (each position and severity occurs twice; each modality participates three times). **S1–S6 are only a model-screening design.** Modality, position, duration and missing ratio are coupled in these six rows; results cannot identify their independent effects or interactions. Controlled factorial analysis of those factors is reserved for Stage 6/7 and is outside this pilot:

| ID | Modalities | Position band | Severity | Requested support ratio |
|---|---|---|---|---:|
| S1 | T | early | small | 10% |
| S2 | A | middle | medium | 25% |
| S3 | V | late | large | 40% |
| S4 | T+A | late | medium | 25% each |
| S5 | T+V | middle | large | 40% each |
| S6 | A+V | early | small | 10% each |

Generate **one clean and one gap copy per A2-train sample and seed**, assigning S1–S6 approximately equally via the stable hash; retain all originals. Create one fixed selection-mask draw and one independently seeded audit-mask draw per A2-valid sample/scenario. All aligned models receive byte-identical mask manifests and placeholders for a given seed/scenario. Select hyperparameters/checkpoints using clean + selection-mask valid; report audit-mask metrics as a pilot diagnostic, acknowledging that the same valid labels are involved. No A2 test or special set participates. For `unaligned_500`, exact per-index mask equality is impossible because coordinates differ; use the same IDs, scenario names, support ratios and seeds, publish its native-index masks, and treat results as a secondary, non-isomorphic comparison.

RU uses the same frozen BERT/raw-text pathway, separate lightweight per-position A/V projections over 500 positions, P/O state summaries, masked mean pooling, concatenation and two heads. It does not trust `vision_lengths` for truncation and does not infer media seconds from 500 positions. One architecture, one primary unknown-retained policy, no cross-time attention search. Its increased time dimension raises pooling cost but not BERT token length.

R1x uses the **same fitted R1 checkpoint** and changes only the unknown-position content pooling rule at inference. Any separately refitted unknown-excluded model belongs to a post-pilot sensitivity study and cannot change this pilot's promotion decision.

## Metrics, failure evidence and promotion rules

For **each** run/seed/scenario report Accuracy, **macro-F1** (primary F1), weighted F1 as a secondary descriptor, MAE, Pearson, class counts/confusion, n eligible and n `not_injectable`. Pearson is `undefined` if predictions or labels are constant. Use the paired eligible subset for each scenario's clean-to-gap degradation: `ΔAccuracy=Acc_gap−Acc_clean`, `ΔF1=F1_gap−F1_clean`, `ΔMAE=MAE_gap−MAE_clean`, `ΔPearson=ρ_gap−ρ_clean`. Negative ΔAccuracy/F1/Pearson and positive ΔMAE are degradation. Report full-valid clean metrics separately; never compare a conditional gap subset with an unrelated full-valid clean denominator. Aggregate across six scenarios with equal scenario weights and bootstrap source-video groups with fixed seed for 90% intervals. Save per-sample predictions and exact mask IDs so metrics can be regenerated.

**Frozen pilot promotion gates** (pilot thresholds, to be reviewed *before* Stage 4; no retrospective threshold changes):

1. **B0:** reference only. Report R0 and R0a; neither is promoted by itself.
2. **B1 versus R0a:** averaged across the six paired audit scenarios, macro-F1 improves by at least **0.015** and MAE falls by at least **0.025**, while the clean-to-gap F1 drop shrinks by at least **0.010** and MAE increase shrinks by at least **0.015**. Directions must hold in at least **2/3 seeds** and **4/6 scenarios**; paired source-video bootstrap 90% intervals for average gap F1 and MAE differences must favor B1. Clean Accuracy and macro-F1 may fall by at most **0.02**, MAE may rise by at most **0.05**, Pearson may fall by at most **0.03** relative to R0a. If R1x reverses the principal conclusion, mark unknown handling unstable and do not promote.
3. **C1 versus B1:** average gap macro-F1 gain at least **0.010**, MAE reduction at least **0.015**, and smaller degradation on both targets (F1 drop by **0.005**, MAE increase by **0.010**); same 2/3-seed, 4/6-scenario and 90%-interval directions, with the same clean guards. Reject if a gate assigns >0.95 to one modality for >90% of clean samples in all seeds without a measured benefit, if gates fail to respond when that modality is deliberately removed, or if wall time/memory exceeds the cap.
4. **C2 teacher gate:** on clean A2 valid the teacher must be noninferior to B0-clean in both macro-F1 (within **0.01**) and MAE (within **0.03**) over at least two seeds; otherwise no student is run. **C2 student:** against the *best admissible simpler* B1/C1 comparator, require the same additional dual-target improvement, degradation, seed/scenario and clean guards as C1. Student inference must cost no more than **1.5× B1**; teacher+student pilot fitting must stay within **2× B1 fitting time after shared text-cache preparation**. Reject if teacher mistakes dominate or compute exceeds bounds.
5. **RU promotion:** require a paired 3-seed valid improvement in **both** targets (macro-F1 ≥ **+0.02**, MAE ≤ **−0.03**) *or* a ≥**15%** reduction in both F1 and MAE gap-degradation magnitudes, with other clean metrics within B1's guards; additionally show a useful, stable source-feature interval/faithfulness gain over aligned on the Q3 wrapper audit, not merely “500>50” positions. Keep peak RAM <14 GB and inference <3× aligned B1. If visual zeros/length semantics require silent truncation or second-level claims, RU cannot advance.

These thresholds are screening choices, not promised effects. Accuracy and Pearson are guard/diagnostic metrics alongside F1 and MAE; no model is promoted from one metric, one seed, or A3/A4 behavior. If bootstrap intervals are wide, mark evidence inconclusive instead of forcing promotion.

## Q3 wrapper audit, outputs and stop conditions

Before any A4 inference, take a deterministic, source-video-grouped and class-stratified **60-sample A2-valid subset** selected without model predictions. On B1 and any promoted C1/C2, use the [Q3 wrapper](../models/model_cards/Q3_explanation_wrapper.md): full-modality deletion, local interval deletion, retention/sufficiency, equal-length same-band controls, and five repeated clipped 0.01-standard-unit nuisance perturbations on other trusted A/V rows, with matched controls redrawn. For each target, save signed modality response, top interval, control distribution, retention response, rank stability, class flips and source locator resolution. Cap at **18 candidate intervals per modality per sample** (predeclared `{1,3,5}` lengths, up to six deterministic windows per length); log if fewer eligible. No audio/vision feature-to-second timestamp is asserted. This is an explanation-faithfulness screen, not new model training.

Every later run should write `workspace/experiments/pilot_runs/<run_id>/config.json`, `mask_manifest.jsonl` with exact intervals and hash, `training_log.jsonl`, `metrics.json`, `predictions_valid.jsonl`, `failures.jsonl` (including empty success file), environment/encoder checksums and checkpoint reference. Aggregate comparison tables belong in `workspace/results/pilot/`; generated figures, if any, in `workspace/figures/`. Failed/partial runs remain visible. A budget, OOM, nonfinite loss, empty eligible group, class collapse, or undefined Pearson is logged explicitly. **No such pilot run or results are produced in Stage 3.**
