# Visualization

Before generating major figures, create or update `workspace/analysis/figure_plan.md`.

For every figure record:

- question answered,
- source result file,
- generating script,
- axes/units,
- comparison groups,
- uncertainty if relevant,
- one supported takeaway,
- target paper section.

Prefer figures that perform one of these jobs:

- explain the problem/model,
- show data structure,
- compare baseline vs improvement,
- validate predictions or reconstruction,
- reveal sensitivity/robustness,
- show a decision frontier/tradeoff,
- communicate the final decision.

Avoid decorative plots that consume space without supporting a claim.
Never manually type result numbers into plots.
