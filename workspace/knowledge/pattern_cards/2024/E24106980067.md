# Card: E24106980067（西安交通大学）高速公路应急车道紧急启用模型

## 0. 元数据
- 年份/题号：2024 E 题
- 学校：西安交通大学

## 1. 问题指纹
- 同 E 题。特色：**检测模型改造（SE注意力+BottleneckCSP）+ Sigmoid标准化拥堵指数五级 + TCNAt-BiGRU预测**。

## 2. 信息流
```
Q1(1): YOLOv5+SE注意力+BottleneckCSP+DeepSORT → q/u/ρ
Q1(2): Sigmoid标准化拥堵指数+五级 → TCNAt-BiGRU预测q/u → 拥堵波实时预警
Q1(3): 第一段训练第二段测试 → MSE/RMSE/MAE/MAPE → 提前10分钟预警
Q2: 激波方向+标准化指数 → 开/关决策条件
```

## 3. 分问拆解
- Q1(1)：YOLOv5加 **SE注意力模块** 提精度；**BottleneckCSP替换C3** 防过拟合；DeepSORT按ID跟踪，帧间中心距离算速度，设基准线算流量。
- Q1(2)：在基本拥堵指数公式上推导 q/u/ρ 拥堵指数；**Sigmoid标准化消除异常值** → 分五级；**TCNAt-BiGRU**（TCN提时序+SK-Net注意力+双向GRU）预测流量速度；用**拥堵波**传播做节点间实时预警。
- Q1(3)：第一段视频训练、第二段测试，四指标(MSE/RMSE/MAE/MAPE)评估，提前10分钟预警。
- Q2：开/关条件显式写：激波速度大+指上游影响→开；标准化指数回落到临界值、车速恢复、激波向下游衰减→关。

## 6. 可迁移 Pattern
> **"检测模型提分三板斧：注意力模块(SE/SK) + 改进backbone(BottleneckCSP) + 残差防过拟合"；"拥堵指数要做Sigmoid标准化去长尾，再分级"；"时序预测TCN+注意力+BiGRU组合"；"开关决策用双向条件（什么时候开+什么时候关），别只写开"。**

## 7. 局限
- 模型组合偏重，小数据集易过拟合，需严格留出测试段；
- 拥堵波理论参数依赖交通流标定。
