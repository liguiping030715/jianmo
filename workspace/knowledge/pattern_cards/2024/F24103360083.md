## 0. 元数据
- 队号 F24103360083，武汉大学，题目：X 射线脉冲星导航（XPNAV-1 / Crab 脉冲星）

## 1. 问题指纹
- 四问：轨道六根数→GCRS 位置速度 → 真空几何时延 → 含相对论效应的总时延 → 光子序列仿真与脉冲轮廓。
- 真正困难：①多坐标系（PQW/GCRS/BCRS）严格变换；②多个物理时延量级悬殊、符号易错；③非齐次泊松点过程的高效仿真。

## 2. 数学抽象链
```
Q1: 六根数(e,h,Ω,i,ω,θ) → PQW(近地点坐标系)
    r=a(1-e²)/(1+e cosθ),  r_PQW=[r cosθ, r sinθ, 0]
    旋转 R=Rz(Ω)·Rx(i)·Rw(ω) → r_GCRS=R·r_PQW
Q2: 赤经赤纬→单位方向 n=[cosαcosδ, sinαcosδ, sinδ]
    脉冲星位置=D·n (D=6500光年); d1=|r_pulsar−r_sat|; d2=|r_pulsar,BCRS|
    Roemer: Δt=|d1−d2|/c = 277.9s
Q3: 总时延 = 自行 + Roemer(点乘投影 r·n/c=473.9s)
           + Shapiro(引力弯曲) + 引力红移 + 动钟变慢
Q4: 背景=齐次泊松; 脉冲=非齐次泊松 λ(t)=λb+λs·h(φ(t))
    仿真: 蒙特卡洛削减 → 拒绝采样 → Ogata Thinning
    相位计时模型 φ(t)=φ0+νΔt+½ν̇Δt²+⅙ν̈Δt³ → 历元折叠出轮廓
```

## 3. 为什么每个模型/算法被选
- **PQW 先建轨道平面坐标**：六根数唯一确定轨道平面，平面内运动最简单，再旋转到 GCRS。
- **Roemer 两种算法**：Q2 用距离差（直观），Q3 改进为点乘投影（避免开根号、计算量小、数值误差小）。
- **Shapiro/红移/动钟变慢分别建模**：物理起源不同（广义相对论引力弯曲、势能差、狭义相对论），各自有标准公式。
- **三种 NHPP 仿真算法递进**：蒙特卡洛削减最基础；拒绝采样用 h/hmax 判接受；Ogata Thinning 用指数分布生成候选+按 λ(t)/λmax 筛选，效率最高。
- **历元折叠**：信号微弱、单周期测不到，把上万周期光子折叠叠加提信噪比。

## 9. 章节承接技法
- Q1 卫星位置 → Q2 距离计算的输入；Q2 Roemer → Q3 总时延的一项；Q3 时延校正 → Q4 相位计时模型。链条严格递进。

## 10. 弱点 / 可疑论断（深读发现）
1. **假设与模型自相矛盾**：假设2 写"光速恒定、不受引力场影响"，但 Q3 恰恰计算 Shapiro 引力弯曲时延——假设直接被后续模型推翻。
2. **Shapiro/红移/动钟变慢全为负值**（−6.63e−6 等）：Shapiro 物理上应是正延迟，负号暴露参考点/符号定义问题，论文仅以"影响极小所以合理"带过，未深究符号。
3. **大数相减的精度隐患**：d1、d2 均为 6.15e16 km（脉冲星 6500 光年），相减得 277s，两个 17 位数量级的数相减对浮点精度极敏感，未见误差分析。
4. 背景光子"完全均匀"假设过强；改进算法精度提升仅 0.0006 相关系数，实际意义有限。
5. 自承高度椭圆/不规则轨道准确性下降、需大量实测校准。

## 11. 可迁移条件 vs 不可迁移
- **可迁移**：坐标系分步旋转（Rz·Rx·Rw）推导；物理效应逐项建模再求和；同一过程多仿真算法按效率+精度对比；用守恒律（能量/角动量）验证；NHPP 的 Ogata Thinning；历元折叠从微弱信号提周期轮廓；直观算法→点乘投影的简化。
- **不可迁移**：Crab 的 D/赤经赤纬/流量参数；具体时延数值；负号处理方式（本例存疑）。
