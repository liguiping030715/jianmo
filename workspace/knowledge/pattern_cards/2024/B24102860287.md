# Card: B24102860287（东南大学）WLAN 组网中网络吞吐量建模

## 0. 元数据
- 年份/题号：2024 B 题
- 学校：东南大学
- 篇幅：约 90 页

## 1. 问题指纹
- 表面任务：基于 WLAN 实测数据，预测 AP 发送机会、PHY Rate（MCS,NSS）、系统吞吐量。
- 真实困难：**数据脏 + 多实验批之间不齐 + 特征相互耦合**（SINR 不是单样本属性，而是同次实验多个 AP 互相影响）。
- 题型标签：数据清洗 + 特征重要性排序 + 多分类（MCS,NSS）+ 回归（吞吐量）。

## 2. 信息流
```
Q1: 原始实测数据 → 分2AP/3AP建模 → RF特征重要性 → AP发送机会预测
Q2: 多行互相影响的SINR → Akima插值对齐 → 残差CNN → (MCS,NSS)分类
Q3: (MCS,NSS) + 干扰/丢包 → 1D-CNN → 吞吐量回归
```
关键：Q2 的 (MCS,NSS) 是 Q3 的输入特征。

## 3. 分问拆解

### Q1 发送机会影响因素排序 + 预测
- 数据清洗三件套：异常值处理、缺失值填补、特征标准化；
- **按 AP 数量分组（2AP/3AP）分别建模**——避免混合后特征分布漂移；
- 随机森林回归做特征重要性：AP-AP 间 RSSI 影响最大（2AP:87.96%、3AP:74.94%），其余依次 AP-STA RSSI、协议类型、拓扑、信号功率、NAV门限、BSS编号。

### Q2 预测 (MCS,NSS)
- 关键洞察：**SINR 与同次实验其他样本有关**——不能把每行当独立样本；
- Akima 插值把 RSSI 测量统一到 540 个采样点；
- **残差连接优化的 CNN** 分类，验证集准确率 86.73%。

### Q3 吞吐量预测
- 1D 卷积提特征 → 池化降维 → FC → Adam；
- 干扰下理论 vs 仿真误差 <5%；
- **CDF（累积分布函数）评估精度**，2AP/3AP 验证集 >95%。

## 4. Baseline → 改进链
| 基线 | 改进 | 证据 |
|---|---|---|
| 混在一起建模 | 按 AP 数量分组建模 | 特征重要性稳定 |
| 单样本独立建模 | 考虑同实验多行相互影响 | — |
| 普通 CNN | 残差连接 CNN | 86.73% |
| 单指标准确率 | CDF 分布评估 | >95% |

## 5. 验证策略
- 特征重要性百分比量化排序；
- CDF 评估预测分布而非单点误差；
- 理论吞吐量 vs 仿真吞吐量交叉验证。

## 6. 可迁移 Pattern
> **"实测数据先按场景分组（AP数/同步异步）再建模"；"分类问题准确率之外，用CDF看误差分布"；"同一场景多次测量的样本不是独立的，特征里要带'实验ID'上下文"。**

## 7. 局限 / 慎用点
- 残差CNN用于表格数据略重，小数据集易过拟合；
- Akima插值的前提是RSSI时序光滑，突变工况未必成立。
