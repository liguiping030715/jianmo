# Card: F24102870082（南京航空航天大学）X 射线脉冲星光子到达时间建模

## 0. 元数据
- 年份/题号：2024 F 题（脉冲星导航）
- 学校：南京航空航天大学

## 1. 问题指纹
- 表面任务：轨道六根数求卫星状态 → 几何传播时延 → 精确相对论时延 → 光子序列仿真+轮廓折叠。
- 真实困难：**多层坐标系/时间系统转换 + 把各阶相对论效应分离成可计算项 + 仿真如何"像真实脉冲轮廓"**。
- 题型标签：轨道力学 + 相对论时延分解 + 随机过程仿真。

## 2. 信息流
```
Q1: 轨道六根数 → 近焦点系 → J2000.0 → GCRS → 反解一致性+STK验证
Q2: 平行光假设 → 几何传播时延(277.92s)
Q3: 时间尺度(红移/动钟变慢 TT↔TDB) + 空间尺度(Roemer/Shapiro/偏折/自行) → 473.90s
Q4: 非齐次泊松过程 → 探测器处序列 → 历元折叠 → Pearson对比
```

## 3. 分问拆解
- Q1：六根数→近焦点系r,v→旋转矩阵→J2000.0→GCRS；**反解轨道根数做一致性检验，并用STK软件独立验证**。
- Q2：平行光假设，单位视线矢量×卫星SSB位置投影/c，得277.9249s。
- Q3：时延分两类——时间尺度（引力红移+动钟变慢，靠TT↔TDB转换消除）、空间尺度（Roemer/Shapiro/光线偏折/自行）；误差灵敏度分析：各天体位置误差影响最大。
- Q4：**非齐次泊松过程**建模光子到达；迭代归算到探测器处；历元折叠成累积轮廓；与标准轮廓Pearson相关0.6992；**高斯拟合改进到0.7079**。

## 6. 可迁移 Pattern
> **"坐标/时间系统题：先把参考系层级画清楚（轨道系→惯性系→质心系），逐级旋转矩阵转换"；"数值结果用独立工具(STK)或反算逆问题做交叉验证"；"时延/误差分解：加性项(路径差)和乘性项(钟速)分开建"；"随机脉冲序列用非齐次泊松+历元折叠，用与标准轮廓的相关系数量仿真质量"。**

## 7. 局限
- Pearson 0.70 对高精度导航仍偏低；
- 高斯拟合改进幅度小。
