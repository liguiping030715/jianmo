# Card: A24103350007（浙江大学）风电场有功功率优化分配

## 0. 元数据
- 年份/题号：2024 A 题
- 学校：浙江大学
- 篇幅：约 79 页

## 1. 问题指纹
- 表面任务：同上——实时分配功率降低疲劳损伤。
- 真实困难：**实时性是第一约束**（1秒内必须出结果），任何"完整重算"思路都死。
- 关键不可观测量：主轴扭矩、塔架推力。
- 题型标签：经典理论改造 + 时序预测 + 非线性映射拟合 + 多目标进化优化。

## 2. 信息流
```
Q1: 扭矩/推力 → TW-Rainflow-Goodman-Miner 实时损伤指标
Q2: 风速/桨距角/功率参考值 → 扭矩/推力（BiLSTM 映射）
Q3: 损伤指标 + 功率指令 → NSGA-II 多目标分配
Q4: 噪声/时延 → 降噪、去时延预处理 + 实时分配
```
风格：**每一问都给了"三方案对比"**（TW vs Rainflow-Miner vs Rainflow-Goodman-Miner；单纯形 vs BiLSTM），证据链完整。

## 3. 分问拆解

### Q1 实时疲劳损伤
- 理论底座：Palmgren-Miner 线性累积损伤 + S-N 曲线 + Goodman 修正（非零平均应力下）。
- 方法：**TW-Rainflow-Goodman-Miner**——把传统雨流装进**滑动时间窗(TW)**，窗内计数、窗间累积。
- 对比：与 Rainflow-Miner、Rainflow-Goodman-Miner 两版基线在**计算时间、误差率**两维度对比。
- 要点：改进点不是发明新疲劳理论，而是**把已有经典理论改造为可流式计算**。

### Q2 载荷估计
- 物理底座：风速模型 + 空气动力学公式（推力系数、功率系数、叶尖速比）。
- 方法：先写物理方程，再用 **Nelder-Mead 单纯形** 和 **BiLSTM** 两种方法拟合"桨距角/风速/功率参考值 → 扭矩/推力"的非线性映射。
- 数据划分：WF1 前 70% 训练、后 30% 测试；结论 BiLSTM > 单纯形。
- 迁移点：**70/30 时间序列切分、两个拟合器对比选优**是标准做法。

### Q3 功率分配
- 方法：**NSGA-II** 多目标进化算法（同时最小化疲劳损伤+功率波动），结合滑动时间窗实现每秒实时求解。

### Q4 噪声与时延
- 预处理链：**降噪 → 去时延 → 再走 Q3 分配**。把数据质量问题前置为独立预处理模块。

## 4. Baseline → 改进链
| 基线 | 为什么不够 | 本文改进 |
|---|---|---|
| 离线雨流计数 | 不能在线 | 滑动时间窗 TW 改造 |
| Rainflow-Miner（无Goodman） | 非零均值应力下不准 | 加 Goodman 修正 |
| Nelder-Mead 纯拟合 | 时序非线性捕捉弱 | BiLSTM 对比胜出 |
| 平均分配 | 不优化 | NSGA-II 多目标 |

## 5. 验证策略
- 每问都有**两到三个对照模型**同场跑分（时间+误差双指标）；
- 时间序列按 70/30 切分防过拟合；
- 改进版与经典版直接对标，不孤芳自赏。

## 6. 可迁移 Pattern
> **"经典理论要实时用 → 套滑动时间窗，窗内跑原算法、窗间做累积"；"物理量关系拟合 → 同时跑传统优化器和深度网络，用时间外测试集说话"；"每一个改进都必须和上一版基线在同一指标下对比"。**

## 7. 局限 / 慎用点
- BiLSTM 训练需要大量标注载荷数据，新题若无同类数据则成本高；
- NSGA-II 每秒求解 100 台风机分配，其真实实时性需要 GPU/充分采样；
- 滑动窗大小选择经验性强。
