# Card: 2024D 中国石油大学（华东）（MK+Sen + 多元回归/ML + DEM水文 + HEV/AHP）

> **Depth: L3_DEEP（P1.5 全文深读）**

## 0. 元数据
- 队号 D24104250063，中国石油大学（华东），题目：地理大数据时空演变

## 1. 问题指纹
- 四问：降水时空演变 → 地形-气候交互作用于极端天气 → 暴雨到灾害的临界与脆弱性 → 土地利用变化结构。
- 真正困难：①多源栅格分辨率/坐标/格式不统一；②极端事件是小样本、因子交互复杂；③"相关"易证、"因果/机制"难立。

## 2. 数学抽象链
```
Q1: 降水栅格 → 均值/标准差 → Pearson(r=0.85, y=1.65x+0.13) → MK检验(Z) → Sen斜率(β)
Q2: DEM→差分→坡度/坡向；NC→TIFF；阈值50/100mm判暴雨
     → 可视化 → Pearson矩阵 → 多元回归(逐层加因子) → ML四模型网格搜索CV
Q3: DEM→Fill→FlowDir→FlowAcc提取河湖；MK+Sen外推2025-35 → 临界条件表 → HEV: D=H×E×V → AHP权重
Q4: 三级阶梯/800mm线/胡焕庸线 → 土地类型变化率与自然人文因子相关
```

## 3. 为什么每个模型被选
- **MK（非参数秩检验）**：不要求分布、容忍缺失/异常，适合水文气候序列判趋势显著性。
- **Sen 斜率（中位数斜率）**：抗异常值，在 MK 判显著后量化趋势大小——两者固定搭配。
- **多元回归逐层加因子**：先地形→气温、再气温→降水、再地形+气温→暴雨，看每加一因子 R² 增量。
- **RF/SVM/XGB/ADB 四模型 + 网格搜索 CV**：回归无先验最优模型，系统对比让数据选；XGB R²=0.562 略胜 RF 0.561。
- **HEV 而非 HV**：暴雨成灾需考虑人口/GDP 的暴露性，乘性框架 D=H×E×V。
- **AHP**：多指标权重无客观刻度，用专家 1-9 标度+一致性检验（CR<0.1）。

## 4. Baseline 与消融逻辑
- 多元回归按高程/气温区间分段建 14 个模型（模型 a~n），看 R² 随区间变化（大区间 R² 高）。
- ML 四模型同数据对比 + 特征重要性饼图。
- 信息增益：气温在 RF 重要性 0.829、XGB 0.814，远高于地形（0.02~0.1）。

## 5. 参数选择逻辑
- 暴雨阈值 50mm、大暴雨 100mm（中国气象局等级）。
- MK 临界值：90%→1.65、95%→1.96、99%→2.58；本文取 1.65。
- XGB 最优参数：lr0.1/depth5/n_estimators50/subsample0.8。
- RF：n_estimators200/depth10。
- 数据划分：3/5 训练、1/5 验证、1/5 测试。
- AHP：危险性最大判断矩阵 λmax=6.61889，CI=0.0338，CR=0.0302（通过）。

## 6. 验证策略
- 空间结果与已知地理界线对照：800mm 线对齐秦岭-淮河、胡焕庸线、三级阶梯——用"能否复现公认界线"验证分析正确性。
- 回归报 R²+MSE；极端值年份（2016 标准差 1.49）接真实极端天气事件。

## 7. 敏感性/鲁棒性
- 外推预测先做 MK 显著性：不显著直接保持 2020 值（不强行外推），显著才用 β 线性外推——避免对无趋势区域过度预测。

## 9. 章节承接技法
- Q1 的 MK/Sen 方法 → Q3 直接用于降水外推；Q2 的地形/气候因子 → Q3 危险性指标；Q3 河湖/脆弱性 → Q4 土地利用背景。方法与因子跨问复用。

## 10. 弱点 / 可疑论断（深读发现）
1. **R² 普遍偏低却结论偏强**：多元回归 R² 多在 0.1–0.4、最好 ML 仅 0.562，MSE 巨大（论文自承），但仍据此归纳"地形显著影响暴雨"，证据强度与结论力度不匹配。
2. **"数值相关低 vs 视觉影响大"矛盾**：地形因子与暴雨相关性仅 0.06，但可视化称地形影响明显；论文以"极端事件地形作用"解释，论证不充分。
3. **临界阈值（坡度 60–90、坡向 60–180）依据偏经验**，未见严格统计标定，更像读图归纳。
4. **2025–2035 线性外推假设趋势延续**，未纳入气候变化/厄尔尼诺等非线性因素。
5. 全篇以"相关+物理解释"替代因果推断，机制论证偏弱；AHP 权重依赖专家主观性。

## 11. 可迁移条件 vs 不可迁移
- **可迁移**：MK+Sen 固定搭配；多源栅格先统一坐标/分辨率；DEM 水文分析标准流程（Fill/FlowDir/FlowAcc）；外推前先判趋势显著性；用"复现公认地理界线"做验证；HEV+AHP 评价框架。
- **不可迁移**：50/100mm 降水阈值（中国标准，换区域需改）；具体权重值；线性外推在趋势转折时失效。
