# Card: D24104250063（中国石油大学华东）大数据驱动的地理综合问题

## 0. 元数据
- 年份/题号：2024 D 题
- 学校：中国石油大学（华东）

## 1. 问题指纹
- 同 D 题。特色：**标准工具链全套（MK检验/Sen斜率 + 4种ML对打 + HEV脆弱性+AHP）**。

## 2. 信息流
```
Q1: 长时序 → Mann-Kendall显著性 + Sen's斜率估计
Q2: 地理因子 → Pearson相关 + 多元回归 + RF/SVM/XGB/ADB网格搜索CV
Q3: DEM径流+降水预测2025-2035 → HEV脆弱性评价+AHP权重 → 脆弱区
Q4: 土地利用增减率 → 相关+ML预测未来变化
```

## 3. 分问拆解
- Q1：趋势显著性用 **Mann-Kendall 非参数检验**（不要求正态），趋势斜率用 **Sen's 斜率**。
- Q2：Pearson 初筛相关；回归+树模型对打；**网格搜索+交叉验证调超参**。
- Q3：HEV（暴露Exposure-敏感Sensitivity-适应能力Adaptive）脆弱性框架；AHP定权；分三个重点区域讨论。
- Q4：土地利用**增长率/减少率分开**建模（防止正负抵消）。

## 6. 可迁移 Pattern
> **"时序趋势分析标准三件套：Mann-Kendall检验显著性 + Sen's斜率估计趋势大小"；"评价类问题套现成框架(HEV/PSR) + AHP/AHP-熵权定权"；"土地利用/结构变化必须增减分开算，净变化会掩盖转型"。**

## 5. 证据
- 网格搜索+CV 调参；多模型对比；分区域结论。

## 7. 局限
- AHP主观权重争议大，宜配熵权法对比；
- HEV框架指标选择未做敏感性分析。
