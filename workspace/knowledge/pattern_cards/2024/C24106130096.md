# Card: C24106130096（西南交通大学）多变量复杂环境下的磁芯损耗建模

## 0. 元数据
- 年份/题号：2024 C 题
- 学校：西南交通大学

## 1. 问题指纹
- 同 C 题。特色：**抗噪鲁棒性测试 + 深度自表示自适应模型**——C题里方法论最扎实的一篇。

## 2. 信息流
```
Q1: 阈值分类98.5% → 5维时域SVM 100% → 加噪声掉26% → Hilbert-Huang+双谱多域融合补回
Q2: NAdam解SE误差0.36 → 对数线性化LSE误差0.31 → 乘γT/e^γT误差0.17/0.18 → LSEDSR深度自适应 0.13
Q3: ANOVA+F统计量+非参数检验 → 多个并列最优组合
```

## 3. 分问拆解
- Q1：阶跃数阈值规则分类（简单但自动化低）→ 5维时域统计特征（均值/方差/峰度/偏度/熵）SVM达100%；**关键：主动加噪声测试抗噪性（掉26%）→ Hilbert-Huang变换(HHT)+双谱时频域多域融合，精度回升并再升10%**。
- Q2：NAdam直接优化原SE误差0.36；**SE方程取对数变线性结构(LSE)**，多元线性回归等价求解误差0.31；乘 γT 或 e^(γT) 修正误差0.17/0.18；最后提出**LSEDSR深度自表示模型**，参数随温度自适应，误差降到0.13。
- Q3：多因素ANOVA+F统计量量化影响；**独立样本非参数检验**逐对比较组合差异，得三个并列最优（70/90℃ + 正弦波 + 材料2/4）。

## 4. 可迁移 Pattern
> **"分类模型在干净数据上100%不算数 → 主动加噪测抗噪性，再针对性补特征域"；"非线性物理方程 → 取对数线性化，能用线性回归解就先线性解"；"模型参数固定换工况就不准 → 让模型自适应学参数(自表示/动态参数)"；"找最优组合 → ANOVA证显著后，用非参数逐对检验，允许多个并列最优"。**

## 5. 证据
- 误差链条清晰：0.36→0.31→0.17→0.13；抗噪测试有前后对比。

## 7. 局限
- 多域特征工程复杂，HHT/双谱计算成本高；
- LSEDSR 可解释性弱于解析修正模型。
