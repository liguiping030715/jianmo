# Card: E24102870008（南京航空航天大学）高速公路应急车道紧急启用模型

## 0. 元数据
- 年份/题号：2024 E 题
- 学校：南京航空航天大学

## 1. 问题指纹
- 同 E 题。特色：**阈值用最大似然估计标定 + Kriging元模型+GA解监控点优化**。

## 2. 信息流
```
Q1: OpenCV透视变换+YOLOv8 → 三参数 → 拥堵指标 → 时空集成学习+窗口梯度判别预警
Q2: 中断概率模型 → 最大似然估计定阈值(速度<20m/s 或 流量>0.5veh/s)
Q3: 时空安全约束 → 实时决策模型 → 5指标评估
Q4: 监控点多目标优化(安全/效率/成本) → Kriging元模型+遗传算法
```

## 3. 分问拆解
- Q1：OpenCV透视变换(把监控斜视图校正为俯视图)+异常值处理；YOLOv8提参数；拥堵指标+**窗口梯度判别机制**（在初步判断上加变化率确认）。
- Q2：**最大似然估计**把"启用阈值"从经验数变成统计标定值：速度<20m/s 或 流量>0.5veh/s。
- Q3：对车道控制加时空安全约束；5指标（行程时间/碰撞暴露/通行时间/延误/平均速度）量化效果。
- Q4：监控点数量位置多目标优化；**Kriging元模型**加速仿真评估 + 遗传算法寻优。

## 6. 可迁移 Pattern
> **"阈值别拍脑袋 → 用最大似然/数据分布标定"；"预警=初步判断+梯度/变化率二次确认，防抖"；"仿真评估太慢 → 用Kriging/响应面元模型代理仿真，再GA寻优"；"视频预处理先做透视变换校正视角"。**

## 7. 局限
- Kriging元模型精度依赖采样设计；
- 阈值20m/s、0.5veh/s是该数据分布下的，换路段需重标。
