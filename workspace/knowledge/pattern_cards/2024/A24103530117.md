# Card: A24103530117（浙江工商大学）风电场有功功率优化分配

## 0. 元数据
- 年份/题号：2024 A 题
- 学校：浙江工商大学
- 篇幅：约 73 页

## 1. 问题指纹
- 表面任务：同 A 题。
- 真实困难：**实时算法的窗口参数如何自动定**（手调窗口大小是常见软肋）；以及**多目标冲突**（疲劳最小 vs 功率波动小 vs 跟踪指令准）。
- 题型标签：自适应窗口算法 + 物理约束非线性回归 + MPC滚动优化 + 鲁棒优化。

## 2. 信息流
```
Q1: 自适应三阶段滑窗 + 改进雨流 → 每秒损伤值
Q2: 风速/功率/状态 → 物理约束 + 分段非线性回归 → 扭矩/推力（拟合度0.86）
Q3: 损伤 → Pareto权重自适应 → 分区域 MPC 滚动优化
Q4: 噪声(卡尔曼滤波) + 延迟(补偿机制) + 鲁棒优化(PSO vs MPC鲁棒)
```
亮点：**Q3 不是一次性求解，而是按风速波动分区、滚动时域重解**。

## 3. 分问拆解

### Q1 自适应三阶段滑动窗口
- 痛点：窗口大小固定则不适应不同工况。
- 方法：
  1. **AB对抗法**自适应搜索初始窗口大小（构造不同窗口划分方案，比特征稳定性，选最优——实测最优窗口=14）；
  2. 三阶段：初始窗口确定 → 相邻窗口损伤差与阈值比较 → 差异点定位分段 → 子段并行算每秒损伤 → **尾部数据逆向滑动补全**；
  3. 改进雨流计数（三点式+动态阈值t）。
- 证据：Python 实测 1 秒内完成、与参考雨流增长趋势一致。

### Q2 物理约束 + 分段拟合
- 方法：
  1. 多因素相关性分析 → **引入非线性项和交互项**提高泛化；
  2. 基于能量守恒写物理约束（多余风能转成额外机械应力）；
  3. 三种分段拟合策略 + 网格搜索选参；
- 证据：估算值 vs 参考值拟合度 0.8632。

### Q3 Pareto 权重自适应 MPC
- 多目标 → 先用 **Pareto 前沿分析**定各目标权重（不靠人拍）；
- 按风速波动把风电场**分区**，高波动区/低波动区并行跑 MPC；
- 滚动时域：每秒重解，输出实时分配。

### Q4 鲁棒优化对决
- 噪声：卡尔曼滤波；延迟：延迟补偿机制；
- 对比模型：**基于粒子群(PSO)的鲁棒优化 vs 分区域MPC鲁棒优化**，最后结论 PSO 略胜；
- 再和"无优化模型"对比，证明优化本身有效。

## 4. Baseline → 改进链
| 基线 | 改进 | 证据 |
|---|---|---|
| 固定窗口滑窗 | AB对抗自适应选窗 + 尾部逆向补全 | 1s内完成 |
| 线性回归 | 非线性项+交互项+三段分段拟合 | R²=0.86 |

- PSO vs MPC 的胜负依赖本题参数，换题未必复现。
