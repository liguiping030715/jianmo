# Card: B24104760033（河南师范大学）WLAN 组网中网络吞吐量建模

## 0. 元数据
- 年份/题号：2024 B 题
- 学校：河南师范大学

## 1. 问题指纹
- 表面任务：同 B 题。
- 真实困难：无明显特殊创新——**标准 ML  baseline 路线**，靠"八种模型对打选优"取胜。
- 题型标签：回归 + 多分类 baseline 大全。

## 2. 信息流
```
Q1: 8种回归模型 → MSE/MAE/MAPE对比 → 发送机会
Q2: 4种分类模型 → Acc/F1/Precision/Recall对比 → (MCS,NSS)
Q3: 多回归模型 → 吞吐量
```

## 3. 分问拆解
- Q1：判断为回归问题，跑 8 种回归模型。结果：2AP 下 MSE=10.412、MAE=1.756、MAPE=0.064；3AP 下 MSE=43.869、MAE=4.812、MAPE=0.209。
- Q2：判断为多分类问题，跑逻辑回归/SVM/KNN/随机森林。MCS 预测 Acc=0.84、F1=0.63、Recall=0.87；NSS 预测 Acc=0.98、F1=0.55。
- Q3：相关性分析 + 多回归模型预测吞吐量。

## 4. 亮点
- **每个问题先判断题型（回归/分类），再上模型族对打**——这是最朴素但最稳的 baseline 打法。
- 评估指标齐全：MSE/MAE/MAPE（回归）+ Acc/F1/Precision/Recall（分类）。

## 5. 验证策略
- 多模型横向对打表；
- 2AP vs 3AP 分场景报告误差。

## 6. 可迁移 Pattern
> **"比赛不确定用什么模型 → 先判断题型，然后把该题型下 5~8 个经典模型全跑一遍，表格对比选优，不赌单一模型"；"回归报 MSE+MAE+MAPE，分类报 Acc+F1+Precision+Recall，指标不齐就是不完整"。**

## 7. 局限 / 慎用点
- 无数据深度洞察（不像东南大学发现 S/N 样本不独立、浙工商发现中间量缺失），全靠模型堆料；
- F1=0.55~0.63 说明类别不平衡严重，处理较粗。
