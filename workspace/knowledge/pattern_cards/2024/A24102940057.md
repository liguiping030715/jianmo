# Card: A24102940057（河海大学）考虑机组实时疲劳损伤的风电场有功功率优化分配

## 0. 元数据
- 年份/题号：2024 A 题
- 学校：河海大学
- 篇幅：约 68 页

## 1. 问题指纹
- 表面任务：在每秒一次的实时调度下，给100台风机分配有功功率，使其总疲劳损伤最小。
- 真实困难：**疲劳损伤是一个"事后才能完整算"的量**（雨流计数需要完整载荷循环），但调度要求每秒实时决策；同时真正决定疲劳的主轴扭矩/塔架推力**并不直接测量**，只能从风速和功率反推。
- 关键不可观测量：主轴扭矩、塔架推力、累积疲劳损伤 D(t)。
- 题型标签：时序实时计算 + 物理量反演估计 + 实时优化 + 鲁棒优化。

## 2. 信息流（各问传递什么）
```
Q1: 扭矩/推力时间序列 → 实时累积疲劳损伤指标 D(t)
Q2: 风速+功率参考值 → 主轴扭矩/塔架推力估计（喂给Q1的载荷来源）
Q3: D(t) + 实时工况 → 各风机功率分配策略（优化对象）
Q4: 在噪声/丢数/时延下的 Q3 策略 → 鲁棒版分配方案
```
核心链条：**估计载荷 → 实时量化损伤 → 以损伤为目标优化分配 → 在脏数据下仍能工作**。

## 3. 分问拆解

### Q1 实时疲劳损伤量化
- 任务：给定扭矩/推力时序，实时算累积疲劳损伤。
- 方法：
  1. **实时雨流计数法**：改造传统雨流，使其可在线处理流式数据；
  2. **实时非线性累积疲劳损伤指标**：引入"时间修正系数 + 暂时损伤"，把载荷循环的**顺序效应**纳入（线性 Miner 准则会忽略先后顺序）。
- 为什么：传统雨流必须等一个循环完整闭合才计数，最大载荷循环要到时间末端才能确定，导致关键扰动时刻延迟响应。
- 证据：计算耗时 0.739s；能逐秒定位 87号风机第27s、40号风机第1~16s 等大扰动时刻。

### Q2 不可观载荷的估计
- 任务：从风速、功率参考值反推主轴扭矩/塔架推力。
- 方法：剖析风电机理（输出功率滞后、风速-载荷耦合），先建风速-参考功率耦合物理模型，再用最小二乘/迭代优化拟合剩余非线性残差。
- 为什么：纯物理模型误差大，纯数据驱动缺泛化——**物理定结构，数据定参数**。
- 证据：主轴扭矩平均误差 6%，塔架推力平均误差 20%。

### Q3 实时功率分配
- 任务：每秒给各风机分功率，最小化总疲劳损伤。
- 方法：**强化学习**求解动态高维 MDP；针对神经网络输出可能越限，构造**特殊网络层+放缩限幅+安全层校正**，保证硬约束（调度指令、单台上限）严格满足。
- 为什么：传统优化每秒重解太慢，RL 一旦训练好可秒级出策略。
- 证据：总累积疲劳损伤下降 10%，载荷波动方差下降 30%。

### Q4 脏数据鲁棒版
- 任务：测量噪声、通信丢包/阻塞下仍要正常分配。
- 方法：
  1. 先做**数据阻塞现象识别**（哪些时刻数据不可信）；
  2. 用预测算法把"缺数据"转化为"预测精度"问题；
  3. **鲁棒优化**：迭代求解最差场景下的最优策略，牺牲少量平均性能换稳定性。
- 为什么：噪声和延迟不能简单滤波了事，要进优化目标里一起处理。

## 4. Baseline → 改进链
| 基线 | 为什么不够 | 本文改进 | 证据 |
|---|---|---|---|
| 传统雨流计数 | 离线、要完整循环 | 实时雨流 + 非线性累积指标 | 0.739s 实时出数 |
| 线性 Miner 准则 | 忽略循环顺序 | 时间修正系数+暂时损伤 | 捕捉到大扰动时刻 |
| 纯物理/纯ML估载荷 | 物理不准/ML不泛化 | 物理模型+数据拟合残差 | 扭矩误差6%/推力20% |
| 平均分配功率 | 不看个体健康 | RL+安全层硬约束 | 损伤-10%、方差-30% |

## 5. 验证策略
- Q1 与参考雨流结果对比趋势一致性 + 运行时间 <1s；
- Q2 用未见过的风电场后30%数据估推力/扭矩，报平均误差；
- Q3 与"优化前平均分配"对比 CDi/ACD/PVj 等指标；
- Q4 用附件4脏数据测试集跑五种分配方式对比。

## 6. 可迁移 Pattern
> **"事后才知道的累计量" → 局部滑窗+在线化改造；"测不到的中间量" → 物理方程定骨架、数据拟合校残差；"高频硬约束优化" → 学一个policy网络+安全层兜底硬约束；"脏数据" → 先判数据可信度、再用预测补缺、最后鲁棒优化兜最差情况。**

## 7. 局限 / 慎用点
- RL 实时策略在新工况下的分布外泛化未充分验证；
- 扭矩 6%、推力 20% 的误差在 Q3 优化里如何传播没有严格分析；
- 鲁棒优化的"最差场景"构造依赖场景集合假设。
