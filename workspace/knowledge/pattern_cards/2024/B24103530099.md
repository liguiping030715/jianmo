# Card: B24103530099（浙江工商大学）基于特征对齐与多重预测驱动的 WLAN 信号预测方案

## 0. 元数据
- 年份/题号：2024 B 题
- 学校：浙江工商大学

## 1. 问题指纹
- 表面任务：同 B 题（发送机会、MCS/NSS、吞吐量）。
- 真实困难：**测试集里缺少中间观测变量**（num_ppdu、ppdu_dur 等），必须先"猜中间量"再算吞吐量——双层推断。
- 题型标签：特征工程 + 聚类分区 + 复合标签多分类 + 双层交叉预测。

## 2. 信息流
```
Q1: 类别特征编码 → DBSCAN分簇 → RF/GBDT对比 → 发送机会预测
Q2: NSS⊕MCS融合复合标签 → 独热编码 → 构造SINR → BP/CNN对比 → (MCS,NSS)
Q3: RF预测缺失的帧统计量 → 残差网络用统计量+门限 → 吞吐量
```
特色：**Q3 是"两层模型串联"**——先预测观测缺失的中间变量，再用这些预测值喂给吞吐量模型。

## 3. 分问拆解

### Q1 发送机会
- 类别特征：目标编码 + 虚拟变量；
- **DBSCAN 聚类**把同步/异步传输按高低密度分区，引入扰动机制控制随机性；
- RF vs GBDT 按 MSE 和拟合优度对比选模。

### Q2 预测 (MCS,NSS)
- **NSS 和 MCS 融合为一个复合标签**（减少类别组合复杂度）；
- 独热编码消除类别数值大小的虚假顺序；
- 手工构造 SINR 特征（同步/异步传输分别算）；
- 截断操作对齐两数据集长度 + 过采样增样本；
- BP vs CNN 对比选优。

### Q3 双层交叉预测
- 关键推理：throughput 受 num_ppdu/ppdu_dur 影响，但测试集没这些值；
- 第一层：用 Q1 验证过的 RF 预测这些帧统计量；
- 第二层：用预测的统计量 + 门限 → 深度残差网络 → 吞吐量。

## 4. Baseline → 改进链
| 做法 | 为什么更好 |
|---|---|
| NSS、MCS 分别分类 | 融合成复合标签，减少决策次数 |
| 类别数值直接进模型 | 独热编码消除虚假序 |
| 直接用原始特征 | 手工构造 SINR 物理量 |
| 单层预测吞吐量 | 双层：先补缺失中间量再预测 |

## 5. 验证策略
- 每层模型单独验证后才串联；
- RF vs GBDT、BP vs CNN 模型对打；
- 过采样/截断处理样本不平衡。

## 6. 可迁移 Pattern
> **"测试集缺中间观测变量 → 不要硬跳步，先训一个模型把中间量补出来，再喂给下游模型（双层串联）"；"多分类组合多时 → 融合成复合标签+独热"；"类别型变量必须独热/目标编码，不能让模型以为 2>1"。**

## 7. 局限 / 慎用点
- 双层串联误差会累积（第一层预测错了第二层跟着错），未做误差传播分析；
- DBSCAN 的密度定义依赖本题 RSSI 分布，换题需重定 eps。
