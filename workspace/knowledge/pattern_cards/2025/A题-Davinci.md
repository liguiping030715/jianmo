# Card: 2025A-Davinci 面向Davinci架构的NPU核内调度算法研究

## 0. 元数据
- 年份/题号：2025 A 题
- 学校：未在摘要标注

## 1. 问题指纹
- 同 A 题。特色：**先 Gephi 可视化算图做模块化分析 + 多启发式对打选优**。

## 2. 信息流
```
Q1: 6个算图 → Gephi可视化+模块化分析 → 贪心/SA/禁忌/遗传对比 → 选贪心
Q2: 固定序列 → 遗传编程求地址 → 变邻域SA解双指标加权
Q3: 两阶段(10%搬运增量约束→多目标) → GP改进
```

## 3. 分问拆解
- Q1：**先用 Gephi 把DAG画出来做模块化分析**，理解结构再建模；四种启发式（贪心/模拟退火/禁忌/遗传）对打，发现启发式需大量调参，最终选贪心结果。
- Q2：拆两个子问题——子问题一固定序列优化地址偏移（遗传编程）；子问题二序列与指标难兼顾时，建**双指标加权单目标**模型，用变邻域模拟退火；对比发现固定序列方案更优。
- Q3：两阶段——阶段一搬运增量≤10%下只优化时间；阶段二多目标。

## 6. 可迁移 Pattern
> **"拿到DAG/图数据先可视化(Gephi/networkx)看模块结构，再设计算法"；"多种启发式都试一遍，诚实地报告'哪个最省事且够用'，不硬吹复杂算法"；"双指标难权衡 → 先试固定一方优化另一方，再试加权，对比选优"。**

## 7. 局限
- 贪心结果未必全局最优；
- 遗传编程实现复杂。
