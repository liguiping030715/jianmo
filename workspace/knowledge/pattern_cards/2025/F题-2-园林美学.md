# Card: 2025F-2 江南古典园林的美学特征建模（Minkowski+Shannon+改进GA）

## 0. 元数据
- 年份/题号：2025 F 题
- 学校：未在摘要标注

## 1. 问题指纹
- 同 F 题。特色：**扇形视域模型参数化（50m/180°）+ Jaccard异景 + K-means五类景观主题**。

## 2. 信息流
```
Q1: 中轴线提取+Minkowski膨胀障碍物→定位点 → 扇形视域(50m/180°)+射线追踪+Shannon多样性 → Jaccard距离异景 → 4指标加权 → 改进GA
Q2: Shannon熵+K-means五类主题(水/石/林/建/过渡) → 多样性/和谐性/复杂度三维 → 开合模型
Q3: 层次聚类+模糊综合评价 → 7个共性特征
```

## 3. 分问拆解
- Q1：**扇形视域模型参数化**（有效视距50m、视角180°）；Shannon多样性指数；**Jaccard距离度量相邻定位点景观集合差异**；综合4指标加权（景观丰富度0.30/异景强度0.35/协同度0.20/覆盖广度0.15）；改进GA种群200/500代/自适应变异，1.5h收敛Gap=0。
- Q2：K-means把景观聚成五类主题；三维评价（多样性/和谐性/复杂度）；留园幻境174.1第一。
- Q3：层次聚类+模糊综合评价，识别7个共性美学特征。

## 6. 可迁移 Pattern
> **"视域模型给物理参数：视距+视角（人眼50m/180°），别拍脑袋"；"相邻点景观差异用Jaccard集合相似度，比汉明更适合元素类别"；"评价指标权重显式列出并赋0~1，可解释可调整"；"多目标GA要报收敛Gap和迭代参数"。**

## 7. 局限
- 50m/180°视域假设通用，不同视角未验证；
- 权重0.30/0.35等仍带主观。
