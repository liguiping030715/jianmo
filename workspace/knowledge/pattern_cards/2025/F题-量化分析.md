# Card: 2025F 江南园林美学量化（抽象美学→几何/拓扑代理 / 骨架图建模 / 适量度指标 / 开阔围合双轴 / 双相似度）

> **Depth: L3_DEEP（P1.5 全文深读，含完整建模与 GA）**

## 0. 元数据
- 题目：基于园林平面图，量化游线趣味性、空间幻境感，并比较各园林美学特征。

## 1. 问题指纹
- Q1 游线刻画/异景/趣味性与最优路线；Q2 空间划分聚类与幻境评分；Q3 园林相似度比较。
- 真正困难：美学（移步异景、趣味、幻境、开阔/围合）是主观抽象概念，需转化为可从平面图计算的几何/拓扑代理变量。

## 2. 数学抽象链
```
Q1: 可通行域 Ω = (道路缓冲带 ∪ 半开带 ∪ 边带) \ 障碍
    线网闭合为障碍多边形; 植物冠径圆盘 ×ηwalk(通行)/ηvis(视域)
    骨架化: 二维廊带 → 一维中线(左右边界均值) → 图 G=(V,E)
    节点=入口/出口/转折(夹角<θthr)/交叉(deg≥3)
    路径特征: 长度 L/转折 Nturn/交叉 Ncross/重复度 R/异景 Nscene/室外半开比例
    异景: 段间 JS 距离·单位长度变化率 + 段内种类密度
    趣味性 F=Σωk Ik（异景0.35/转折0.20/交叉0.15/空间比例0.15/长度0.15）
    边权 W=长度 - λ2·趣味性 + λ3·重复惩罚; 改进 GA 求 min Cost
Q2: 空间划分子区 Ωi → 聚类成审美主题区 Rk
    元素面积比例 πc/离散度 Dc/特征 fi/空间权重 wij
    临水开敞分 ψk(开阔感) + 硬边覆盖分 ηk(围合感) → 幻境评分 Hg(百分制)
Q3: 综合向量 Fi(趣味+幻境) → 余弦 Simcos + 杰卡德 SimJ(主导元素)
    Sim=α·Simcos+(1-α)·SimJ
```

## 3. 为什么每个模型被选
- **几何/拓扑代理**：平面图可精确计算，给主观美学一个客观、可复现的量化基础。
- **骨架化降维**：二维廊带直接搜索量大且冗余，抽中线成图保留拓扑、丢弃边界冗余。
- **JS 距离 + 种类密度**：段间用分布距离刻画"切换感"、段内用种类密度刻画"渐变感"，且都按长度归一防短段刷变化。
- **高斯型"适量度"**：转折/交叉/长度不是越多越好也非越少越好，用 exp(−(N−N*)²/σ²) 在理想值附近取 1。
- **GA**：路径组合离散、约束多，进化优化配合修复机制；开阔/围合双轴刻画空间性格；余弦+杰卡德从连续向量与离散集合两口径比相似。

## 4. Baseline 与消融逻辑
- 路径：随机可行路径 → GA 优化；异景段间/段内两分量分别建模再融合（βinter 0.6–0.7 / βintra 0.3–0.4）。
- 相似度：余弦与杰卡德两口径加权，避免单一度量偏差。

## 5. 参数选择逻辑
- 趣味权重 0.35/0.20/0.15/0.15/0.15；TOL=0.8m（剔贴建筑窄缝）；视线缓冲 ρ=2–3m。
- ηwalk∈(0,1.5]、ηvis∈[1,2]；重复度上限 Rmax（0 禁重复、2 允许两次）。

## 6. 验证策略
- 可通行域分层叠加可视化（留园/拙政园/寄畅园/秋霞圃）核对真实可达性。
- 异景程度热力路径可视化；GA 收敛曲线图；最优路径节点编号展示。
- 关键节点异景值与景观组合类型对照（表5.8）。

## 7. 敏感性/鲁棒性
- 距离衰减核 k(d)=e^{−d/σ} 修正面积占比（近处突出、远处削弱），左右视角分别加权。
- 出现阈值 θpres=0.1 滤小比例噪声；线网 ε 加厚闭合防缝隙。

## 9. 章节承接技法
- Q1 路径趣味性 → Q2 空间幻境，二者合成综合向量 → Q3 相似度。从"线（路径）→面（分区）→集合（园林比较）"层层扩展。

## 10. 弱点 / 可疑论断（深读发现）
1. **"适量度"锚点主观**：理想值 N*/M*/ρ*/L* 如何确定未说明，是整个评价的关键却缺依据。
2. 大量权重（0.35 等、β、λ、α）经验给定，未见标定与敏感性分析。
3. ηwalk 范围跨 1（可放大可缩小冠径障碍）依据不明；ρ、TOL 等均经验值。
4. **仅二维平面图**：丢失假山起伏、漏窗框景、借景等三维/视觉效果，而这些恰是江南园林精髓。
5. 几何代理只捕捉"空间结构"，无法涵盖意境、文化、季相、材质、声景等美学维度。
6. GA 单点交叉易产生不连通路径（靠修复补救、增复杂度）；仅 10 个园林样本，聚类/相似度统计稳定性弱；部分统计表数值在 Markdown 中缺失/错位。

## 11. 可迁移条件 vs 不可迁移
- **可迁移**：抽象主观概念→可计算几何/拓扑代理的范式；中心线缓冲+障碍的可行域；骨架化（二维→一维→图）降维；段间分布距离(JS)+段内多样性(种类密度)且按长度归一；**高斯型"适量度"防止"越多越好"的线性思维**；负向收益+重复惩罚边权；开阔/围合双轴；余弦+杰卡德双相似度；GA+修复路径优化。
- **不可迁移**：各类权重/理想值/缓冲半径随场地与尺度重标；二维平面法在强三维场景失效；几何代理不能替代人对意境等非空间维度的评价。
