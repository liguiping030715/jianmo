# Card: 2025F-量化 江南古典园林美学特征的量化建模与分析

## 0. 元数据
- 年份/题号：2025 F 题
- 学校：未在摘要标注

## 1. 问题指纹
- 同 F 题。特色：**骨架提取图建模 + GMM-MRF空间约束模糊聚类 + 灵敏度分析 + 余弦/Jaccard线性融合相似度**。

## 2. 信息流
```
Q1: 骨架提取路径中心线→图建模(长度/转折/交叉) → 五维加权(异景/转折/交叉/室内外贴合/长度) → GA → 与官方路线对比
Q2: 六特征向量→GMM-MRF空间约束模糊聚类分区 → 开合变化量(临水/硬软边) → 灵敏度分析
Q3: 综合向量余弦+主导元素Jaccard线性融合 → 鹤园广效用验证 → 新提自然人工融合度/水路交融度
```

## 3. 分问拆解
- Q1：**骨架提取**得路径中心线选关键节点建图；五维加权评价；GA优化；**与官方推荐路线在多维指标下对比**验证最优性。
- Q2：**GMM-MRF空间约束模糊聚类**（GMM概率+MRF空间平滑）把园林分区；开合变化量=临水/非临水、硬边/软边切换次数；**灵敏度分析（一次一参+联合扰动）**验证评分鲁棒。
- Q3：综合向量余弦相似度+主导元素Jaccard相似度线性融合；鹤园外推验证；新提两个美学特征量化。

## 6. 可迁移 Pattern
> **"路径提取用骨架化(skeletonize)得中心线再选节点建图"；"空间聚类要加空间约束（MRF/GMRF），否则聚类结果空间散乱"；"评价模型必须做灵敏度分析（单参数+联合扰动），证明鲁棒"；"相似度=连续向量余弦+类别集合Jaccard线性融合"；"模型外推验证：拿一个训练时没用过的园林测"。**

## 7. 局限
- 骨架提取对复杂廊道可能断裂；
- 两新提美学特征仅拙政/留园案例验证。
