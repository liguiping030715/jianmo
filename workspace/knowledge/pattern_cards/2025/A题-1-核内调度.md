# Card: 2025A-1 通用神经网络处理器下的核内调度问题（模拟退火+分层优化）

## 0. 元数据
- 年份/题号：2025 A 题（NPU核内调度）
- 学校：未在摘要标注
- 题型：DAG调度 + 缓存分配 + 联合优化

## 1. 问题指纹
- 表面任务：给定算子DAG，求最小缓存驻留序列、缓存受限下最小额外搬运量、联合优化执行时间+搬运量。
- 真实困难：**三问层层嵌套（Q1定序列→Q2定地址/SPILL→Q3联合调优），每问都是NP-hard**。
- 题型标签：组合优化 + 启发式 + ILP + 分层分解。

## 2. 信息流
```
Q1: DAG拓扑序 → 生成优质初始解+模拟退火 → 最小max缓存驻留
Q2: 固定Q1序列 → 彩色边图/rounding/ILP → 缓存地址+SPILL → 最小搬运
Q3: Q1序列+Q2分配 → 负载均衡优先级+Best-Fit+多目标 → 总时间
```

## 3. 分问拆解
- Q1：在拓扑序约束下压缩缓冲区生命周期；**好初始解+模拟退火**（快速找优+提升精度）。
- Q2：拆成调度序列子问题、缓存分配子问题、SPILL优化子问题**分步求解**；彩色边图+rounding+ILP。
- Q3：分层优化——单元负载均衡自适应优先级调度、时序敏感Best-Fit缓存分配、多目标优化。

## 6. 可迁移 Pattern
> **"嵌套优化题：上一问的输出作为下一问的固定输入，分步解，别三问一起优化"；"组合优化先造优质初始解再上模拟退火/禁忌，别纯随机启动"；"NP-hard问题拆成'序列→分配→溢出'三层，每层用合适工具（启发式/ILP）"。**

## 7. 局限
- 模拟退火参数敏感；
- 分步优化可能不是全局最优。
