# Card: 2025B-机器学习MIMO（Isotonic校准+OOF防泄漏+岭正则融合）

## 0. 元数据
- 年份/题号：2025 B 题
- 学校：未在摘要标注

## 1. 问题指纹
- 同 B 题。特色：**工程细节最扎实——Isotonic校准、OOF防信息泄漏、GroupKFold防域泄漏、长尾逆频权重、岭正则融合**。

## 2. 信息流
```
Q1: EESM α/β + Isotonic校准 + OOF预测 + HGBR堆叠 → 加权融合ISO+HGBR
Q2: 259维特征(线性/dB域SINR+统计) → 随机森林 + GroupKFold + 逆频权重 + 随机搜索
Q3: SVD 2×2闭式特征值 + 粗细搜索β + 30维特征HGBR → 岭正则线性融合
```

## 3. 分问拆解
- Q1：EESM拟合后用**Isotonic回归做单调概率/阈值校准**；**OOF(out-of-fold)预测防信息泄漏**；堆叠特征训HGBR；学习型加权融合可解释基线与非线性模型。
- Q2：122子载波SINR线性域+dB域+统计特征拼成259维；**GroupKFold按组划分防同域泄漏**；MCS长尾→**等频10分箱逆频权重**；随机搜索调参；每折内训Isotonic再作用验证折。
- Q3：SVD闭式特征值公式；EESM的β粗细扫描寻优；30维特征HGBR；**带岭正则的闭式线性融合**两种模型。

## 6. 可迁移 Pattern
> **"校准问题：Isotonic回归保单调且校准概率"；"防信息泄漏三板斧：OOF预测、GroupKFold按组划分、每折内拟合校准器"；"标签长尾 → 分箱逆频权重/类权重"；"物理模型+ML模型 → 用岭正则闭式解学融合权重，比手工加权客观"。**

## 7. 局限
- 259维特征对随机森林够但可解释性下降；
- 多步pipeline误差累积。
