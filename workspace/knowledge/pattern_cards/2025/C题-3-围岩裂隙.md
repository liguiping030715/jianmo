# Card: 2025C 围岩裂隙（两阶段6法投票 + 多层次聚类拟合 + 傅里叶/小波分层 + 信息衰减不确定性/贪心布孔）

> **Depth: L3_DEEP（P1.5 全文深读，含附录与 AI 声明）**

## 0. 元数据
- 题目：钻孔孔壁图像裂隙识别、正弦拟合、分层表征、三维概率重构与补钻孔优化。

## 1. 问题指纹
- 四问：裂隙像素识别 → 正弦状裂隙几何拟合 → 裂隙分层/粗糙度表征 → 连通概率、不确定性场与新增钻孔选址。
- 真正困难：①裂隙与噪声/光照不均难分、单种检测器漏检多；②离散像素点如何稳健拟合成正弦曲线；③钻孔稀疏、孔间区域未知，如何量化不确定性并指导补孔。

## 2. 数学抽象链
```
Q1: 6 种互补检测法 → 加权融合投票(高召回粗检测) → 区域特征+物理约束精分类
Q2: DBSCAN 聚类 → 水平聚类(多层次) → 正弦模型 y=A sin(ωx+φ)+b
     两种正弦参数化对比; 残差/优度评价
Q3: 傅里叶变换提主轮廓(低频) + 小波变换提细节(高频) → JRC 粗糙度
Q4: 连通概率(深度+产状+距离)
     信息衰减: Ik(x)=I0·exp(-dk/Lc), Lc=1000mm (变异函数定)
     多孔 IDW: wk=dk^-p/Σdj^-p, p=2
     不确定性场 U → 补孔 min J=Σ U_new(x|Xn)
     s.t. xn∈Ωf, ||xn,i-xn,j||≥500, zn=0
     贪心: 每步选信息增益 ΔI 最大位置
```

## 3. 为什么每个模型被选
- **6 法投票**：单一检测器对某种裂隙/噪声失效，互补方法加权融合先保高召回，再精分类提精度——召回优先于精度（漏检不可恢复、误检可剔除）。
- **DBSCAN+水平两阶段聚类**：先按空间密度把像素聚成裂隙、再按水平连续性细分，兼顾不同尺度误差。
- **傅里叶+小波**：傅里叶捕全局主形态、小波捕局部粗糙度细节，分层表征。
- **信息衰减场**：钻孔是信息源、信息随距离指数衰减（1/e 物理意义明确），把"哪里未知"量化成连续场。
- **贪心布孔**：组合优化不可穷举，按即时信息增益序列选点，高效近似。

## 4. Baseline 与消融逻辑
- 识别：单法 → 6 法融合（召回提升）；粗检测 → 精分类（精度提升）。
- 布孔：3 个新孔信息增益 472.75 / 434.98 / 429.19，呈边际效益递减，验证贪心序列合理。

## 5. 参数选择逻辑
- Lc=1000mm（煤系地层变异函数）：1000mm 处信息 37%、2000mm 13.5%、3000mm 5%。
- IDW 幂 p=2；最小孔距 dmin=500mm；新增 3 孔、z=0 地表施工。
- 推荐位置：(800,1300)、(2400,1500)、(1600,1500)。

## 6. 验证策略
- 处理过程图 + 最终结果图逐图对照。
- 空间结果验证：不确定性"碗状"分布（中心低、四角高）符合"孔间信息足、角部盲区"预期；新孔覆盖图确认填补空白。
- 连通概率矩阵与深度/产状规律对照（近孔、同产状连通率高）。

## 7. 敏感性/鲁棒性
- 多法融合本身即对噪声/光照的鲁棒机制；论文自承对输入质量敏感，建议机器学习/迁移学习增强。

## 9. 章节承接技法
- Q1 像素 → Q2 曲线几何 → Q3 分层/粗糙度 → Q4 三维网络与连通；Q4 的不确定性又回到指导"再采样"。形成"识别→表征→重构→补数据"闭环。

## 10. 弱点 / 可疑论断（深读发现）
1. **评分/投票权重主观**（论文自承），权重优化方法未详述。
2. **Lc 各向同性假设**：用单一 1000mm 相关长度，但裂隙岩体明显各向异性，会高估/低估某些方向信息。
3. **贪心布孔不保证全局最优**，可能错过组合更优的布点方案。
4. 连通概率仅基于深度/产状/距离的经验融合，未纳入裂隙实际交切的几何约束。
5. 三维概率网络仅生成 50 条裂隙，样本偏少、连通统计稳定性有限。
6. 传统图像处理特征信息量少；大规模场景计算复杂（自承）。
7. AI 辅助声明规范（DeepSeek-V3.1），但需注意核心判断的原创性。

## 11. 可迁移条件 vs 不可迁移
- **可迁移**：召回优先的"多法粗投票+物理约束精分类"；多层次聚类；傅里叶+小波分层；信息指数衰减+IDW 构造不确定性场；把补采样/布点转为最小化不确定性并用贪心信息增益求解；边际效益递减评估；规范的 AI 辅助声明。
- **不可迁移**：Lc=1000mm、dmin=500mm、JRC 等煤系地层专用参数；6 种检测器的具体阈值；各向同性假设在强各向异性介质需改。
