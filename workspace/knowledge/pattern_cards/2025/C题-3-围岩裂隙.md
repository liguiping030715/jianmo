# Card: 2025C-3 围岩裂隙精准识别与三维模型重构（两阶段投票+扩展傅里叶+小波）

## 0. 元数据
- 年份/题号：2025 C 题
- 学校：未在摘要标注

## 1. 问题指纹
- 同 C 题。特色：**两阶段粗+精识别、两模型对打、多尺度小波分解轮廓**。

## 2. 信息流
```
Q1: 6方法投票粗定位(Frangi/Canny/梯度张量/自适应阈值/局部纹理/黑帽) → 12维连通域特征赋分(≥6分入选)
Q2: 模型一DBSCAN+水平带合并+RANSAC  vs  模型二滑动窗口+Hough降维 → 选模型一(22条)
Q3: 扩展傅里叶提主轮廓 + 4层小波分离残差细节 + Bootstrap → 4种采样策略400点曲率最优
Q4: 空间距离+法向量夹角综合 → 补孔
```

## 3. 分问拆解
- Q1：**两阶段**——多方法投票粗定位（每个像素6个方法投票），再对每个连通域算3大类12维特征赋分（满分10，≥6判裂隙）。
- Q2：两套模型对打——模型一DBSCAN+水平带合并（解决局部断裂误分割）+RANSAC；模型二自适应滑动窗口+Hough变换；用有效拟合率/IQR/RMSE对比，选模型一。
- Q3：**扩展傅里叶级数+小波多尺度分解**——主轮廓（低频）+残差细节（4层小波）；Bootstrap评估参数不确定性；4种采样×5种点数对比，400点曲率自适应最优。
- Q4：空间距离+法向量夹角两几何指标综合。

## 6. 可迁移 Pattern
> **"难分割问题：先多方法投票粗定位，再对连通域做特征赋分精筛，比单模型端到端可控"；"聚类后必须合并断裂（水平带/邻接）再拟合，否则一条裂隙被切成多段"；"轮廓表征=主趋势+残差细节：傅里叶提主、小波提细节"；"采样策略要做'采样方法×采样点数'双因素对比实验"。**

## 7. 局限
- 12维特征赋分阈值6分仍带主观；
- 小波分解层数需调。
