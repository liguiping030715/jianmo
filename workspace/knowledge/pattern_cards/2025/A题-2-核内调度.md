# Card: 2025A-2 通用神经网络处理器下的核内调度问题（ABQPSO+双种群进化）

## 0. 元数据
- 年份/题号：2025 A 题
- 学校：未在摘要标注

## 1. 问题指纹
- 同 A 题。特色：**自适应二进制量子粒子群(ABQPSO) + 双种群多目标进化**。

## 2. 信息流
```
Q1: 领域搜索贪心+优先级+禁忌搜索 → 调ALLOC/FREE位置 → 缓存亚线性增长 O(N²)
Q2: ABQPSO量子粒子群+多维混合编码 → 决策SPILL时机+地址 → 降搬运
Q3: 双种群(收敛+探索)多目标进化 → 并行度挖掘 → 时间-搬运权衡
```

## 3. 分问拆解
- Q1：优先级策略+禁忌搜索；**智能调整 ALLOC/FREE 相对位置**使内存亚线性增长；O(N²)。
- Q2：**ABQPSO（量子动力学+多维混合编码）**动态决策SPILL介入时机和物理地址；分层修复+局部搜索应对碎片化。
- Q3：双种群多目标进化——**收敛种群保证收敛、探索种群保多样性**，差异化环境选择；性能综合提升10-30%。

## 6. 可迁移 Pattern
> **"多目标优化用双种群策略（收敛+探索）防止早熟"；"离散调度问题用二进制/混合编码粒子群，比纯遗传更适合连续-离散混合决策"；"内存管理节点(ALLOC/FREE)的位置可调，是压缩峰值的关键自由度"。**

## 7. 局限
- 量子粒子群参数仍需调；
- 10-30%提升是平均，单算子波动大。
