# Card: 2025B-无线通信链路速率建模（IQR时间同步+Adam+MFF-CT Transformer）

## 0. 元数据
- 年份/题号：2025 B 题
- 学校：未在摘要标注

## 1. 问题指纹
- 同 B 题。特色：**数据时间同步清洗 + 物理感知Transformer逐场景升级（70%→79%→87.5%）**。

## 2. 信息流
```
Q1: IQR剔时间差异常+mcs区间归一化+L2+物理约束惩罚+Adam拟合α/β
Q2: Chernoff边界修正指数映射+SVD奇异值+SINR统计+网格搜索正则 → 79%
Q3: 主奇异值加权映射 + MFF-CT Transformer(CSI+SINReff多模态+PosEnc+波束注意力) → 87.5%
```

## 3. 分问拆解
- Q1：**CSI采集时间csi_time与速率采集时间dfx_time不同步，用IQR剔异常值**；mcs非整数离散→统计最小差值划分区间、归一化[0,1]；双边误差+约束违背惩罚+Adam优化α/β；三终端独立训练（硬件差异大不能合并）。
- Q2：基于符号错误率**Chernoff边界近似改进指数映射**；加MIMO奇异值特征+SINR统计特征；网格搜索正则系数。
- Q3：**MFF-CT多模态融合Transformer**——标量SINReff+CSI序列融合，Positional Encoding保留频率顺序，用波束赋形空间相关性优化注意力权重；平均池化+分类头输出mcs。

## 6. 可迁移 Pattern
> **"多传感器/多通道数据采集时间戳必须先对齐(IQR剔时间差异常)"；"离散标签非整数 → 划区间+归一化再回归，最后反归一化"；"不同终端/设备分别训练，别合并拉平"；"Transformer处理122子载波序列要加PosEnc保频率顺序，用领域先验(波束空间相关)设计注意力"。**

## 7. 局限
- Transformer在小样本通信数据上易过拟合；
- 三终端独立训练泛化性存疑。
