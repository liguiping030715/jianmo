# Card: 2025D-1 低空湍流监测及最优航路规划研究

## 0. 元数据
- 年份/题号：2025 D 题（低空湍流+航路）
- 学校：未在摘要标注

## 1. 问题指纹
- 表面任务：双资料基准→单设备ML反演→多源三维同化→NWP预报+三维航路。
- 真实困难：**多雷达数据时空对齐 + 径向速度反演水平风场 + 三维动态路径规划**。
- 题型标签：气象同化 + 树模型反演 + 三维路径优化。

## 2. 信息流
```
Q1: 风廓线+微波 → Ri+TKE基准a → 单风廓线RF/XGBoost模型b
Q2: 三源数据 → VAD重建水平风场 → X/S波段加权 → 集合卡尔曼滤波 → 三维湍流场
Q3: NWP建TKE场 → LSTM多设备预测加权 → 代价函数 → 三维蚁群航路
```

## 3. 分问拆解
- Q1：双资料时空匹配合并做基准；**以站点号+TKE区间双分层Bootstrap抽样**（避免站点不平衡偏差）；RF R²=0.4977→XGBoost R²=0.5621（Bagging→Boosting）。
- Q2：**VAD技术三步重建水平风场**（分解u/v、观测方程、最小二乘解超定方程组）；X波段0.6+S波段0.4加权；简化集合卡尔曼滤波插值到笛卡尔网格。
- Q3：NWP数据选因子建TKE场；LSTM分设备预测+RBF插值+K-means聚类+**拟合优度归一化加权融合多设备预测**；三维蚁群算法搜最优路径。

## 6. 可迁移 Pattern
> **"多站点数据训练ML：按站点号分层抽样，否则样本多的站主导模型"；"雷达径向速度→水平风场：VAD技术+最小二乘解超定方程"；"多设备预测同一物理量：按各设备拟合优度归一化加权融合"；"三维动态航路：TKE场作代价图，蚁群/A*在体素网格上搜"。**

## 7. 局限
- R²=0.56仍偏低，单设备反演能力有限；
- 三维蚁群参数敏感。
