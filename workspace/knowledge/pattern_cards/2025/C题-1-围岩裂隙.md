# Card: 2025C-1 围岩裂隙精准识别与三维模型重构（改进U-Net+PPIGA）

## 0. 元数据
- 年份/题号：2025 C 题（钻孔裂隙）
- 学校：未在摘要标注

## 1. 问题指纹
- 表面任务：钻孔展开图裂隙分割 → 正弦状裂隙聚类+参数反演 → 粗糙度JRC → 多钻孔三维连通+补孔推荐。
- 真实困难：**岩石纹理/泥浆杂质干扰分割；裂隙像素占比极小；二维曲线推三维平面的不确定性**。
- 题型标签：图像分割 + 鲁棒曲线拟合 + 粗糙度计算 + 多指标综合评价。

## 2. 信息流
```
Q1: 展开图 → CLAHE+双边+Sobel → 改进U-Net(ResNet50+ASPP+通道注意力) → 二值掩码
Q2: 掩码 → 8邻域连通+DBSCAN合并 → 中心线 → LM+RANSAC正弦拟合(周期=94.25mm)
Q3: 轮廓 → 多尺度LoG边缘 → 等间距/曲率加权采样 → Z₂经验公式 → JRC
Q4: 几何匹配+JRC修正概率 → PPIGA投影寻踪GA替代AHP → 补孔排序
```

## 3. 分问拆解
- Q1：改进U-Net（ResNet50编码器+ASPP多尺度+通道注意力）；Accuracy=98.7%、IoU=73.1%。
- Q2：频域分析给正弦拟合初值，LM+RANSAC鲁棒拟合；周期物理固定=钻孔周长94.25mm，只解振幅/相位/中心。
- Q3：**等间距vs曲率加权采样对比**，曲率加权在高曲率区加密；Z₂-JRC经验公式。
- Q4：**PPIGA投影寻踪改进遗传算法**——投影寻踪降维多指标+GA搜最优投影向量，**替代主观AHP**（综合分9.95 vs AHP 8.40）。

## 6. 可迁移 Pattern
> **"语义分割模型三招升级：ResNet编码器+ASPP多尺度+注意力门"；"已知物理约束（周期=钻孔周长）就把它当固定量，少估一个参数更稳"；"评价类AHP太主观 → 用投影寻踪+GA客观权重，并用AHP做对照实验"；"分割评估不能只报Accuracy（前景太小时虚高），必须报IoU/Recall/F1"。**

## 7. 局限
- 改进U-Net训练数据量小；
- PPIGA计算成本高。
