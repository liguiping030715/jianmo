# Card: 2025D 低空湍流/航路（双模型冗余蒸馏 + 变分同化三代价 + 各向异性距离 + A*风险代价）

> **Depth: L3_DEEP（P1.5 全文深读，含完整源码）**

## 0. 元数据
- 题目：多源观测（风廓线雷达/微波辐射计/多普勒雷达/地面站）融合的湍流监测与航路规划。

## 1. 问题指纹
- 三问：湍流强度量化 → 三维湍流场融合重构 → 短时预报与航路规划。
- 真正困难：①设备可能缺测/失效，需冗余；②多源异构数据时空分辨率/可靠性不同；③三维场垂直变化远快于水平；④飞行需在安全（避湍流）与经济（路程短）间平衡。

## 2. 数学抽象链
```
Q1: 位温 θ=T(1000/P)^0.286; 静力平衡估气压
    理查逊数 Ri=(g/θ)(∂θ/∂z)/[(∂u/∂z)²+(∂v/∂z)²]  (热力)
    TKE≈SW²; 风切变 S=(∂u/∂z)²+(∂v/∂z)²
    模型a(全源): Ia=α1·f(Ri)+α2·TKE_norm+α3·S_norm, f(Ri)=exp(-βRi)
    模型b(仅雷达): Ib=c1·SW_norm+c2·S_norm
    蒸馏: min Σ(Ia-Ib)²+λ(c1²+c2²) 或 RF(SW,S,u,v) 学 Ia
Q2: 预处理(高斯权重插补/去趋势/Hampel 3MAD)
    各向异性距离; 半方差 γ(h)
    变分融合: J(T)=Jobs+Jb+Js
      Jobs=Σ[H(T)-Tobs]²/σ²; Jb=λb||T-Tb||²; Js=λs||∇²T||²
    权重 wi=wdist·wsource·wtime; 卡尔曼滤波外推
Q3: 分步插值(双线性水平+垂直线性)
    预报: NWP模型d分层标定 / 观测模型e多变量时序回归
    A*: Cost(ni,nj)=(T(ni)+T(nj))·distance
```

## 3. 为什么每个模型被选
- **双模型冗余（a 全源 / b 仅雷达）**：微波辐射计有空间覆盖与可靠性问题，b 作为降级方案保证设备失效时仍可运行。
- **用 a 蒸馏 b**：b 缺热力项会系统偏差，用 a 的输出当"软标签"标定 b 的权重/RF，把全源知识压缩进单源模型。
- **变分同化（观测+背景+平滑）**：气象融合标准框架——观测项贴数据、背景项防偏离先验、平滑项抑制噪声，三者权衡得最优场。
- **各向异性距离（γ≈10）**：垂直相关尺度远小于水平，放大垂直差异才符合大气结构。
- **A***：网格空间可证最优、启发式高效，代价中嵌入湍流风险实现安全-经济平衡。

## 4. Baseline 与消融逻辑
- Q1 系统对比 12 种回归（线性/多项式/LASSO/对数/指数/幂/决策树/RF/梯度提升/NN），RF 最优 RMSE5.1234、R²0.8543、MAE2.8812。
- 模型 b 原始 → 优化后（RMSE7.85→5.12，R²0.65→0.85），量化蒸馏收益。

## 5. 参数选择逻辑
- 模型a：α1=0.3/α2=0.5/α3=0.2，β=0.5（默认经验）。
- 模型b：c1=c2=0.5；Ri 阈值 0.25 不稳定 / 1 稳定；分母下限 1e-6。
- 网格：水平 100m、垂直 50m、域高 0–2000m。
- 数据源可靠性：WPR 1.0 / DWR 0.8 / AWS 0.6；时间衰减 τ=30min。
- 各向异性 γ=10。

## 6. 验证策略
- 误差三维度：RMSE（异常敏感）+MAE（稳健幅度）+R（趋势一致）。
- 训练/测试性能接近判泛化（RF 训练 R²0.8154 vs 测试 0.8543，无明显过拟合）。
- 物理合理性：廓线符合垂直物理规律；守恒律（质量/能量）。

## 7. 敏感性/鲁棒性
- 冗余模型应对设备失效；质量控制三件套：SNR 阈值 + 速度一致性(3σ) + 空间连续性(拉普拉斯)。
- 时间衰减权重保证新数据主导。

## 10. 弱点 / 可疑论断（深读发现）
1. **蒸馏天花板受 a 限制**：a 不是真值，a 的误差/偏差会直接传给 b，未见对 a 本身的独立验证。
2. **假设自相矛盾**：Q1 假设"局地均匀各向同性"，Q2 却用各向异性距离处理——边界层湍流实际各向异性。
3. 模型 b 静态、缺热力项，强对流天气系统偏差（自承），动态扩展式(6.15)未实现。
4. A* 假设"规划时段湍流场稳定"，仅适用短时，长时/快速演变失效。
5. 大量权重（α、β、γ、可靠性系数）为经验默认值，未系统标定；背景场 Tb、误差方差 σ² 来源未详述。
6. 梯度提升训练 R²0.9981 vs 测试 0.8001 明显过拟合（虽未选它，暴露数据量小）。
7. 部分表格公式在 Markdown 中错位/缺失，需核对原文。

## 11. 可迁移条件 vs 不可迁移
- **可迁移**：全源/单源双模型冗余应对失效；复杂模型蒸馏简单模型；变分同化三代价（观测+背景+平滑）；各向异性距离；多维权重（误差方差+空间密度+时间衰减）；质量控制三件套；A* 代价嵌入风险场；外推前先判显著性。
- **不可迁移**：Ri 阈值、γ=10、可靠性系数、τ=30min 等大气专用参数；各向同性假设；蒸馏在"教师模型本身不可靠"时不成立。
