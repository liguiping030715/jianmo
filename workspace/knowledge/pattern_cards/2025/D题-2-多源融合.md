# Card: 2025D-2 基于多源数据融合的低空湍流监测与航路优化

## 1. 问题指纹
- 同 D 题。特色：**物理公式对偶标定 + 变分同化三代价项 + A*代价函数**。

## 2. 信息流
```
Q1: 模型a(Ia=α1f(Ri)+α2TKE+α3S) vs 模型b(Ib=c1SW+c2S) → 正则化min(Ia-Ib)²+λ‖c‖² → RF标定
Q2: 各向异性距离wdist(γ>1垂直惩罚) → 变分同化J=Jobs+Jb+Js → 共轭梯度+卡尔曼 → 三维场
Q3: 双线性+垂直线性插值100m×50m → NWP诊断+5算法集成外推 → A*代价=(T1+T2)/2×dist
```

## 3. 分问拆解
- Q1：**双模型对偶标定**——全量模型a做基准，简化模型b只用单设备，最小化二者差+权重正则化；RF标定，RMSE 7.85→5.12，R² 0.65→0.854。
- Q2：**各向异性距离**wdist中γ>1惩罚垂直方向（垂直相关尺度小于水平）；权重=空间距离×数据源可靠性×时间衰减；**变分同化三代价**：观测项+背景场项+平滑项（二阶导），共轭梯度解+卡尔曼外推；湍流垂直指数衰减I=I0e^(-z/2000)。
- Q3：水平双线性+垂直线性插值规格化；5种外推算法集成（趋势外推/移动平均/指数平滑/多变量回归/时空相关）；**A*代价函数Cost=(T(ni)+T(nj))/2×distance**（平均湍流×路径长度）；中度以上湍流识别82%，暴露量降35%。

## 6. 可迁移 Pattern
> **"有全量模型和简化模型 → 用正则化把简化模型向全量模型对齐（distillation思路）"；"三维空间插值：各向异性距离，垂直方向加γ惩罚"；"数据同化=变分代价函数（观测+背景+平滑三项）"；"路径规划代价=边两端风险均值×边长，A*启发用欧氏距离"。**

## 7. 局限
