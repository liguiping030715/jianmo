# Card: 2025E 轴承故障诊断（手工+ViT 特征融合 / ResNet-CBAM / DANN+MMD 迁移 / 可解释性证据链）

> **Depth: L3_DEEP（P1.5 全文深读，含特征表与消融）**

## 0. 元数据
- 题目：源域（江南大学轴承数据）特征与分类 → 迁移到目标域 16 个无标签 .mat 文件 → 可解释性分析。该篇实际 4 问。

## 1. 问题指纹
- Q1 源域特征分析；Q2 源域故障分类；Q3 跨域迁移诊断；Q4 迁移可解释性。
- 真正困难：①故障冲击微弱、被噪声/转频调制；②源域（实验室）与目标域（实际工况）域偏移；③目标域完全无标签、无真值，如何验证。

## 2. 数学抽象链
```
Q1: 故障特征频率(机理):
    BPFI=fr·(Nd/2)(1+(d/D)cosα); BPFO=fr·(Nd/2)(1-...)
    BSF=fr·(D/2d)(1-(d/D cosα)²); FTF=fr·(1/2)(1-(d/D)cosα)
    手工特征: 时域(均值/RMS/峭度/偏度/波形/脉冲/裕度因子)
             +频域/包络(质心/带宽/熵/故障频带能量比)
    深度特征: 信号→DWT 64×64 小波图→ViT→FC 前 128 维
    手工 ∥ 深度 融合
Q2: 4 模型(KNN/TCN/ResNet-CBAM/DenseNet) × 3 划分(6:4/7:3/8:2)
Q3: Z-score(用源域 μ,σ 标准化目标域防泄漏) + MIC 筛跨域共性特征
    DANN(特征器 G vs 域鉴别器 D 的 minimax) + MMD(高斯核分布距离)
    L=Lcls+λ(Ldom+Lmmd), λ=0.5
    目标域聚类 + 余弦距离匹配源域模板 → 伪标签
Q4: 事前(模块化透明) + 事后(SHAP/TCAV) + 反事实
```

## 3. 为什么每个模型被选
- **手工+深度融合**：手工特征物理可解释、深度特征补人工难覆盖的隐性模式。
- **机理频率验证**：BPFI/BPFO/BSF/FTF 提供"信号峰值是不是真故障"的客观锚点，防止纯数据驱动误判。
- **ResNet-CBAM**：残差训深层 + CBAM 通道/空间注意力聚焦判别特征。
- **DANN+MMD 双机制**：对抗对齐（隐式）+ 分布距离（显式约束）互补，单一机制易不稳。
- **聚类+余弦匹配**：目标域无标签，只能无监督聚成类再与源域已知模板对齐。

## 4. Baseline 与消融逻辑
- Q2：4 模型 × 3 比例矩阵，ResNet-CBAM 7:3 最优 0.998，排序 ResNet-CBAM>TCN>DenseNet>KNN。
- Q3 无真值消融（表10）：Baseline → DANN → MMD → 本文，MMD 0.89→0.15、内聚性 0.62→0.91、跨域匹配 0.45→0.89。

## 5. 参数选择逻辑
- TCN/ResNet：100 轮、batch32、lr0.0002、Adam；DenseNet 50 轮、lr0.0001。
- 7:3 划分最优（6:4 训练不足、8:2 测试代表性弱）；λ=0.5；ViT 取 128 维。

## 6. 验证策略
- Q2：混淆矩阵 + t-SNE（轮廓/聚类）+ 四指标（ACC/P/R/F1）。
- Q3（无真值）：迁移前后 t-SNE 域混合可视化 + MMD/内聚性/匹配度三代理 + 关键特征统计与机理对照。
- Q4：像素级+频带级+特征级+反事实证据串联成可审计链。

## 7. 敏感性/鲁棒性
- 分层划分保类别分布；3σ 剔 <3% 异常中间数据；机理频率作噪声下的稳定锚。

## 9. 章节承接技法
- Q1 特征 → Q2 分类验证特征有效性；Q2 最优 ResNet-CBAM → Q3 直接作分类器；Q3 黑箱 → Q4 补可解释性。模型与结论跨问递进复用。

## 10. 弱点 / 可疑论断（深读发现）
1. **参数表硬伤**：表6 给 KNN 标了"训练轮次 200、batch32、lr0.0002、Adam"——KNN 是惰性无训练模型，根本无这些参数，系错套神经网络参数。
2. **无真值=无法确认真实正确率**：Q3 的 MMD/内聚性/匹配度全是间接代理，域对齐好不代表分类对。
3. 源域 99.8% 在实验室数据上取得，与实际工况域偏移下的性能无直接关系。
4. λ=0.5 称"实验证明最佳"但未给标定过程。
5. 特征维度高（手工+128）而样本小，ViT 侧过拟合风险；域对齐可能把对分类有用的域特有信息也抹掉（过度对齐）。
6. 4 类粒度粗，未区分故障严重程度；大量特征表数值在 Markdown 中重复/错位需核对原文。

## 11. 可迁移条件 vs 不可迁移
- **可迁移**：手工+深度特征融合；机理频率/公式作客观锚；模型×划分比例实验矩阵；DANN+MMD 域适应；无标签聚类+伪标签+余弦模板匹配；无真值时用多个代理指标做消融；可解释性多层证据链；用源域统计量标准化目标域防泄漏。
- **不可迁移**：BPFI/BPFO 等频率随轴承尺寸与转速变；λ、轮次等需按数据重标；代理指标在域差异极大时可能失真；"高源域准确率"不可外推到目标域。
