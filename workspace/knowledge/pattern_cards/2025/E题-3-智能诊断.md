# Card: 2025E-3 高速列车轴承智能故障诊断问题（ResNet-CBAM+DANN-MMD+SHAP）

## 0. 元数据
- 年份/题号：2025 E 题
- 学校：未在摘要标注

## 1. 问题指纹
- 同 E 题。特色：**ResNet-CBAM主干 + DANN对抗+MMD双重对齐 + 事前/过程/事后三层可解释性**——E题最完整的一篇。

## 2. 信息流
```
Q1: 下采样32k+滑窗1024/512 → SNR/RMS/波峰因子筛每类362+10%低分 → 手工20+特征+ViT128维
Q2: 6:4/7:3/8:2分层 → KNN/TCN/DenseNet/ResNet-CBAM → ResNet-CBAM 7:3 Acc=99.8%
Q3: Z-score用源域统计量+MIC筛共性 → DANN对抗+MMD联合 → 伪标签聚类 → MMD 0.89→0.15
Q4: 事前(模块化)+过程(t-SNE+MMD量化)+事后(SHAP聚焦故障频点)
```

## 3. 分问拆解
- Q1：**保留10%低分样本增强多样性**（不把数据筛得太干净）；手工特征（时/频/包络/时频20+项）+ ViT从64×64小波图提128维深度特征，**双路融合**；t-SNE轮廓系数0.7755验证特征。
- Q2：三种划分比例×四种模型全跑；ResNet-CBAM（残差+CBAM注意力）最优。
- Q3：**关键防泄漏细节：Z-score只用源域统计量**；MIC最大信息系数筛跨域共性特征；**DANN对抗博弈+MMD分布距离双损失**；伪标签迭代；MMD 0.89→0.15。
- Q4：三层可解释——①事前模型模块化结构；②过程t-SNE+MMD量化；③事后SHAP单样本归因，证明模型关注BPFO/BPFI频点。

## 6. 可迁移 Pattern
> **"防数据泄漏铁律：标准化只用源域统计量，目标域用同样的均值方差变换"；"数据筛选别把差样本全删——保留10%低分样本提泛化"；"域适应双损失：对抗(DANN)+距离(MMD)比单强"；"可解释性三段论：事前结构/过程对齐/事后SHAP归因"；"特征有效性验证：t-SNE轮廓系数量化聚类质量"。**

## 7. 局限
- ResNet-CBAM训练成本高；
- SHAP在深度模型上计算量大。
