# P3 reusable_patterns: 评价/综合评分类

> 从 2024 D/E + 2025 F + 各题Q3/Q4提炼。

## 1. 评价模型骨架
- 套现成框架（HEV/PSR/景观生态学指标）。
- 权重：AHP（主观专家）+ 熵权法（客观数据）组合，比单用稳。
- 指标显式赋 0~1 权重，可解释可调整。

## 2. 感性/抽象概念量化
- 拆成多个可计算子指标（时间维度+空间维度）。
- 每个子指标给物理/数学定义。
- 综合评分 = 加权和。

## 3. 必须做鲁棒性检验
- 灵敏度分析：单参数扰动+联合扰动。
- 外推验证：拿训练时没用过的样本测。
- 排名与专家认知/造园常识对照。

## 4. 管理决策类
- 先立原则清单（合法/安全/公平/效率），再写规则。
- 开关条件双向写（何时开+何时关）。
- 多条独立依据AND组合，比单阈值鲁棒。
