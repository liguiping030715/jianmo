# P3 reusable_patterns: 证据门 / 防胡编 / 可复现

> 全库通用，对应 v4 的 evidence gate / final audit。

## 1. 数值结果必须交叉验证
- 独立工具验证（STK/反算逆问题）。
- 守恒量验证（能量<0判椭圆、角动量模不变、周期=物理周长）。
- 国际标准数据集/标准轮廓线外部验证。

## 2. 做量级分析
- 修正项分主项/微扰（几何项473s vs Shapiro微秒），别平均用力。
- 大数相减丢精度 → 用点积投影代替。

## 3. 不确定性必须量化
- 蒙特卡洛抽样+概率云图。
- Bootstrap 估参数区间。
- 灵敏度分析（单参数+联合扰动）。

## 4. 验证动作清单
- 残差分布画直方图（正态/零对称）。
- 时间序列 70/30 或 5 折 CV。
- 与参考方法比趋势，不只比单点。
- 多场景分别报告误差。
