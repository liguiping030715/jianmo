# P3 reusable_patterns: 证据门 / 防胡编 / 可复现（带适用条件）

> P1.5 据 12 篇深读重写。

---

## Pattern E-1：数值结果独立交叉验证
- **Applicable When**：关键结果由单一算法/工具产出，需确认其可信。
- **Why It Works**：用独立工具、反算逆问题、守恒量或标准数据集从另一路径验证，单一路径的错误可被暴露。
- **Evidence**：2024F 能量守恒（E<0 判束缚）、角动量守恒、参数一致性；2024E 独立视频段测试。
- **Failure Modes**：两种方法若共享同一假设/数据，错误会同时出现、无法互证。
- **Do Not Use When**：无（关键结论须有独立验证；但验证手段要真正独立）。

## Pattern E-2：量级分析，区分主项与微扰
- **Applicable When**：模型含多个量级不同的项。
- **Why It Works**：抓主导项、把微扰单独处理，避免平均用力；并警惕大数相减丢精度。
- **Evidence**：2024F 几何项 473s vs Shapiro 微秒级，改用点积投影替代大数相减。
- **Failure Modes**：误判量级会漏掉虽小但决定性的项；微扰符号错误（2024F 多个修正项全负、符号可疑）。
- **Do Not Use When**：各项量级相近时不可随意忽略，需全保留。

## Pattern E-3：不确定性量化
- **Applicable When**：输入含噪声/参数需估计/结论对扰动敏感。
- **Why It Works**：蒙特卡洛/Bootstrap 给参数区间、灵敏度分析检验结论稳健性。
- **Evidence**：2025C 概率网络；各题 Bootstrap 区间与单参/联合扰动。
- **Failure Modes**：分布假设错误（如 2024F 背景"完全均匀"过强）使概率结果失真；样本少时区间不可靠。
- **Do Not Use When**：不能因做了不确定性量化就免除对模型结构错误的检查。

## Pattern E-4：残差与多场景验证
- **Applicable When**：回归/预测模型产出后。
- **Why It Works**：残差应零均值/无结构；多场景分别报误差、与参考法比趋势而非单点。
- **Evidence**：2024C 消融矩阵逐因子量化信息增益；2024D 多因子逐层回归。
- **Failure Modes**：只报总体指标会掩盖局部失效（如 2024E 观测点4 R²仅0.80）。
- **Do Not Use When**：无（残差与分场景是默认验证；但须在真实入口/目标环境下做）。
