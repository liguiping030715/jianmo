# P3 reusable_patterns: 优化/调度类模式（带适用条件，非通用规则）

> P1.5 据 12 篇深读重写。每条 Pattern 是**带条件的经验**。

---

## Pattern O-1：优质初始解 + 元启发式精化
- **Applicable When**：组合/调度问题规模大、不可穷举，且存在贪心或先验可构造好初解。
- **Why It Works**：贪心/先验初解把搜索放到高质量区域，再用 SA/GA/PSO/禁忌搜索改进，比纯随机启动收敛快。
- **Evidence**：2025A Q1 贪心+禁忌邻域；2024A NSGA-II；2025F 改进 GA。
- **Failure Modes**：初解过强可能限制多样性、陷入其邻域；编码与问题不匹配会产生大量非法解。
- **Do Not Use When**：小规模可用 ILP/精确解时，不必上元启发式（2025A 缺 ILP 对照、不知最优 gap，是其弱点）。

## Pattern O-2：双目标用帕累托或双种群；硬约束可两阶段
- **Applicable When**：两目标量纲冲突、难事先定权重；或某目标有明确硬阈值。
- **Why It Works**：帕累托保留权衡面；双种群（收敛+探索）防早熟；硬约束两阶段比加权求和更可控。
- **Evidence**：2024A NSGA-II；2025A Q3 DPEA 双种群、Q2 罚函数+分层修复。
- **Failure Modes**：加权法权重主观且敏感；罚函数系数过大约束被违反、过小目标失真。
- **Do Not Use When**：两目标有明确主次且阈值清晰时，简单加权/两阶段更直接，不必上帕累托。

## Pattern O-3：嵌套问题分步解，上问输出定下问
- **Applicable When**：各问天然递进（序列→分配→溢出→时间），下游依赖上游结果。
- **Why It Works**：分步降维、每步可验证，避免多问联合优化的高维耦合。
- **Evidence**：2025A Q1 无容量→Q2 加容量+SPILL→Q3 双目标。
- **Failure Modes**：分步是贪心，上游次优会传递并锁定下游，无法回头修正。
- **Do Not Use When**：各决策强耦合、必须联合权衡时，分步会丢失全局最优。

## Pattern O-4：路径/航路规划——风险嵌入代价
- **Applicable When**：在网格/图网络中寻路，且途经区域有连续风险（湍流/障碍）。
- **Why It Works**：把风险写进边代价（如两端风险均值×边长），A* 可证高效最优，实现安全-经济平衡。
- **Evidence**：2025D A* Cost=(T(ni)+T(nj))·distance；2025F 边权=长度−趣味+重复惩罚。
- **Failure Modes**：A* 假设规划时段场稳定，快速演变/长时段失效；启发函数设计不当影响效率。
- **Do Not Use When**：环境强动态、需在线重规划时，静态 A* 不适用；阈值应按数据分布/最大似然标定，不拍脑袋。
