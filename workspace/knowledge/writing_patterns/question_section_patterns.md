# P4 writing_patterns: 分问正文与图表写法（P1.5 深读升级版）

## 一问正文的功能段落（按论证需要取用，非固定凑满）
1. **问题分析**：这问真正困难是什么、需要什么子对象/子模型。
2. **数据预处理**：清洗/对齐/分组/标准化（说明口径与范围）。
3. **模型建立**：从题意到公式的推导逻辑，配算法/流程。
4. **模型求解**：参数如何确定、迭代与结果数值。
5. **结果分析**：与基线/消融对比、可视化论证。
6. **小结**：本问结论 + 明确"输出 X 作为下问输入"。

> 段落是为了把"为什么这样建模、改进是否成立"讲清楚；若某问无需复杂预处理或求解，不强行凑段。

## 信息流写法
- 每问结尾点明输出如何被下问使用，使各问链式传递（Q1 特征/基线→Q2 改进→Q3 寻优→Q4 鲁棒/解释）。
- 嵌套问题分步降维，但要说明分步可能带来的上游误差传递。

## 图表：按论证任务组织（核心原则）
**不设"每问至少 N 张流程图/结果图/对比表"的硬指标。每张图、每张表必须回答一个明确的论证问题；没有论证任务的图表一律删除。**

| 图表类型 | 它回答的论证问题 |
|---|---|
| 思路/算法流程图 | 我们是怎么解决的？ |
| 数据分布图 | 数据本身有什么规律/异常？ |
| 消融表 | 每个改进组件到底有没有用、贡献多少？ |
| 敏感性/鲁棒性图 | 参数扰动会不会推翻结论？ |
| 结果对比表 | 为什么最终选这个模型？ |
| 残差分布图 | 误差是随机的还是仍有结构？ |
| 三维/空间结构图 | 对象的空间结构/分布是什么？ |
| 混淆矩阵 | 哪些类别在互相混淆？ |
| t-SNE/聚类图 | 特征是否可分、域是否对齐？ |

- 对比表固定列：对象/指标/数值/提升幅度（或差距）。
- 图表数量由论证需要决定：可能一问多图，也可能一问仅一表，以"问题是否被证明"为准。
