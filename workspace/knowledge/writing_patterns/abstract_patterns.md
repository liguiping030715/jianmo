# P4 writing_patterns: 摘要写法（P1.5 深读升级版）

> 从 12 篇深读论文的摘要与正文对照归纳。摘要只承担"让评委快速抓住问题转化、方法链与可信结果"的任务。

## 摘要骨架（顺序服务于论证，非填空模板）
1. **背景一句**：领域重要性 + 现存缺口（感性缺量化/数据稀缺/分布偏移/设备会失效）。
2. **问题转化**：把题目的现实/感性对象转成数学对象（"移步异景"→异景程度；像素→裂隙对象；物理量→风险场）。这是优秀论文区别于普通论文的关键句。
3. **方法链总起**：基线 → 针对性改进，而非罗列算法名。
4. **分问展开**：每问"方法/关键技术 + 一个量化结果"，并体现各问如何链式传递。
5. **关键词**：5~8 个，取模型/算法/指标的实名词。

## 必含元素
- 每问一个**可核验**的量化结果（R²=0.995、Acc=99.8%、RMSE=5.12、MMD 0.89→0.15）。
- 一个能体现针对性的创新点名词（DANN-MMD、EESM+保序映射、变分同化三代价）。
- 明确的问题转化关系（现实词 → 数学词）。

## 反面清单
- 不写"取得良好效果/显著提升"，要写"R² 0.65→0.85"。
- 摘要不列公式推导、不堆图表编号，只说方法与结果。
- 不把摘要级/代理指标结果写成"已完全解决"（如无真值的迁移结果）。
- 不逐字复述题目。
