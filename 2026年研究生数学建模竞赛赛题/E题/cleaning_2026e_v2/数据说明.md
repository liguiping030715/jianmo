# cleaning_2026e_v2 处理后数据

E题的**处理后数据**（清洗/对齐版本 v2）。原始数据见上级目录《数据下载说明.md》。

## 为什么不在本文件夹
处理后数据共 **2.58GB、143 个文件**，其中单个 `text.npy` 达 **497MB**，超过 GitHub 单文件 100MB 硬限，无法直接进 git。已打包为 Release 附件。

## 下载
- Release 页面：https://github.com/liguiping030715/jianmo/releases/tag/2026-E-data
- 直链：https://github.com/liguiping030715/jianmo/releases/download/2026-E-data/cleaned_2026e_v2.zip

## 校验
- 附件名：`cleaned_2026e_v2.zip`
- 大小：**1,675,394,613 字节（约 1.56GB）**；解压后约 **2.58GB**
- SHA256：`49EC391C168F11E7A8A5ECCE30120B29EDF3BBB46C4660A6D4D52FFCE21FBBFD`

## 解压后结构（即本目录应有的内容）
```
cleaning_2026e_v2/
├── manifest.json
├── attachment1_manifest.json
├── aligned/
│   ├── train/  {text.npy, audio.npy, vision.npy}
│   ├── valid/   {...}
│   └── test/    {...}
└── unaligned/
    ├── train/  {text.npy, audio.npy, vision.npy}
    ├── valid/   {...}
    └── test/    {...}
```
- `text.npy`：768 维 BERT 文本特征；`audio.npy`：语音特征；`vision.npy`：视觉特征。
- `aligned_50`：三模态均按 50 个对齐序列位置；`unaligned_50`：文本 50 位，语音/视觉各 500 位（有效长度见对应 lengths）。
- 字段/维度含义见上级题目《复杂场景下多模态情感识别的数学建模与算法设计.md》“二、数据说明 / 附件2”。

> 把下载的 zip 解压后，内容应放在本目录（`E题/cleaning_2026e_v2/`）下，与 `media/` 平级。
