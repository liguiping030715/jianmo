# E题 数据下载说明

## 为什么数据不在本文件夹
GitHub 对普通 git 单文件有 **100MB 硬限制**，而 `E题数据.zip` 约 **1.88GB**，无法直接进 git 历史。数据已作为 **Release 附件**发布（不占用仓库体积）。

## 下载地址
- Release 页面：https://github.com/liguiping030715/jianmo/releases/tag/2026-E-data
- 直链：https://github.com/liguiping030715/jianmo/releases/download/2026-E-data/Eti_data_2026.zip

## 文件信息与校验
- 文件名（Release 附件）：`Eti_data_2026.zip`
- 大小：**1,884,355,282 字节（约 1.88GB）**；解压后约 **4.08GB**
- SHA256：`F895003ABEB3E972E69EF9C457032720CBCB8ECD3D2261A0E30BC15667604ACB`
- 校验（PowerShell）：
  `(Get-FileHash .\Eti_data_2026.zip -Algorithm SHA256).Hash`

## 数据构成（zip 内共 295 项）
- **附件1 数据集原始多模态样本**：MOSEI 部分原始视频 100 条（.mp4）；
- **附件2 数据集特征文件**：`aligned_50.pkl`、`unaligned_50.pkl` 等特征（.pkl）；
- **附件4 可解释专项视频样本与特征文件**：对齐 / 未对齐两版本（.mp4、.pkl）；
- 另有 2 个 .xlsx。
- 合计约 140 个 mp4、102 个 pkl、2 个 xlsx。
